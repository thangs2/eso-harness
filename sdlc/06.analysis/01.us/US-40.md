# US-40 — Consumer provisioning

**REQ:** `REQ-40` · **Năng lực:** `F-32` · **Actor:** A-01 · **AC:** [`AC-40`](../02.ac/AC-40.md)

## 1. Story

*Là* **operator**, *tôi muốn* BE provision đủ schema + material + setup info cho consumer, *để* consumer dùng được ngay, chạy lại vẫn an toàn.

## 2. Giá trị & vì sao không gộp

| | |
|---|---|
| **Giá trị** | onboard end-to-end: DB + file/folder/material + read-back |
| **Vì sao không gộp** | UI select là F-31; host sync là F-33 |

## 3. Trong / ngoài phạm vi

| Trong | Ngoài |
|---|---|
| schema `c_<id>` · material bundle · setup info | host projection |

## 4. AC dự kiến

| AC | Loại | Một dòng |
|---|---|---|
| `AC-40-1` | happy | provision schema + material + info; read-back |
| `AC-40-2` | edge | chạy lại idempotent; không duplicate |
| `AC-40-3` | failure | mismatch/material fail ⇒ error, fail closed |
