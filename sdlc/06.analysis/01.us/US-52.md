# US-52 — Truy vấn task ngoài scope không được lộ sự tồn tại

**REQ:** `REQ-26` · **Năng lực:** `F-18` · **Actor:** A-02 agent · **AC:** [`AC-52`](../02.ac/AC-52.md)

## 1. Story

*Là* **agent**, *tôi muốn* khi hỏi một task ngoài scope thì nhận **cùng một câu từ chối** dù task có tồn tại hay không —
*để* không dùng lỗi làm kênh dò thông tin.

## 2. Giá trị & vì sao không gộp

| | |
|---|---|
| **Giá trị** | `BR-10` + chống leak qua thông điệp lỗi |
| **Vì sao không gộp** | scope ghi file là `AC-50`; đây là truy vấn read |

## 3. Trong / ngoài phạm vi

| Trong | Ngoài |
|---|---|
| từ chối đồng nhất · log refusal · task trong scope trả dữ liệu | quyền actor (F-25) · DB isolation |

## 4. AC

| AC | Loại | Một dòng |
|---|---|---|
| `AC-52-1` | failure | task ngoài scope **có** tồn tại ⇒ `OUT_OF_SCOPE` |
| `AC-52-2` | failure | task ngoài scope **không** tồn tại ⇒ cùng mã + **cùng message** |
| `AC-52-3` | happy | task trong scope ⇒ `allowed` + task từ store |
