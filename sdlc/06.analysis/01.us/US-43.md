# US-43 — Stack composition & publish version

**REQ:** `REQ-48` · **Năng lực:** `F-34` · **Actor:** A-01 · **AC:** [`AC-43`](../02.ac/AC-43.md)

## 1. Story

*Là* **A-01**, *tôi muốn* xem và sửa layer policy/material của consumer rồi publish thành version bất biến, để host chỉ nhận cấu hình đã duyệt.

| | |
|---|---|
| **Giá trị** | host nhận đúng cấu hình đã publish, không cấu hình tự phát |
| **Vì sao không gộp** | worker sync (F-40) thuộc năng lực khác |
