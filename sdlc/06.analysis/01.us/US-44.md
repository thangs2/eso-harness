# US-44 — Host binding theo published Stack version

**REQ:** `REQ-49` · **Năng lực:** `F-35` · **Actor:** A-01 · **AC:** [`AC-44`](../02.ac/AC-44.md)

## 1. Story

*Là* **A-01**, *tôi muốn* gán developer × host runtime với một published stack version (và pin flow), để mỗi host chạy đúng cấu hình.

## 2. Giá trị & vì sao không gộp

| | |
|---|---|
| **Giá trị** | host nhận đúng cấu hình đã publish, không cấu hình tự phát |
| **Vì sao không gộp** | đăng ký host (F-30) thuộc năng lực khác |

## 3. Trong / ngoài phạm vi

| Trong | Ngoài |
|---|---|
| binding list · new/edit · bulk upgrade · pin flow · sources | đăng ký host (F-30) · sync (F-33) |

## 4. AC

| AC | Loại | Một dòng |
|---|---|---|
| `AC-44-1` | happy · edge | bảng binding + empty state |
| `AC-44-2` | happy | tạo binding tới version published |
| `AC-44-3` | edge | bulk upgrade nhiều developer |
| `AC-44-4` | edge | pin flow published + version |
| `AC-44-5` | failure · rbac | từ chối version draft/không tồn tại; lỗi có mã |
