# US-49 — Cấu hình observation & JEV cho consumer

**REQ:** `REQ-06` · **Năng lực:** `F-03` (+ `F-42` đọc) · **Actor:** A-01 · **AC:** [`AC-49`](../02.ac/AC-49.md)

## 1. Story

*Là* **A-01**, *tôi muốn* bật/tắt observation, chọn loại event và cấu hình JEV mode/threshold —
*để* host chỉ gửi evidence trong phạm vi đã đồng ý, còn verdict vẫn do ESO tính từ evidence đó.

## 2. Giá trị & vì sao không gộp

| | |
|---|---|
| **Giá trị** | consent tường minh · JEV config không chạy · evidence append-only |
| **Vì sao không gộp** | verdict (`F-09`/`F-15`) và observatory page (`F-42`) là nơi khác |

## 3. Trong / ngoài phạm vi

| Trong | Ngoài |
|---|---|
| consent · event kinds · JEV mode/threshold/confidence · link timeline | chạy JEV · verdict · sửa event · 3D |

## 4. AC

| AC | Loại | Một dòng |
|---|---|---|
| `AC-49-1` | happy · edge | consent on/off; off ⇒ khoá event + JEV |
| `AC-49-2` | happy | chọn event → Save lưu profile; đếm đúng |
| `AC-49-3` | edge · failure | JEV shadow/active thiếu consent ⇒ `PROFILE_JEV_NEEDS_CONSENT`; threshold sai ⇒ `PROFILE_JEV_THRESHOLD` |
| `AC-49-4` | happy · failure | timeline chỉ đọc + link `/observatory`; lỗi hiện mã + message |
