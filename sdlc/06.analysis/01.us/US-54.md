# US-54 — Đăng ký host & runtime dùng chung

**REQ:** `REQ-46` · **Năng lực:** `F-30` (+`F-33`) · **Actor:** A-01 · **AC:** [`AC-54`](../02.ac/AC-54.md)

## 1. Story

*Là* **A-01**, *tôi muốn* đăng ký host và runtime (kind/health/endpoint), khai model tier và ghi heartbeat —
*để* consumer bind được host thật, còn ESO chỉ lưu cấu hình/observation.

## 2. Giá trị & vì sao không gộp

| | |
|---|---|
| **Giá trị** | `BR-22` capability phải đo · host dùng chung, binding tách (`F-35`) |
| **Vì sao không gộp** | binding là `F-35`; sync projection là `F-33` |

## 3. Trong / ngoài phạm vi

| Trong | Ngoài |
|---|---|
| register/edit host · add/edit runtime · heartbeat · model tier | binding · sync · chạy host |

## 4. AC

| AC | Loại | Một dòng |
|---|---|---|
| `AC-54-1` | happy | register host + runtime hợp lệ |
| `AC-54-2` | failure | validate Host/Runtime ID (slug/trùng) |
| `AC-54-3` | edge | edit: ID read-only, sửa label/kind/health/endpoint |
| `AC-54-4` | happy | heartbeat cập nhật health + notice |
| `AC-54-5` | happy · edge | model sheet + 3 tier; `n models` |
| `AC-54-6` | failure | lỗi API hiện message; response thiếu ⇒ lỗi rõ |
