# US-39 — Host-first setup wizard

**REQ:** `REQ-39` · **Năng lực:** `F-31` · **Actor:** A-01 · **AC:** [`AC-39`](../02.ac/AC-39.md)

## 1. Story

*Là* **operator**, *tôi muốn* setup theo thứ tự host → source → consumer → observe → preview, *để* không chọn một source mà host không hỗ trợ.

## 2. Giá trị & vì sao không gộp

| | |
|---|---|
| **Giá trị** | source chỉ hiện khi host/capability cho phép; preview trước khi ghi |
| **Vì sao không gộp** | đây là luồng UI mới thay wizard v1; không phải onboarding 4 field |

## 3. Trong / ngoài phạm vi

| Trong | Ngoài |
|---|---|
| 6 bước host-first · source filter · preview · apply | cài plugin thủ công; billing/edition |

## 4. AC dự kiến

| AC | Loại | Một dòng |
|---|---|---|
| `AC-39-1` | happy | host → source khả dụng → 4 field consumer → preview → apply; không tier/recipe |
| `AC-39-2` | edge | `eso-native` chưa build ⇒ disable + lý do; source không hợp host ⇒ ẩn |
| `AC-39-3` | failure | id/root sai hoặc apply khi chưa preview ⇒ từ chối |
