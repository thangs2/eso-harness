# US-37 — Harness adapter packaging

**REQ:** `REQ-37` · **Năng lực:** `F-29` · **Actor:** A-01 · **AC:** [`AC-37`](../02.ac/AC-37.md)

## 1. Story

*Là* **operator**, *tôi muốn* cài harness layer theo cùng một cấu trúc cho mọi host, *để* thêm host mới không phải copy logic hoặc sửa core.

## 2. Giá trị & vì sao không gộp

| | |
|---|---|
| **Giá trị** | một core, adapter mỏng, conformance chung; thêm host không phá host khác |
| **Vì sao không gộp** | packaging là điều kiện của mọi adapter; không thuộc một host cụ thể |

## 3. Trong / ngoài phạm vi

| Trong | Ngoài |
|---|---|
| `eso/harness/{protocol,core,adapters,manifests}` · manifest · conformance | publish npm; UI cài đặt |

## 4. AC dự kiến

| AC | Loại | Một dòng |
|---|---|---|
| `AC-37-1` | happy | layout đúng; core không import host SDK |
| `AC-37-2` | edge | adapter đạt conformance + manifest khai capability |
| `AC-37-3` | failure | thiếu manifest/entrypoint ⇒ `MISSING_MANIFEST` |
