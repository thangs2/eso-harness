# US-50 — Scope guard: chặn ghi ngoài `allowed_files`

**REQ:** `REQ-26` · **Năng lực:** `F-18` · **Actor:** A-02 agent · **AC:** [`AC-50`](../02.ac/AC-50.md)

## 1. Story

*Là* **agent**, *tôi muốn* bị chặn **trước khi ghi** nếu path ngoài `allowed_files`, scope rỗng, hoặc thư mục đích đã mất —
*để* không có thay đổi đĩa một phần và mọi lần từ chối đều có bản ghi.

## 2. Giá trị & vì sao không gộp

| | |
|---|---|
| **Giá trị** | `BR-10` (scope check trước khi ghi) · từ chối có log |
| **Vì sao không gộp** | boundary policy (F-06) là khai báo; đây là enforce lúc ghi |

## 3. Trong / ngoài phạm vi

| Trong | Ngoài |
|---|---|
| glob match · refuse + log · empty scope · dangling scope · agent không set Done | quyền actor (F-25) · DB isolation (F-06) |

## 4. AC

| AC | Loại | Một dòng |
|---|---|---|
| `AC-50-1` | happy | path trong `allowed_files` ⇒ cho ghi |
| `AC-50-2` | failure | path ngoài ⇒ `BLOCKED_SCOPE`, không ghi, có refusal log |
| `AC-50-3` | edge | `allowed_files` rỗng ⇒ `EMPTY_SCOPE` |
| `AC-50-4` | edge | thư mục đích không tồn tại ⇒ `DANGLING_SCOPE` |
| `AC-50-5` | failure · rbac | agent set `Done` ⇒ `DONE_FORBIDDEN` |
