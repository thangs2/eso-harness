# Phase 1 charter — Consumer onboarding + provisioning

> **Re-baseline 2026-11-10:** goal/BRD cũ (“canonical repo harness UI”) thiếu nghiệp vụ provision.
> Gap chi tiết: [`08.gap-goal-brd.md`](08.gap-goal-brd.md).

## 1. Mục đích

Operator onboard một consumer từ CP: chọn consumer, cấu hình setup, BE provision đầy đủ schema + material + setup info; FE thấy trạng thái.

## 2. Mục tiêu đo được

| # | Mục tiêu | Đo bằng |
|---|---|---|
| G1 | Chọn consumer có sẵn trên `/onboarding` | AC onboarding UI |
| G2 | BE tạo/verify schema `c_<id>` | AC provisioning DB |
| G3 | BE ghi material: `AGENTS.md`, `agents/`, `.harness/config.json`, `manifest` | AC provisioning files |
| G4 | Setup info persist + đọc lại | AC read-back |
| G5 | Provision idempotent, fail-closed khi lệch id | AC idempotent/conflict |

## 3. Trong phạm vi

- `UC-17` Onboard consumer.
- FE: select consumer + setup flow.
- BE: schema provisioning + material provisioning + setup info.
- Một consumer có thể được dùng bởi nhiều host; host sync là **sau**, không phải core onboarding.

## 4. Ngoài phạm vi

- Host sync/projection (`L5.4`) — tách khỏi onboarding.
- Ingest/harness adapter/probe (`L7.x`/`L13.x`) — phase 2.
- Multi-user/remote.
- Database riêng mỗi consumer.

## 5. Stakeholder / vai

| Vai | Trách nhiệm |
|---|---|
| Operator (A-01) | chọn consumer, chạy setup |
| CP UI | hiển thị consumer, trạng thái, lỗi |
| CP BE | provision schema/material/info; idempotent; audit |
| Human signer | duyệt phase gate/`Done` |

## 6. Ràng buộc

- `D-125`: schema-expanded `c_<id>`; không shared-db, không isolated-db.
- `D-123`: canonical `AGENTS.md` + `agents/` + `.harness/`; host projection tách.
- `D-113`: `config.json` là artifact từ DB.
- Không implement trước gate + permission.

## 7. Material bundle

```text
AGENTS.md
agents/        (rules · skills · hooks · mcp · subagents)
.harness/config.json
.harness/manifest.json
schema c_<id>
setup metadata
```

## 9. Exit criteria

1. Chọn consumer + provision schema/material/info end-to-end.
2. Chạy lại idempotent; không duplicate.
3. Read-back setup info.
4. AC/SCN pass; human ký.

## 10. Rủi ro cấp phase

| Rủi ro | Ảnh hưởng | Giảm thiểu |
