# Phase 4 — Plan review (Learning + Host parity)

> **APPROVED 2026-11-19 — operator chốt D4-1..D4-7. Chưa implement.**

## 1. Vấn đề

```text
ESO đã có verdict/evidence nhưng chưa học từ evidence
host dry-run chưa phải model turn thật
Mode B chưa production transport
chưa đo parity giữa nhiều host
chưa audit một change ở mức team
```

Câu hỏi:

```text
evidence nào đủ để đề xuất thay đổi?
ai approve proposal?
apply xong đo thế nào, revert thế nào?
cùng SLP trên nhiều host có ra cùng kết quả?
vì sao một turn được cho qua?
```

## 2. Mục tiêu

```text
M1 Wire eso/learn: propose → approve → apply → measure → revert
M2 Human approval UI
M3 Real Mode A: Cursor/AGY auth + model turn
M4 Real Mode B: production transport
M5 Host parity metric
M6 Team-level observatory
M7 Evidence score
```

## 3. Deliverables

|---|---|---|---|
| 4.1 | Learning proposal store | proposal + diff + basis | P4-1 |

```text

[P4-5] người thứ ba audit một change từ evidence
```

## 5. Ngoài phạm vi

```text

```

## 6. Dependency / input

```text
Phase 2 verdict + JEV audit

```

## 7. Risks

| Risk | Giảm |
|---|---|
| learning tự apply | human approval gate |
| proposal dựa evidence yếu | basis + evidence score |
| real adapter lộ token | host env/keychain, không ESO |
| parity so sai | cùng flow/worker policy + fixture |
| audit team thiếu provenance | evidence score |

## 8. Decisions — APPROVED 2026-11-19

| # | Quyết định | Chốt |
|---|---|---|
| D4-1 | Approval UI | **Learning page riêng** `/consumers/:id/learning` |
| D4-2 | Proposal scope | **skill + rule trước; worker + flow sau**, theo risk tier |
| D4-3 | Apply mode | **draft → approve → apply version → measure → revert version** |
| D4-4 | Real adapter auth | **host-owned credential** (keychain > env > runtime provider); ESO không giữ token |
| D4-5 | Mode B production | **TLS + HMAC + host identity + nonce + replay window 5m**; mTLS sau |
| D4-6 | Parity metric | **policy + outcome là gate; evidence là diagnostic** |
| D4-7 | Evidence score | **deterministic 0–100**; shadow trước, không thay verdict |

Rule:

```text
không auto self-upgrade
không token trong snapshot/cache/evidence
không so raw output giữa host
score không bịa confidence
```
