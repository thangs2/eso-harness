# `12.phases` — phase execution workspaces

**Mỗi phase một workspace.** Workspace giữ **execution artifacts** của phase: charter · WBS · packets · go/no-go · decisions index · records · acceptance. Requirements/design dùng chung vẫn nằm ở các folder toàn cục.

| Phase | Trạng thái | Workspace |
|---|---|---|
| **Phase 1** | DOC-READY · HOLD | [`01.phase-1/`](01.phase-1/00.index.md) |
| **Phase 2** | planned · NO-GO | [`02.phase-2/`](02.phase-2/00.index.md) |
| Phase n | template | copy `01.phase-1` skeleton, không tạo rỗng |

## Luật

1. Phase folder **không copy** BRD/PRD/FRD/SRS/US/AC; chỉ link tới artifact toàn cục.
2. WBS + packet + go/no-go + record **thuộc phase**; active WBS nằm trong workspace.
3. Gate của phase đọc từ `03.go-no-go/`; không có gate ⇒ phase không được tuyên bố mở/đóng.
4. Decision vẫn một log toàn cục (`03.inception/02.decision-log`); phase chỉ giữ **index lọc**.
5. Status toàn cục (`02.governance/02.records/01.document-status`) vẫn là nguồn đo; phase record link tới nó.
6. Phase folder không thay thế `02.governance/01.standard`; standard là luật, phase là áp dụng.
