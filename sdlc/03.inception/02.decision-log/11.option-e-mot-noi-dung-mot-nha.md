# `11` — Option E: một nội dung, một nhà (D-128)

**Thay `D-127`.** `D-127` sai ở chỗ biến page thành **cái hộp chứa nội dung của mọi hạng mục**, rồi các artifact
lại mô tả lại nhau (FRD chép endpoint, "tech" chép cột + endpoint, page doc chép cả BA/QC/TECH). Đó **chính là phân mảnh**:
*"cùng 1 hạng mục, cùng 1 nội dung, nhưng bị đặt ở nhiều nơi"* — không phải "nhiều file".

> Định nghĩa chuẩn của *"rời rạc / phân mảnh / lỗi thời"* nằm ở [`13.doc-refactor-alignment`](../../02.governance/01.standard/13.doc-refactor-alignment.md) §1 — file này **không** định nghĩa lại.

## 1. Nguyên tắc

> **Nội dung thuộc hạng mục nào thì chỉ nằm ở folder của hạng mục đó. Nơi khác chỉ trỏ ID — không mô tả lại.**

1. **Một sự thật, một nhà.** Endpoint · entity/cột · KPI · mã lỗi · AC · SCN · test · trace — mỗi thứ **đúng một** file giữ.
2. **Page là ID, không phải nhà.** `/observatory` có id `PAGE-OBS`; page không sở hữu nội dung của BA/QC/TECH.
3. **Không lặp.** Nếu một câu đã có nhà, chỗ khác chỉ được viết `xem <ID>` — cấm chép bảng, cấm diễn giải lại.
4. **Không có delta ⇒ không có file.** Page không thêm component/entity/endpoint nào thì `01.architecture`, `02.data-design`, `03.api`
   **không nhận file nào**; trạng thái page ghi ở [`07.page-register`](../../02.governance/02.records/07.page-register.md) (ô `N/A` + lý do).
5. **Trace một chỗ:** chỉ RTM (QC) có bảng `AC → SCN → endpoint → bảng → test`.
6. **UI doc chỉ nói UI:** layout · section · component · state · a11y · visual. Cấm endpoint, cột, mã lỗi, AC, test, trace.

## 3. Hệ quả cho một page

| Hạng mục | Có file? | Vì sao |
|---|---|---|
| BA | ✅ FRD + (`REQ` trong SRS) + US + AC | page có hành vi riêng cần đặc tả và kiểm |
| QC | ✅ SCN + RTM | cần kịch bản và bản đồ kiểm |
| TECH | ❌ **N/A** nếu 0 delta | page chỉ **dùng** component/entity/endpoint đã có |
| UI | ✅ 1 file | bề mặt là nội dung riêng của UX |

## 4. Đã loại

| Phương án | Loại vì |
|---|---|
| `D-127` (page = 7 artifact, có "page wiring" trong `07.technical`) | tạo nguồn thứ tư cho endpoint/cột; đặt tài liệu L4-implementation vào folder L1–L3; page doc chép lại BA/QC/TECH |
| "Delta record" như một file riêng | vẫn là file thứ tư; delta chỉ là **một ô trạng thái**, không phải tài liệu |
| Gộp mọi thứ vào page doc | đúng kiểu phân mảnh đang muốn xoá |

## 5. Phép thử phản chứng

`D-128` sai nếu: (a) một sự thật (endpoint path, tên cột, mã lỗi, `AC`) xuất hiện ở **≥2** file; (b) page doc
chứa endpoint/cột/AC/test/trace; (c) `07.technical` nhận file cho page không có delta.

## 6. Áp dụng

`D-126` (upstream-first, evidence freeze, gate) **giữ nguyên**. `D-127` bị thay bởi file này.
Page `/observatory` làm lại theo bảng §2; trạng thái ghi ở [`07.page-register`](../../02.governance/02.records/07.page-register.md) (`TECH = N/A`, 0 delta).
