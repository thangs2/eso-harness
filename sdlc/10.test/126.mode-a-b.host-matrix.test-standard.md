# 126 — Mode A / Mode B host matrix — regression-test standard

> **Hiệu lực:** mọi regression test, release gate hoặc mở rộng host chạm
> `host-runtime`, `scripts/flow-orchestrate.mjs`, `worker-placement`, `modelTiers`
> hoặc adapter `dry | cursor | agy | main-chat`.
>
> Mục đích: không lặp lại các lỗi test ngày 2026-11-22 — test làm mất model
> override, dùng `jobId` trùng làm remote replay, rồi báo PASS giả.

## 1. Định nghĩa

| Mode | Điều kiện chạy | Host nào chạy model |
|---|---|---|
| **A — local** | Worker chạy trên host đang chạy flow | Host đó; model resolve từ worker placement → tier → default |
| **B — remote** | Worker được dispatch sang host khác | Host đích; model resolve theo placement của host đích |

Mode A/B là hành vi **host-side**. ESO chỉ giữ placement/config/observatory;
`eso/**` không được chạy, queue hay gọi model.

## 2. Điều kiện cấu hình bắt buộc

### 2.1 Worker placement

Mỗi worker trong matrix phải có:

```text
allowedHosts  : đủ host muốn test
modes         : ['A','B'] cho cấu hình chuẩn
models[host]  : model chỉ định cho từng host
hostBindingIds: hp-<consumer>-<hostId> cho từng host
```

`models[host]` là **nguồn chân lý per-worker per-host**. Không được xoá
`models` để "test host tier" trừ khi test case ghi rõ
`PURPOSE=host-tier`; nếu xoá thì mọi worker sẽ rơi về tier/default và test
không còn chứng minh cấu hình thật.

Thứ tự resolve của host runtime:

```text
explicit --model
→ placement.models[runtimeKey]
→ placement.model
→ runtime.modelTiers[tier]
→ runtime.defaultModel
→ MODEL_UNAVAILABLE
```

### 2.2 Host runtime

Mỗi runtime phải có:

```text
runtimeKey
models[]        catalog thật
defaultModel    model hợp lệ
modelTiers{}    fast/balanced/reasoning, mỗi tier trỏ model trong catalog
```

Nếu `modelTiers` rỗng mà flow gửi `modelTier=balanced`, host sẽ cảnh báo
`MODEL_TIER_NOT_MAPPED` và rơi về `runtime-default`. Đây là **config data
gap**, không phải model resolver đúng. Regression suite fail nếu còn warning
này trên host đã được khai.

### 2.3 Remote host

Host đích Mode B cần:

```text
server mode B đang listen
ESO_REMOTE_TOKEN >= 8 ký tự, cùng secret hai phía
allowedWorkspace chứa workspace repo
host token scoped cho consumer
remote envelope chấp nhận adapter tương ứng
```

Adapter Mode B theo runtime key:

```text
agy:*     → agy
cursor:*  → cursor
dsh:*     → main-chat
dry       → dry
```

`main-chat` phải nằm trong `ADAPTER_NAMES` của remote envelope.

Checker phải xanh và in matrix worker × host × model. Chỉ khi đó mới chạy
flow. Các điều kiện khác:

```text

2. ESO_TRACE_ID unique           — mỗi lần chạy một trace mới

4. remote server đang listen     — đúng port, token, workspace
5. placement snapshot mới        — restart remote server nếu host config đổi

```

## 5. Regression cases bắt buộc

### Mode A

| ID | Host | Điều kiện | Kỳ vọng |
|---|---|---|---|
| A-AGY-FULL | `agy:agy` | full SLP 7 worker | PASS 7/7; model đúng từng worker theo matrix |
| A-DSH-FULL | `dsh:main-chat` | full SLP 7 worker | PASS 7/7; DeepSeek Flash |
| A-CURSOR-QUOTA | `cursor:cursor-agent` | full SLP | FAIL `PROVIDER_QUOTA_OR_INFRA` tại worker đầu; không có model success |
| A-MODE-BLOCK | worker modes `['B']`, chạy local | 1 worker | BLOCKED `MODE_NOT_ALLOWED` |
| A-PLACEMENT-BLOCK | worker không placed trên host | 1 worker | BLOCKED `WORKER_NOT_PLACED` |

### Mode B

Mode B regression phải đặt `modes:['B']` tạm thời. Nếu để `['A','B']` và
host nguồn nằm trong `allowedHosts`, flow sẽ chọn local Mode A — đây là
**điều kiện test**, không phải bug.

| ID | Source | Target | Kỳ vọng |
|---|---|---|---|
| B-CURSOR-AGY | `cursor` | `agy` | PASS 7/7; không gọi model Cursor local |
| B-DSH-AGY | `dsh` | `agy` | PASS 7/7; model đúng từng worker |
| B-AGY-DSH | `agy` | `dsh` | PASS 7/7; DeepSeek Flash; không `MODEL_TIER_NOT_MAPPED` |
| B-CURSOR-FALLBACK | `dsh` | cursor trước, agy fallback | cursor FAIL quota → agy PASS; toàn flow PASS 7/7 |
| B-NO-REPLAY | bất kỳ | nhiều host | mỗi step jobId khác nhau; model các worker khác nhau (trừ host chỉ có 1 model) |
| B-REMOTE-DENY | target không cho worker | 1 worker | `WORKER_NOT_PLACED` |

## 6. Bằng chứng bắt buộc

Một lần regression chỉ được ghi PASS khi có đủ:

```text
1. check-mode-ab-config.mjs output
2. flow stderr từng bước:
   [flow N] worker -> host (local|remote) outcome=PASS model=<model> (<source>)
3. trace id
4. observation id cho ít nhất worker đầu/cuối
5. token estimate + duration
6. xác nhận modes/placements trước và sau test
```

Không chấp nhận bằng chứng dạng:

```text
"flow PASS"                    — thiếu model từng worker
"tất cả worker PASS"           — có thể là replay jobId
"model giống nhau"             — nếu host đa model, phải giải thích
"dry-run PASS"                 — không thay thế real-model test
```

## 7. Phân loại lỗi — phải ghi đúng

| Triệu chứng | Kết luận |
|---|---|
| Mọi worker cùng một model | Nghi `jobId` trùng / remote replay; kiểm job ledger trước khi kết luận resolver |
| Mọi worker ra `argon-medium` | Placement models bị xoá; test harness sai, không phải code |
| `MODEL_TIER_NOT_MAPPED` | Host runtime thiếu modelTiers; config data gap |
| `WORKER_NOT_PLACED` | allowedHosts/placement thiếu host |
| `MODE_NOT_ALLOWED` | modes thiếu A hoặc B |
| `PROVIDER_QUOTA_OR_INFRA` ở Cursor | Quota Cursor; ngoại lệ đã biết, không phải regression |
| `ADAPTER_UNKNOWN` / `policy.adapter must be` | Remote envelope thiếu adapter |
| PASS nhưng model không đúng matrix | Test không dùng config thật hoặc report lấy sai step |

## 8. Mở rộng host mới

Thứ tự bắt buộc:

1. Register host/runtime trong ESO với `runtimeKey`, `models`, `defaultModel`,
   `modelTiers`, `remoteUrl` nếu Mode B.
2. Issue host token scoped consumer; thêm host binding
   `hp-<consumer>-<host>`.
3. Thêm host vào `allowedHosts` của **tất cả worker** muốn chạy.
4. Thêm `models[newHost]` cho từng worker; không để trống trừ khi test
   explicit host-tier.
5. Thêm `modes` A/B.
6. Khởi động remote server Mode B với token/workspace đúng.
7. Chạy `check-mode-ab-config.mjs` — matrix mới phải in ra đủ.
8. Chạy smoke 1 worker thật trên host mới; kiểm model/source.
9. Chạy full SLP Mode A trên host mới.
10. Chạy full SLP Mode B từ ít nhất một source khác vào host mới.
11. Cập nhật matrix ở §3 và ghi trace/evidence.
12. Nếu host mới có quota/limit: ghi rõ expected-fail và fallback host.

Host mới **không đạt** nếu:

```text
không có modelTiers nhưng nhận modelTier
remote không nhận adapter của runtime
không có host binding
chỉ chạy được dry
```

## 10. Definition of done

```text
[ ] preflight checker PASS, matrix đúng
[ ] 7/7 worker PASS (Mode A host hỗ trợ đủ; Mode B target hỗ trợ đủ)
[ ] mỗi worker log đúng model + modelSource
[ ] jobId unique từng bước
[ ] không có MODEL_TIER_NOT_MAPPED trên host đã khai tiers
[ ] Cursor quota có expected-fail rõ nếu liên quan
[ ] fallback cursor → host khác PASS
[ ] trace + observation + token/duration được ghi
[ ] placements/modes restore sau test
[ ] remote server dừng
```

## 11. Prompt router (2026-11-25)

Prompt có thể chọn mode **không cần SLP**:

```text
mode=A <task>
mode=B <task>
impl <KEY> slp g mode=A|B <task>
```

Regression bắt buộc:

| ID | Case | Kỳ vọng |
|---|---|---|
| `MR-1` | `mode=A` từ mỗi host | target = local runtime của host đó |
| `MR-2` | `mode=B` từ mỗi host | target = remote đầu tiên trong `allowedHosts` |
| `MR-3` | mode B nhưng worker `modes=['A']` | fail `does not enable mode B` |
| `MR-4` | mode B nhưng chỉ local allowed | fail `no allowed remote` |
| `MR-5` | prompt có `to=` | fail, không dispatch |
| `MR-6` | không có default flow | fail `no default flow configured` |
| `MR-7` | `impl … slp g mode=A` | SLP optional, vẫn chọn target A |

Dry-run tối thiểu:

```bash
node .harness/hooks/eso-mode-router.mjs --host agy --prompt 'mode=A review X' --dry-run
node .harness/hooks/eso-mode-router.mjs --host dsh --prompt 'mode=B review X' --dry-run
```
