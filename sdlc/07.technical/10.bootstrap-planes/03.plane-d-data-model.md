# Plane D — Data model Bootstrap (DDL + cô lập)

**Một chủ đề:** mô hình dữ liệu `platform` + `c_<id>` và cơ chế cô lập. Không mô tả API (plane C).

## 1. Quy ước

- Một database; schema `platform` (registry) + `c_<id>` mỗi consumer; `public` **trống**.
- Mọi query qua `PlatformDb`; `search_path = c_<id>, platform, public` set **trong transaction** (`SET LOCAL`).
- **Không runner DDL, không `schema_version`**: `platform.consumer`/`consumer_event` bảo đảm bằng `CREATE TABLE IF NOT EXISTS` lúc CP start; schema `c_<id>` tạo trong transaction tạo consumer.

## 2. DDL — `platform`

```sql
create table platform.consumer (
  id                text primary key check (id ~ '^[a-z0-9][a-z0-9-]{1,31}$'),
  name              text not null,
  root              text not null,
  sdlc_root         text,
  schema_name       text not null unique,
  status            text not null check (status in ('ready','retired','deleted','purged','error')),
  version           integer not null default 1,
  storage_mode      text not null default 'schema' check (storage_mode = 'schema'),
  materialized_hash text,
  created_at        timestamptz not null default now(),
  updated_at        timestamptz not null default now()
);

create table platform.consumer_event (
  id          bigserial primary key,
  consumer_id text not null,
  event_type  text not null,
  actor_kind  text not null check (actor_kind in ('operator','machine','system')),
  actor_label text,
  at          timestamptz not null default now(),
  detail      jsonb not null default '{}'::jsonb
);
create index on platform.consumer_event (consumer_id, at desc);

```

## 3. DDL — schema consumer (trong transaction tạo consumer)

```sql
create schema c_<id>;
```

Bootstrap chỉ tạo schema rỗng; bảng miền thêm ở Expansion. Không bảng `schema_version`.

## 4. Cô lập và vòng đời

| Việc | Cách |
|---|---|
| Đọc/ghi | `SET LOCAL search_path` trong transaction; `public` trống ⇒ fail-closed |
| Retire | `status=retired`; data route 404; schema giữ |
| Soft delete | `status=deleted`; giữ schema + file; restore được |
| Purge | `DROP SCHEMA c_<id> CASCADE`; record `purged`; xoá file generated |

## 5. Bất biến

| Bất biến | Kiểm |
|---|---|
| `id` bất biến, slug 2–32 | check + REQ-06 |
| `version` +1 mỗi update | optimistic lock |
| Không bảng trong `public` | CP start DDL (`IF NOT EXISTS`) + test |
| Event append-only | không endpoint sửa/xoá |

## 6. Quyết định / không quyết định

| Quyết định | Không quyết định |
|---|---|
| DDL · check · index | API shape (→ plane C) |
| schema-per-consumer | microservice/tenant DB |

## 7. Revision rule

Đổi DDL ⇒ sửa `CREATE TABLE IF NOT EXISTS` tương ứng + bump; packet chạm bảng xem lại.
