# Plane C — Contract GĐ1 (HTTP API)

**Một chủ đề:** hợp đồng HTTP của control plane GĐ1. Không quyết định DDL (plane D), không hành vi nội bộ (plane B).

## 1. Chung

| | |
|---|---|
| Base URL | `http://127.0.0.1:8787` |
| Auth | `Basic` (UI) · `Bearer <ESO_API_TOKEN>` (máy) |
| Content | `application/json; charset=utf-8` |
| Envelope lỗi | `{ code, message, detail? }` — `code` ⊆ BRD `06` |
| Version | `/api/v1/` |
| CORS | allowlist `127.0.0.1:4200` · `localhost:4200`; GET,POST,PUT,DELETE,OPTIONS |

## 2. Endpoint

| Method · Path | Body | 200/201 | Lỗi chính |
|---|---|---|---|
| `GET /api/v1/auth/me` | — | `{kind}` | `AUTH_REQUIRED` · `AUTH_INVALID` |
| `GET /api/v1/consumers` | query `status` · `include_deleted` | `[consumer]` | `AUTH_*` |
| `POST /api/v1/consumers` | `id,name,root,sdlcRoot,profile` | consumer | `INVALID_CONSUMER_ID` · `ROOT_NOT_FOUND` · `CONSUMER_EXISTS` |
| `GET /api/v1/consumers/{id}` | — | consumer | `CONSUMER_NOT_FOUND` |
| `PUT /api/v1/consumers/{id}` | `profile, expected_version` | consumer v+1 | `STALE_VERSION` · `MATERIALIZE_FAILED` |
| `POST .../{id}/retire` · `/reactivate` | — | consumer | `INVALID_STATE` |
| `POST .../{id}/delete` · `/restore` | — | consumer | `INVALID_STATE` |
| `POST .../{id}/purge` | `confirm_id` | consumer `purged` | `PURGE_CONFIRM_MISMATCH` · `INVALID_STATE` |
| `GET .../{id}/profile` | — | `{profile,hash}` | `CONSUMER_NOT_FOUND` |
| `POST .../{id}/profile/check` | — | `{status,expected,actual}` | `CONSUMER_NOT_FOUND` |
| `POST .../{id}/profile/materialize` | — | `{hash}` | `ROOT_NOT_FOUND` · `PROFILE_INVALID` |
| `GET .../{id}/events` | query `limit` | `[event]` | `CONSUMER_NOT_FOUND` |
| `* /api/v1/c/{consumer}/…` | theo handler | 200 | `INVALID_CONSUMER_ID` · `CONSUMER_NOT_FOUND` |

## 3. Ngữ nghĩa

- Consumer **chỉ** từ path, không từ token/body.
- `PUT` = optimistic lock: thiếu/sai `expected_version` ⇒ 409.
- `purge` không hoàn tác; `confirm_id` phải khớp.
- 404 thống nhất cho không tồn tại/retired/deleted/purged.

## 4. Quyết định / không quyết định

| Quyết định | Không quyết định |
|---|---|
| route · method · status · mã lỗi | DDL/bảng (→ plane D) |
| auth scheme · CORS | UI state machine (→ 08.ui-design) |

## 5. Revision rule

Thêm/đổi route hoặc mã lỗi ⇒ đăng ký mã ở BRD/06 trước (`D-104`), bump version; packet liên quan xem lại.
