# Plane B — Kiến trúc baseline (C4 container + component)

**Một chủ đề:** cấu trúc tĩnh của control plane baseline và luồng request consumer-scoped. Không mô tả API (plane C), không DDL (plane D).

## 1. C4 — context

| Actor / hệ | Quan hệ |
|---|---|
| **Operator** (browser) | đăng nhập UI, quản lý consumer |
| **CLI `eso`** | `DDL` · `serve` · `consumer check/materialize` (Bearer) |
| **Consumer repo** | nhận `.harness/config.json` (ghi bởi control plane) |
| **Postgres** | lưu `platform` + `c_<id>` |

## 2. C4 — container

| Container | Công nghệ | Trách nhiệm |
|---|---|---|
| **UI** | Angular 22 · build bun · static | login · list · wizard · detail · nút trạng thái |
| **Control plane** | NestJS + Fastify (Node) | auth · registry · provisioning · profile · isolation · events |
| **Postgres** | PG ≥ 14 | `platform` + schema mỗi consumer |
| **CLI** | Node ESM | DDL · serve · check/materialize |

**Triển khai baseline:** control plane `127.0.0.1:8787`; UI dev `127.0.0.1:4200`; không proxy/TLS/multi-user.

## 3. C4 — component

| Component | Việc | Không làm |
|---|---|---|
| `auth` | Basic/Bearer · `AUTH_*` · `/auth/me` | account store, role |
| `platform-db` | `PlatformDb (query/exec/transaction)` · DDLs | ORM entity |
| `consumers` | register (transaction) · registry · lifecycle | ghi file profile |
| `profiles` | materialize · drift check · hash | quyết định version |
| `isolation` | route → registry → `SET LOCAL search_path`; fail-closed | fallback `public` |
| `events` | append + read timeline | sửa/xoá event |
| `host-sync` | đọc canonical, generate/merge projection, ghi manifest | không tạo consumer/không đổi version |
| `provisioning` | schema `c_<id>` + material + setup info; idempotent | không tạo consumer/không host projection |
| `errors` | envelope + mã lỗi BRD/06 | tự chế mã |

## 4. Luồng request consumer-scoped

```text
/api/v1/c/<consumer>/…
  → auth (401 nếu sai)
  → isolation: validate slug → tra platform.consumer (status=ready)
  → 404 CONSUMER_NOT_FOUND nếu không có
  → BEGIN; SET LOCAL search_path = c_<id>, platform, public
  → handler (chỉ query qua search_path)
  → COMMIT → trả connection (search_path không rò)
```

**Fail-closed:** thiếu registry/không `ready` ⇒ 404; `public` trống ⇒ quên `search_path` là lỗi.

## 4a. Consumer provisioning flow

```text
POST /consumers/{id}/provision
  → auth
  → registry: consumer ready
  → schema: create/verify c_<id>
  → material: AGENTS.md · agents/ · .harness/config.json · manifest
  → setup info: persist + read-back
  → 200 provisioned / error
```

- Idempotent; lệch id/schema ⇒ fail closed.
- Không đổi consumer version; không host projection.

## 4b. Host sync flow (canonical → projection)

```text
POST /consumers/{id}/hosts/sync
  → auth
  → registry: consumer ready
  → canonical reader: AGENTS.md · agents/ · .harness/config.json
  → host adapter (operator-selected): generate/merge
  → manifest: fail nếu ESO-owned hash lệch (PROJECTION_CONFLICT)
  → 200 synced/partial; consumer version unchanged
```

- Host sync **không** là bước setup; chạy trước/sau host install đều được.
- Projection là artifact; canonical là nguồn.

## 5. Quyết định / không quyết định

| Quyết định | Không quyết định |
|---|---|
| 4 container + ranh giới component | endpoint (→ plane C) |
| luồng auth → isolation | bảng/cột (→ plane D) |
| local-only · 1 operator | microservices/queue/observability |
