# 26 — Flow source of truth

## Decision

```text
Flow is the only source of truth for worker transitions.
```

Formation is not a domain object. It is the edge set of the default published flow.

## Canonical files

```text
.harness/flows/<flowId>.v<N>.json     published, immutable
.harness/flows/<flowId>.draft.json    draft, mutable
.harness/flows/index.json             default pointer
```

```json
{
  "defaultFlowId": "that-tinh-tran",
  "defaultFlowVersion": 1
}
```

## Derived artifacts

```text
workers.edges               derived from default flow
knowledge_worker_edge       derived from default flow
Workers tab formation view  derived from default flow
```

## Forbidden

```text
.harness/formation.json
PUT /workers with edges
WorkerFileService writing edges
Workers tab mutating edges
DB as canonical edge source
```

`PUT /workers` with edges returns:

```http
422 EDGES_MOVED_TO_FLOW
```

## Write path

```text
Flows page / flow API
  → PUT /flows/:flowId
  → validate
  → publish vN
  → index default if first or same flow
  → refresh worker edge index
```

## Read path

```text
GET /workers
  → workers from agents/subagents/*.md
  → edges + flow pointer from default flow
  → read-only

GET /flows/default
  → default published flow

policy.handoff
  → knowledge_worker_edge
  → rebuilt from default flow
```

## Invariants

```text
INV-1  Only flow publish writes worker transitions.
INV-2  WorkerFileService never writes formation.json.
INV-3  Workers tab never mutates edges.
INV-4  worker edge index equals default published flow edges.
INV-5  Every flow edge endpoint is an existing worker.
INV-6  hostBinding.flowVersion must exist as a published version.
INV-7  default pointer must point to a published version.
```

## Validation

Reject:

```text
unknown worker
duplicate edge id
self edge
edge endpoint not in nodes
default pointer to missing version
```

Allow with warning:

```text
FLOW_HAS_LOOP
```

SLP repair loop `verify ↔ fixbug` is intentional.

## Migration history

The old `formation.json` and `settings.harness.workerEdges` were removed on
2026-11-15. Existing consumers with formation data must move edges into a flow
draft, publish it, and set the default pointer. A consumer that already has a
published default flow wins; formation data is not imported over it.

`testeso` result:

```text
default  that-tinh-tran v1 published
workers  7
edges    8
formation.json removed
```
