# 36 — Prompt mode router: `mode=A|B` (host-side)

## 1. Vấn đề

Mode A/B là **placement của worker**, nhưng người dùng bắt đầu mọi việc bằng **prompt**. Nếu
prompt không chọn được mode thì config-only là thiếu. Router biến directive trong prompt thành
execution, **không phụ thuộc SLP**.

## 2. Ba trục độc lập — đừng trộn

| Trục | Câu hỏi | Ai chọn |
|---|---|---|
| **Agent/workload** | một agent hay SLP team? | prompt (`slp g` hay không) |
| **Mode A/B** | worker chạy ở host nào? | prompt `mode=` + placement config |
| **Model/tier** | model nào? | worker placement / host tier |

Mode A/B **không cần SLP**. SLP **không bắt buộc Mode**.

## 3. Hợp đồng prompt

```text
mode=A <task>
mode=B <task>
impl <KEY> slp g <task>            # SLP (không kèm mode — chưa nối)
```

| Phần | Nghĩa |
|---|---|
| `mode=A` | chạy **một worker** trên host đang nhận prompt |
| `mode=B` | dispatch **một worker** sang host remote đầu tiên trong placement |
| `<task>` | prompt còn lại, chuyển nguyên văn cho worker |
| `impl … slp g` | SLP team; **không** kèm `mode=` (router từ chối) |

**Cấm:**

```text
mode=B to=dsh:main-chat   → sai; target do placement quyết
mode=A                    → thiếu task
review X                  → không có mode; router không can thiệp
```

## 4. Cấu hình bắt buộc

| Thành phần | Nơi | Dùng để |
|---|---|---|
| Default flow | `GET /flows/default` | chọn flow + entry worker |
| Worker placement | `worker-placement` | `modes`, `allowedHosts` |
| `esoRoot` | `.harness/eso-host.json` | tìm `host-runtime` |
| Host token | `.harness/eso-host.json` | đọc `config-snapshot` |
| `ESO_REMOTE_URL/TOKEN` | host A env | Mode B dispatch |
| Remote server | host B `serve` | nhận dispatch |

Nếu thiếu default flow/worker → fail, **không** tự bịa worker.

## 5. Thuật toán chọn target

```text
modes = placement.modes.length ? placement.modes : ['A','B']
allowed = placement.allowedHosts

mode=A: first allowed host là local runtimeKey (hoặc main-chat)
mode=B: first allowed host KHÔNG phải local
```

- Không có target hợp lệ ⇒ fail-closed.
- Không fallback sang chat/SLP.
- `to=` bị từ chối vì phá single source.

## 6. Matrix prompt × host

Giả sử placement `allowedHosts = [agy:agy, dsh:main-chat, cursor:cursor-agent]`,
`modes = ['A','B']`.

| Host gõ prompt | Prompt | Target |
|---|---|---|
| AGY (`agy:agy`) | `mode=A <task>` | `agy:agy` local |
| AGY | `mode=B <task>` | `dsh:main-chat` remote |
| DSH (`dsh:main-chat`) | `mode=A <task>` | `dsh:main-chat` local |
| DSH | `mode=B <task>` | `agy:agy` remote |
| Cursor (`cursor:cursor-agent`) | `mode=A <task>` | `cursor:cursor-agent` local |
| Cursor | `mode=B <task>` | `agy:agy` remote |

Host detection:

```text
--host <id>  >  DSH env (PASEO_AGENT_ID/DSH_PROFILE → dsh)  >  ESO_HOST_ID  >  config first host
```

## 7. Thực thi

```text
Mode A: host-runtime run   --runtime-key <local> --flow <default> --worker <entry>
Mode B: host-runtime dispatch --from <local> --to <remote> --remote-url --remote-token
```

Cả hai dùng `--max-steps 1` cho single worker; `slp g` vẫn đi theo workload SLP nếu được triển khai.

## 8. Quan sát

- Cùng `traceId` xuyên host.
- Mode A: `local: true`, target local.
- Mode B: `local: false`, `remoteObservationId`.
- Model/tier lấy theo placement của host đích, không theo prompt.

## 9. Hiện trạng

| Phần | Trạng thái |
|---|---|
| Parser + target resolver | DONE · `qc/eso-mode-router.test.mjs` |
| Dry-run plan | DONE (`--dry-run`) |
| Mode A execute | DONE qua `host-runtime run` |
| Mode B execute | DONE qua `host-runtime dispatch`; cần remote server/token |
| Skill `mode-router` | DONE; model-followed |
| Hard injector — AGY | **DONE** — `injectSteps.userMessage` exact command |
| Hard injector — DSH | **DONE** — `hookSpecificOutput.additionalContext` exact command |
| Hard injector — Cursor | **BLOCKED** — `beforeSubmitPrompt` only has `continue`/`user_message`; no context-injection field. Skill-followed only. |
| Hard execution hook | **chưa** (không khuyến nghị cho Mode B) |

**Giới hạn:** AGY và DSH inject the exact command; the model still runs it. Cursor has no documented prompt-time context field ([Cursor hooks](https://cursor.com/docs/hooks.md)), so Cursor remains skill-followed. A full execution hook is deliberately not used: Mode B can exceed hook timeouts and would double-respond.
