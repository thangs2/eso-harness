# 34 — Host write boundary & folder policy

> **Trạng thái: DRAFT — REVIEW.** Chưa phải law. Cần operator chốt trước khi implement.

## 1. Nguyên tắc gốc

```text
Host hook là write gate duy nhất.
ESO phát policy + grant.
Host enforce.
ESO audit observation.
```

ESO **không** execute hook, không chặn write thay host. Nếu host bypass hook thì ESO chỉ thấy
observation thiếu; đó là giới hạn của sidecar.

Hooks thuộc host:

```text
ESO:      khai báo + material + project
Host:     install + execute
Legacy:   .harness/host-pack — moved to agents/hooks/host-pack 2026-11-18; .harness path removed
```

## 2. Phạm vi policy

`FolderPolicy` áp cho cả folder và file:

```text
pathType: file | directory | glob
```

Ví dụ:

```text
AGENTS.md          file
**/*.md            glob
**/*.mdc           glob
scripts/**         directory
```

## 3. Policy categories

### Write

| Mức | Host hook |
|---|---|
| `bypass` | cho ghi, không hỏi, vẫn audit |
| `gated` | deny; cần grant/approval mới cho |
| `warn` | cho ghi, trả reminder + observation |
| `deny` | luôn chặn |

### Read

```text
allow | deny
```

Ngoài repo root:

```text
default deny
operator grant:
  once    — một lần
  always  — persistent, revocable, audited
```

Read grant không được dùng để ghi.

### Index

```text
yes | no
```

`read` và `index` tách nhau:

```text
read allow + index no   → đọc được, không index knowledge
read deny  + index no   → không đọc, không index
```

## 4. Default policy

```text
trong <repo root>: allow-list theo folder/file
ngoài <repo root>: DENY tuyệt đối
                   chỉ mở bằng explicit external policy + grant
                   KHÔNG có bypass ngoài root
```

| Path / pattern | read | write | index |
|---|---|---|---|
| `SDLC/**` (hoặc `sdlcRoot`) | allow | allow | yes |
| `scripts/**` | allow | allow | no |
| `deploy/**` | allow | allow | no |
| `agents/**` | allow | allow | yes |
| `agents/hooks/**` | allow | **gated** | no |
| `.cursor/**` | allow | allow | no |
| `.agents/**` | allow | allow | no |
| `AGENTS.md` | allow | **allow + audit** | yes |
| `**/*.md`, `**/*.mdc` | allow | allow | yes/no theo folder |
| `.harness/runtime/**` | allow | allow | no |
| `.harness/config.json`, `manifest.json` | allow | **deny** | no |
| `.harness/bindings`, `placements.json` | allow | **gated** | no |
| `data-lake/**` | allow | **gated** | **no** |
| `.git/**` | allow | **deny** | no |
| `.env*`, `credentials*`, `*.pem` | **deny** | **deny** | no |
| `node_modules/**`, `dist/**` | allow | **deny** | no |
| **outside `<repo root>`** | **deny** | **deny** | no |

`AGENTS.md` cho ghi nhưng phải audit; law file không được sửa im lặng.

## 5. Precedence

```text
exact file > exact directory > glob dài nhất > recursive
deny luôn thắng allow
file rule thắng folder rule
external policy thắng internal nhưng vẫn phải gated
```

Không được:

```text
bypass ngoài repo root
symlink escape
policy mơ hồ → allow
policy hết hạn → allow
```

## 6. Grant

```text
WriteGrant
  grantId
  policyId
  actor
  targetPrefix
  purpose
  expiresAt
  issuedBy
  signature

ReadGrant
  grantId
  targetPrefix
  mode       once | always
  expiresAt  null for always
  issuedBy
  revokedAt
  signature
```

### Ai tạo grant?

**Operator tạo. Host chỉ request.**

```text
host gặp gated write
→ observation "write.grant.requested"
→ operator approve
→ host snapshot nhận grant
→ host enforce
→ observation "write.grant.used"
```

Lý do không cho host tự grant:

```text
host bị compromise có thể tự cấp quyền
mất human authority
không audit được ai cấp
```

Cho phép operator pre-authorize grant cho CI/automation, nhưng vẫn có expiry + signature.

## 7. Policy engine

```text
1. realpath(target)
2. ngoài repo root?
   → deny, trừ external grant
3. match policy:
   exact > prefix dài nhất > recursive
4. nhiều policy:
   deny > gated > warn > bypass
5. gated:
   grant còn hạn? allow : deny
6. read:
   outside root? grant once/always còn hiệu lực? allow : deny
7. write / deny
8. observation
```
