# `03` — Actor và thẩm quyền

**Nguồn:** vision §8 (actors) + `D-105`/vòng đời consumer. File này chốt **ai được làm gì**, và **cái gì không phải identity**.

## 1. Tám actor

| id | Actor | Loại | Quyền chính | Ghi chú |
|---|---|---|---|---|
| `A-01` | **Operator** | **người** | đăng ký/ sửa/ retire/ xoá consumer · ký `Done` · duyệt tri thức · bypass · đổi ngưỡng | người duy nhất trong baseline |
| `A-02` | Lead agent | máy | hỏi "đủ chưa" trước khi giao việc; ghi trong `allowed_files` | cần danh tính (Expansion) |
| `A-03` | Peer agent | máy | nhận pack, ghi trong `allowed_files` | cần danh tính (Expansion) |
| `A-04` | Auditor | người/máy đọc | chấm độc lập, không sửa | được đọc evidence |
| `A-05` | Host | hệ thống | khai năng lực thật của host | không được tự nhận "native" khi chưa đo |
| `A-06` | Provider | hệ thống | trả lời truy vấn, khai cái **không** thấy | |
| `A-07` | Consumer project | hệ thống | ranh giới cô lập; sở hữu dữ liệu | **không phải người đăng nhập** |
| `A-08` | Document custodian | người | chịu trách nhiệm một `kind` tài liệu | P7 |

## 2. Consumer **không phải** identity

| Điều | Đúng |
|---|---|
| Consumer là **bản ghi** (id · tên · root · profile · schema) do operator đăng ký | ✅ |
| Consumer "đăng nhập" vào control plane | ❌ — không có chuyện này |
| baseline có token/account riêng cho từng consumer | ❌ |
| Expansion: agent/hook trong repo consumer gọi control plane ghi evidence | ✅ — lúc đó mới thiết kế danh tính cho máy |

**Hệ quả:** mọi API consumer-scoped chọn consumer từ **đường dẫn** (`/api/v1/c/<consumer>/…`), không từ token; token không quyết định dữ liệu.

## 4. Mô hình truy cập baseline

| Thành phần | Cách |
|---|---|
| Control plane | chạy local `127.0.0.1`, một operator |
| Đăng nhập UI | 1 account từ file `.env` (`admin`/`change-me`); credential ở **sessionStorage** |
| Máy gọi API (CLI/proxy) | Bearer token trong cùng file `.env` |
| Consumer | không có account; xác định bằng route + registry |
| Lên **B** (team remote) | bổ sung HTTPS + account/role; **không** đổi mô hình consumer |
