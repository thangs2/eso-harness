# `06` — Use case nghiệp vụ

Mỗi use case: **actor · trigger · trước/sau · bất biến**. Use case **nghiệp vụ** — chưa phải đặc tả API.
`UC-01…UC-09` phục vụ Bootstrap (beneficiary); `UC-10…UC-14` thuộc Expansion.

## 1. Bootstrap — tạo và quản lý beneficiary

| id | Use case | Actor | Trigger | Kết quả | Bất biến |
|---|---|---|---|---|---|
| `UC-01` | **Đăng nhập control plane** | A-01 | mở UI | phiên đăng nhập bằng account trong `.env`; credential ở sessionStorage | `BR-05` |
| `UC-02` | **Đăng ký consumer** | A-01 | muốn dùng ESO cho một repo thật | record `ready` + schema riêng + `.harness/config.json` sinh ra | `BR-01` · `BR-02` · `BR-08`; root phải tồn tại |
| `UC-03` | **Xem danh sách / chi tiết consumer** | A-01 | mở màn consumers | thấy id · tên · root · status · version; mặc định ẩn `deleted` | `BR-06` |
| `UC-04` | **Sửa profile** | A-01 | đổi cấu hình cho consumer | version + 1; file sinh lại; hash cập nhật | `BR-09` · `BR-03` |
| `UC-05` | **Kiểm drift profile** | A-01 / CLI | nghi ngờ file bị sửa tay | `OK` hoặc `DRIFT` (nêu file, hash mong đợi/thực tế) | `BR-04` |
| `UC-06` | **Retire / reactivate** | A-01 | ngừng dùng tạm thời | trạng thái `retired`; dữ liệu giữ nguyên; route dữ liệu 404 | `BR-06` |
| `UC-07` | **Soft delete / restore** | A-01 | muốn ẩn consumer khỏi danh sách | `deleted` (ẩn, giữ dữ liệu) → restore về `ready` | `BR-06` |
| `UC-08` | **Purge consumer** | A-01 | xoá hẳn | schema mất, file generated mất, record `purged` (giữ audit) | `BR-07` · `BR-15` |
| `UC-09` | **Kiểm cô lập** | A-01 / test | trước khi tuyên bố Bootstrap xong | 6/6 case pass: không đọc chéo, injection bị chặn, pool không rò | `BR-01` · `BR-02` |

**Luồng thay thế bắt buộc (mã lỗi nghiệp vụ):**

| Mã | Khi nào |
|---|---|
| `ROOT_NOT_FOUND` | đăng ký consumer với root không tồn tại |
| `CONSUMER_EXISTS` | id đã có |
| `STALE_VERSION` | update profile với version cũ |
| `CONSUMER_NOT_FOUND` | route tới id không tồn tại / retired / deleted — **cùng một thông điệp** |
| `PROFILE_DRIFT` | `check` thấy file khác DB |
| `PURGE_CONFIRM_MISMATCH` | gõ lại id không khớp |
| `INVALID_CONSUMER_ID` | id không khớp slug 2–32 |
| `AUTH_REQUIRED` | thiếu credential (401) |
| `AUTH_INVALID` | sai credential (401) |
| `AUTH_NOT_CONFIGURED` | `.env` thiếu biến auth (server không khởi động) |
| `INVALID_STATE` | transition vòng đời không hợp lệ |
| `MATERIALIZE_FAILED` | ghi `.harness/config.json` lỗi |
| `PROFILE_INVALID` | file profile sinh ra không parse được |
| `INVALID_TASK` | task không dựng/parse được (F-09 · F-13 · F-20 · F-21) |
| `NEEDS_APPROVAL` | thay đổi cần người duyệt (F-12 · F-16 · F-24) |
| `FORBIDDEN_ACTOR` | actor không có quyền với action (F-16 · F-25) |
| `UNKNOWN_ACTOR` | không xác định được danh tính actor (F-18 · F-19 · F-25) |
| `UNKNOWN_CAPABILITY` | capability không có trong danh mục / host không khai (F-22 · F-23) |
| `SCOPE_VIOLATION` | ghi ra ngoài `allowed_files`/root consumer (F-18) |
| `NEAR_DUPLICATE` | tri thức gần trùng đã tồn tại (F-12 · F-16) |
| `DOC_CONTRACT_VIOLATION` | quan hệ derived⊆source hoặc HUMAN↔AI không thỏa (F-11 · F-20 · F-21 · F-27) |
