# FRD `F-18` — Scope check (`allowed_files`)

**Trace:** `P6` → `G-J` → `MET-14` · `BR-10`
**Actor:** A-01 · A-02 · A-03 · **Giai đoạn:** Expansion

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | write set (đường dẫn dự kiến ghi) + `allowed_files` của actor + `forbidden` |
| **Đầu ra** | `verdict ∈ allowed · denied` + `violations[]` (đường dẫn + lý do) |
| **Luật** | `BR-10` (nghiêng deny) · `BR-01` (cô lập) |
| **Trạng thái** | allowed · denied |

## 2. Xử lý

1. Chuẩn hoá path (resolve `..`, bỏ `.`), so với **root consumer** — path ra ngoài root ⇒ deny.
2. So với `allowed_files` (glob) và `forbidden`; không khớp allowed ⇒ deny.
3. Kiểm chéo consumer: path thuộc consumer khác ⇒ deny.
4. Trả violations kèm lý do; ghi event khi deny.
5. Deny áp **trước** khi ghi (không phải sau).

## 3. Từ chối

| Mã | Khi |
|---|---|
| `SCOPE_VIOLATION` | path ngoài allowed/forbidden/root |
| `UNKNOWN_ACTOR` | không xác định được actor để lấy scope |

## 4. Dữ liệu chạm

Đọc profile/scope của actor; ghi event `scope_denied` (audit).

## 5. Phi chức năng

- `allowed_files` rỗng ⇒ deny hết (fail-closed), trừ operator có quyền rộng.
- Không dựa vào lời dặn trong prompt — chỉ scope khai báo.
