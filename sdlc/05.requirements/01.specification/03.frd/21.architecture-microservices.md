# FRD `F-21` — Kiến trúc microservices

**Trace:** `P2` → `G-B2` → `MET-16` · `MET-17` · `BR-16`
**Actor:** A-01 · A-02 · **Giai đoạn:** GĐ2 (sau monolith)

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | hệ microservices: service · topic/queue · event · tenant · domain |
| **Đầu ra** | trả lời câu hỏi CQRS · event sourcing · multi-tenant · multi-domain **kèm chứng** |
| **Luật** | `BR-16` · `MET-16` (4/4 câu trên hệ thật) |
| **Trạng thái** | trả lời được · không đủ dữ liệu |

## 2. Xử lý

1. Dựng graph service ↔ topic/event ↔ aggregate.
2. Trả lời: *"đổi event X chạm service nào"* · *"read model nào lệch"* · *"tenant A có rò sang B không"*.
3. Mỗi kết luận kèm trích dẫn (config/handler/schema).
4. Không suy từ tên service; chỉ từ nguồn.
5. Không đủ dữ liệu ⇒ `unknown`.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `DOC_CONTRACT_VIOLATION` | kết luận không có chứng trong graph |
| `INVALID_TASK` | câu hỏi ngoài 4 nhóm CQRS/ES/tenant/domain |

## 4. Dữ liệu chạm

Đọc repo/hạ tầng consumer (read-only); graph index riêng cho microservices.

## 5. Phi chức năng

- **Không** tuyên bố G-B2 đạt bằng demo AMQP (đó là lỗi cũ trong vision).
- Không chạy trên production; chỉ đọc mô hình.
