# FRD `F-31` — Onboarding UI

**Trace:** `P3` · `P4` → `G-R` → `BR-26` · `BR-27` · `BR-30`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · `D5`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | consumer được chọn từ danh sách; root repo |
| **Đầu ra** | request provision + trạng thái provision hiển thị/read-back |
| **Luật** | `BR-26` (provision), `BR-27` (select consumer), `BR-30` (info) |
| **Trạng thái** | select · preview · provisioning · ready · error |

## 2. Luồng

1. **Select consumer**: dropdown/list consumer `ready`; không tạo mới nếu đã có.
2. **Review**: hiện consumer id/name/root, material bundle, schema `c_<id>`.
3. **Preview**: hiện việc sẽ provision; chưa ghi.
4. **Apply**: gọi provisioning F-32.
5. **Status**: hiện schema/material/info; lỗi mã + message; retry.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `CONSUMER_NOT_FOUND` | consumer không tồn tại |
| `INVALID_STATE` | consumer không `ready` |
| `ROOT_NOT_FOUND` | root không tồn tại |
| `PROVISION_FAILED` | BE provision lỗi (surface nguyên văn) |

## 4. Dữ liệu chạm

UI state; gọi F-32. Không tự ghi file/schema từ FE.

## 5. Phi chức năng

- Không có field host/source/tier/recipe.
- Không tự tạo consumer nếu đã có.
- Hiển thị trạng thái thật từ BE; không báo “xong” trước read-back.
