# FRD `F-34` — Stack policy & version lifecycle

**Trace:** `P1` · `P3` → `G-C` · `G-P` → `BR-32` · `BR-31`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · `D14`
**Model:** [`04.landscape/06`](../../../04.landscape/06.stack-host-binding.md) §4.1 (Stack = layer policy + material + document graph, versioned)

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | consumer `:id` · layer policy · material · document graph · rules material (`.mdc/.md`) |
| **Đầu ra** | danh sách version + version đang active; publish sinh version mới bất biến |
| **Luật** | `BR-47` (bất biến sau publish) · `BR-03` (DB là nguồn) |
| **Trạng thái** | no version · draft · published · active |

## 2. Xử lý

1. Đọc version hiện có + version active (`GET .../stack-versions`).
2. Sửa layer policy (bật/tắt layer, allowed sources) · material · document graph.
3. `Save changes` ⇒ `PUT .../stack-versions` danh sách version đầy đủ.
4. Publish = thêm version mới `published`; version cũ **không sửa** (`BR-47`).
5. Import rules material: preview trước, conflict phải chọn `keep-eso`/`adopt-legacy`; không ghi trước khi xác nhận.
6. Version active là version binding host dùng (`F-44`).

## 3. Từ chối

| Mã | Khi |
|---|---|
| `STACK_LAYER_INVALID` | layer không thuộc danh mục đóng |
| `STACK_VERSION_INVALID` | version ≤ 0 hoặc trùng số |
| `STACK_VERSION_IMMUTABLE` | sửa nội dung version đã publish |
| `RULES_IMPORT_CONFLICT` | import khi chưa chọn hướng xử lý conflict |

## 4. Dữ liệu chạm

`platform.harness_stack_version` · `consumer.profile.harness.stack` · `agents/rules/**` (rules material).

## 5. Phi chức năng

- Không publish khi thiếu layer bắt buộc; không tự bật layer.
- `PUT` idempotent theo danh sách version; gửi thiếu version ⇒ không xoá ngầm.

### 7.4 Hiển thị

`Version` select · trạng thái version (`draft`/`published`/`retired`) · 2 nhóm layer + mô tả · bảng rules (Rule · Description · Globs · Always apply · Action) · bảng Skipped · preview/skipped counts.

### 7.5 Lỗi

`STACK_DENIED` (401/403) · `STACK_UPSTREAM_FAILED` (5xx/network) · `STACK_INVALID` (version/layer không hợp lệ) · import lỗi hiện message. Hiện **mã + message**.

### 7.6 Không làm

Sửa layer khi version published (phải reopen/new version) · xoá version published đang active · sửa rule file trực tiếp (import là một chiều qua preview) · bulk upgrade binding (thuộc `F-35`, nút nằm ở tab hosts).
