### 7.3 Luật khớp pulse

1. Khớp **chính xác** `traceId` trước.
2. Không khớp ⇒ khớp chuỗi trên worker/event/outcome/evidence.
3. Không có kết quả ⇒ `OBS_TRACE_NOT_MATCHED`; chuỗi rỗng ⇒ `OBS_QUERY_EMPTY`; trace không event ⇒ `OBS_TRACE_EMPTY`.
4. Mỗi nhịp 450ms; hết trace tự dừng.

### 7.4 Trạng thái

`loading` · `ready` · `no published flow` (graph rỗng, không lỗi) · `playing` · `error`.

### 7.5 Lỗi (mã ở SRS `04` §6)

`OBS_CONSUMER_UNKNOWN` (consumer trong URL không tồn tại — **không** fallback im lặng) · `OBS_DENIED` (401/403) · `OBS_UPSTREAM_FAILED` (5xx/network) · `OBS_FLOW_MISSING` (rỗng, không lỗi) · 3 mã pulse ở §7.3.

### 7.6 Không làm

Ghi/sửa event · hiện prompt body · 3D event graph (Phase 2) · phân quyền per-consumer (`OPEN-OBS-ACL`).

## 8. Bề mặt `/events` — `PAGE-EVENTS` (audit C0–C6 + reverify, 2026-11-23)

**Chain:** US-53 · AC-53-1…6 · SCN-53 · RTM-EVENTS-01

> Cùng `F-42`; **REQ** [`REQ-52`](../04.srs/03.functional-requirements.md) (page-level, tách khỏi REQ-47 `/observatory`).
> UI [`13.events`](../../../08.ui-design/20.pages/13.events.md). Nguồn: `event-stream.page.ts` 520 dòng.

| | |
|---|---|
| **Route** | `/events?consumer=&trace=&event=` (query `project` = alias cũ của `consumer`) |
| **Component** | `observatory/pages/event-stream.page.ts` |
| **Actor** | A-01 operator |
| **Đầu ra** | list event + timeline trace + detail envelope/evidence/request card |

### 8.1 Khởi tạo

1. Tải `GET /consumers`; consumer = `?consumer=` nếu có trong list, ngược lại `?project=`, ngược lại consumer đầu tiên.
2. `?trace=` ⇒ set cả `traceFilter` và `selectedTrace` (timeline lọc **exact**); `?event=` ⇒ set `eventFilter`.
3. Khởi động **SSE** `GET .../observations/stream` (`autoRefresh` mặc định **true**); nếu stream không mở được ⇒ `streamState='fallback'` + poll `GET .../observations?limit=500` mỗi **5 s**. `Live` toggle bật/tắt cả hai.

### 8.2 List & filter

6 control: `Consumer` (select) · `Event` · `Outcome` · `Worker` (substring, reset page 0) · `Trace` (substring) · `Order` (newest/oldest).
3 chip: `All` (chỉ reset `eventFilter` — **không** reset `outcomeFilter`) · `Requests` (`prompt.submitted`) · `Failures` (`outcome=FAIL`).
Đếm `n events · m traces` (traces = distinct `traceId`). **Pager 40 dòng/trang** (`pageSize = 40`), `Previous`/`Page n / m`/`Next`.

### 8.3 Timeline 2D

Chỉ dựng cho `selectedTrace`: head `Trace · 2D timeline` + trace id + `Clear trace`; trục `traceStart` · `live →` · `traceEnd`; lane theo `workerId` (`unknown` khi rỗng); pill `eventLabel` (7 nhãn: `prompt.submitted`, `plan.created`, `tool.called`, `file.edited`, `decision.recorded`, `turn.completed`, `error`), đỏ khi `FAIL`/`BLOCKED`, click để chọn event. Timeline lọc **exact** `traceId` — gõ một phần trace có thể ra list nhưng timeline rỗng (khác list).

### 8.4 Detail

Envelope 9 khoá: `event_id` · `trace_id` · `span_id` · `parent_span_id` · `worker_id` · `host_binding_id` · `type` · `at` · `decision` (2 khoá span do UI sinh, không phải host báo).
`Evidence` = `<pre>` JSON thô, `<details open>`.
Nếu `event === 'prompt.submitted'`: link `Open full request detail →` (`/requests/{traceId}?consumer=`) + card `Prompt request` 5 field: `Request hash` · `Request length` · `Task type` · `Model` · `Adapter`; ghi rõ "Body is not stored by ESO policy".

### 8.5 Trạng thái

`loading` (`Loading events…`, `role=status`) · list empty (`No matching events` + gợi ý; **không** phân biệt consumer rỗng vs filter) · timeline empty (`No events for this trace in the loaded window.`) · stream `connecting`/`live`/`fallback`/`closed` · error banner `role=alert`.

### 8.6 Lỗi (as-is)

Hiện **message thô** (`detail || message`), **không** map mã `OBS_*` — không có chuỗi `OBS_` nào trong component. Đây là **lệch** với `REQ-47` ("mọi lỗi hiện mã + message") ⇒ `OPEN-EVENTS-ERROR-CODES`. Khi lỗi, banner hiện nhưng toolbar vẫn render `0 events · 0 traces` và empty state (không phải màn trắng).

### 8.7 Không làm (và dead code)

Không ghi/sửa event · không hiện prompt body · không 3D.
Nhánh `requestMode` (`Observatory · requests`, ép `prompt.submitted`) **không thể chạy**: `routeConfig.path` luôn `'events'`, không route nào trỏ component này với path `requests` ⇒ ghi nhận là **dead code**, không thuộc hành vi.
