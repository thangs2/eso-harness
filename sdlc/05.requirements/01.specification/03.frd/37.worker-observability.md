# FRD `F-42` — Worker execution observability

**Trace:** `P4` · `P7` → `G-V` → `BR-46` · `BR-12`

> **Phân tách subject trong cùng một F:** §1–§6 = **cơ chế** (event envelope · 2D/3D); §7 = **bề mặt** `/observatory`; §7b = **bề mặt** `/observatory/requests/:requestId`.
> Theo luật phòng *"mỗi `F-nn` một file"* ([`00.index`](00.index.md)) nên bề mặt nằm cùng file, không tách file thứ hai.
**Actor:** A-01 operator · A-04 auditor · **Giai đoạn:** Phase 2 · `D17`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | host adapter events; policy events; flow edge events |
| **Đầu ra** | event store; 2D timeline; 3D event graph sau 2D |
| **Luật** | `BR-46` (append-only, cùng envelope), `BR-12` (provenance) |
| **Trạng thái** | live · completed · error · empty |

## 2. Event envelope

```json
{
  "event_id": "evt_...",
  "trace_id": "trace_...",
  "span_id": "span_...",
  "parent_span_id": "span_...",
  "worker_id": "worker-build",
  "host_binding_id": "hb_...",
  "type": "worker.tool.write",
  "at": "...",
  "decision": "ALLOW",
  "payload": {}
}
```

## 3. Giai đoạn

```text
Phase 1  2D timeline theo worker lane, filter, click detail
Phase 2  3D event graph: x=time, y=worker, z=trace depth
```

Không có 3D trước 2D.

## 4. Từ chối

| Mã | Khi |
|---|---|
| `EVENT_INVALID` | envelope thiếu id/type/at |
| `EVENT_DUPLICATE` | trùng `event_id` |
| `TRACE_NOT_FOUND` | trace id không tồn tại |
| `OBSERVATION_DISABLED` | consent tắt |

## 5. Dữ liệu chạm

```text
knowledge_worker_event
knowledge_worker_handoff
```

2D/3D đọc cùng event store; 3D không có store riêng.

## 6. Phi chức năng

- Không log prompt body, secret, file content.
- Read-only viewer.
- 3D có fallback 2D.

### 7.3 Luật khớp pulse

1. Exact `traceId` trước; 2. substring trên trace/worker/event/outcome/evidence; 3. không khớp ⇒ `OBS_TRACE_NOT_MATCHED`; rỗng ⇒ `OBS_QUERY_EMPTY`; trace không event ⇒ `OBS_TRACE_EMPTY`; 4. 450 ms/nhịp, hết tự dừng.

### 7.4 Trạng thái

`loading` · `error` · `no published flow` (text, **không phải mã**) · `playing` · pulse empty/error. **Không có** state `ready`.

### 7.5 Lỗi — 6 mã thực phát

`OBS_UPSTREAM_FAILED` · `OBS_DENIED` · `OBS_CONSUMER_UNKNOWN` · `OBS_QUERY_EMPTY` · `OBS_TRACE_NOT_MATCHED` · `OBS_TRACE_EMPTY`.
`OBS_FLOW_MISSING` có trong SRS `04` §6 nhưng **không được phát** (flow rỗng render text `:118-119`) ⇒ `OPEN-OBS-FLOW-MISSING`.

UI hiển thị **mã + message** cho mọi lỗi (banner `role=alert`); không có nhánh "chỉ message".

### 7.6 Không làm

Ghi/sửa event · prompt body · 3D event graph (Phase 2) · không gọi API khi đổi view/filter (client-side).
