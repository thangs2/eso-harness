# FRD `F-42` — Worker execution observability

**Trace:** `P4` · `P7` → `G-V` → `BR-46` · `BR-12`

> Theo luật phòng *"mỗi `F-nn` một file"* ([`00.index`](00.index.md)) nên bề mặt nằm cùng file, không tách file thứ hai.


### 7.3 Luật khớp pulse

1. Khớp **chính xác** `traceId` trước.
2. Không khớp ⇒ khớp chuỗi trên worker/event/outcome/evidence.
3. Không có kết quả ⇒ `OBS_TRACE_NOT_MATCHED`; chuỗi rỗng ⇒ `OBS_QUERY_EMPTY`; trace không event ⇒ `OBS_TRACE_EMPTY`.
4. Mỗi nhịp 450ms; hết trace tự dừng.

### 7.4 Trạng thái

`loading` · `ready` · `no published flow` (graph rỗng, không lỗi) · `playing` · `error`.

### 7.5 Lỗi (mã ở SRS `04` §6)

`OBS_CONSUMER_UNKNOWN` (consumer trong URL không tồn tại — **không** fallback im lặng) · `OBS_DENIED` (401/403) · `OBS_UPSTREAM_FAILED` (5xx/network) · `OBS_FLOW_MISSING` (rỗng, không lỗi) · 3 mã pulse ở §7.3.

### 7.6 Không làm

Ghi/sửa event · hiện prompt body · 3D event graph (Phase 2) · phân quyền per-consumer (`OPEN-OBS-ACL`).

## 8. Bề mặt `/events` — `PAGE-EVENTS` (cùng `F-42`)

> Cùng `F-42`; chi tiết observatory ở §7. Tiêu chí `AC-53-1…4`; UI [`13.events`](../../../08.ui-design/20.pages/13.events.md).
> Mã lỗi: dùng `OBS_*` (§4) — page này **không** có mã riêng.

| | |
|---|---|
| **Actor** | A-01 operator |
| **Đầu vào** | consumer · filter event/outcome/worker/trace/order |
| **Đầu ra** | danh sách event host-reported; chọn event ⇒ request/evidence detail |
| **Trạng thái** | loading · ready · empty (nêu lý do) · error |

**Xử lý**

1. Chọn consumer (query `?consumer=`); không có ⇒ consumer đầu tiên.
2. Tải observation list một lần (`GET .../observations`), **read-only**.
3. Filter: event type · outcome · worker (chuỗi con) · trace (khớp chính xác trước) · order; đếm `n events · m traces`.
4. Chọn một event ⇒ hiện request/evidence detail (không có prompt body).
5. Điều hướng: `Observatory` · `Office 3D` (mang `?consumer=`).
6. Lỗi hiện **mã + message** (SRS `04` §6) — không hiện 0 giả.

**Không làm:** ghi/sửa event · hiện prompt body · 3D graph (office) · phát lại (ở §7).
