# FRD `F-33` — Host sync

**Trace:** `P1` · `P4` → `G-C` · `G-M` → `BR-24` · `BR-25`
**Actor:** A-01 operator · **Giai đoạn:** roadmap · `D13`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | consumer + danh sách host operator chọn |
| **Đầu ra** | projection `.cursor`/`.agents`/`.claude`/`.dsh` + sync status |
| **Luật** | `BR-24` (projection, merge, không đổi consumer) · `BR-25` (operator chọn) |
| **Trạng thái** | synced · partial · conflict · error |

## 2. Xử lý

1. Operator chọn một/nhiều host; **không auto-detect**.
2. Đọc canonical `AGENTS.md` + `agents/` + `.harness/config.json`.
3. Generate projection ESO-owned; **merge** file người dùng đã có.
4. Ghi sync status vào `.harness/manifest.json`.
5. Không tạo consumer mới, không tăng consumer version.
6. Chạy lại idempotent; host thêm sau setup chỉ cần sync.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `HOST_UNSUPPORTED` | host ngoài danh mục |
| `PROJECTION_CONFLICT` | merge không an toàn (file khác ESO-owned) |
| `CANONICAL_MISSING` | chưa có `.harness`/`agents/` |
| `SYNC_FAILED` | ghi projection lỗi |

## 4. Dữ liệu chạm

`.cursor/**` · `.agents/**` · `.claude/**` · `.dsh/**` · `.harness/manifest.json`.

## 5. Phi chức năng

- Projection **hybrid** generate/merge; không overwrite mù.
- Thêm/bớt host không đổi consumer identity/version.
- Host lạ ⇒ fail closed, không đoán layout.

## 6. OPEN

Không còn OPEN. Layout host theo `D-123`; chi tiết merge thuộc implementation phase 2.
