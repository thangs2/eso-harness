# FRD `F-02` — Đăng ký consumer

**Trace:** `B-00` · `P3` → `G-L` → `D3` → `UC-02` · `BR-01` · `BR-02` · `BR-03` · `BR-08`
**Actor:** A-01 · **Giai đoạn:** Bootstrap

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `id` (slug 2–32) · `name` · `root` (đường dẫn tuyệt đối tới repo) · `sdlcRoot` · các trường profile |
| **Đầu ra** | record `platform.consumer` (`status=ready`, `version=1`) · schema `c_<id>` · `.harness/config.json` |
| **Luật** | `BR-01` · `BR-02` · `BR-03` · `BR-08` |
| **Tính nguyên tử** | một transaction: `CREATE SCHEMA` + DDL + insert registry + event; lỗi ⇒ rollback toàn bộ |

## 2. Xử lý

1. Validate `id` bằng slug; validate `root` **tồn tại** và là directory.
2. Kiểm `platform.consumer` chưa có `id` (kể cả `deleted`/`purged` ⇒ `CONSUMER_EXISTS`).
3. Một transaction:
   1. `CREATE SCHEMA c_<id>`;
   2. tạo bảng Bootstrap trong schema (`schema_version` + bảng dùng chung);
   3. insert `platform.consumer` với `storage_mode='schema'`, `status='ready'`, `version=1`;
   4. ghi `platform.consumer_event(created)`.
4. Sau commit: materialize `.harness/config.json` (gọi F-05) + lưu `materialized_hash`.
5. Trả `201` kèm record (không trả credential).

## 3. Từ chối

| Mã | Khi |
|---|---|
| `INVALID_CONSUMER_ID` | slug sai độ dài/ký tự |
| `ROOT_NOT_FOUND` | root không tồn tại / không phải directory |
| `CONSUMER_EXISTS` | id đã có (bất kể trạng thái) |
| `MATERIALIZE_FAILED` | bước 4 lỗi sau commit ⇒ record chuyển `error`, báo operator |

## 4. Dữ liệu chạm

| Nơi | Ghi gì |
|---|---|
| `platform.consumer` | id · name · root · sdlc_root · schema_name · status · version · storage_mode · created_at · updated_at |
| `platform.consumer_event` | `created` |
| schema `c_<id>` | bảng dữ liệu của consumer + `schema_version` |
| `<root>/.harness/config.json` | bản chiếu profile (artifact) |

## 5. Phi chức năng

- `id` **bất biến** (BR-08); không cho đổi qua update.
- Nếu materialize lỗi: consumer vẫn tồn tại nhưng `status=error`; operator có thể retry materialize, không tạo lại schema.
- Không cho đăng ký khi DB chưa migrate (kiểm `platform.schema_version`).
