# FRD `F-35` — Host binding & capability resolution

**Trace:** `P1` · `P7` → `G-C` · `G-P` → `BR-35` · `BR-33` · `BR-34`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · `D14`
**Model:** [`04.landscape/06`](../../../04.landscape/06.stack-host-binding.md) §2.2–§5 (WHO × WHERE × WHICH; cardinality developer × host × version)

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | consumer `:id` · developer · host runtime · **published** stack version · flow (tuỳ chọn) |
| **Đầu ra** | host binding list; binding trỏ đúng version + flow; bulk upgrade |
| **Luật** | `BR-48` (chỉ published) · `BR-44` (flow là cấu hình) |
| **Trạng thái** | no binding · active · drift (version cũ) |

## 2. Xử lý

1. Đọc binding + host runtime + version hiện có.
2. Thêm binding: chọn developer · host runtime · stack version; version phải `published`.
3. Sửa binding: đổi version/flow; pin `flowId` + published `flowVersion` (nếu có).
4. Bulk upgrade: chọn nhiều developer → cùng một version đích.
5. Xoá binding: chỉ xoá join, không xoá host runtime/consumer.
6. Binding giữ `memorySource`/`codeGraphSource` + provider (nếu có).

## 3. Từ chối

| Mã | Khi |
|---|---|
| `BINDING_INVALID` | thiếu developer/host runtime |
| `VERSION_NOT_FOUND` | stack version không tồn tại |
| `VERSION_NOT_PUBLISHED` | trỏ version draft |
| `BINDING_CONFLICT` | trùng developer × host runtime |

## 4. Dữ liệu chạm

`host_binding` · `platform.consumer.profile.harness` · `platform.host_runtime` (read).

## 5. Phi chức năng

- Không tạo host runtime mới từ tab này (đăng ký thuộc F-30/F-33).
- Bulk upgrade không tạo version mới; chỉ đổi con trỏ.
- Xoá binding không đụng Stack/Flow.
