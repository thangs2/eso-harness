# FRD `F-39` — Consumer worker flow

**Trace:** `P1` · `P4` → `G-T` → `BR-44` · `BR-32`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · `D16` · Phase B done

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | consumer id; workers đã lưu; flow definition (nodes/edges) |
| **Đầu ra** | flow draft/published version; default pointer; worker edge index derived |
| **Luật** | `BR-44` (flow là source duy nhất), `BR-32` (published immutable) |
| **Trạng thái** | no flow · draft · valid · published · default |

## 2. Luồng

1. **Open**: `/consumers/:id/flows`, không phải Settings tab.
2. **Edit**: read-only canvas Phase A; sửa edge `on` + guard.
3. **Validate**: worker tồn tại; edge endpoint; edge id; cycle chỉ warning `FLOW_HAS_LOOP`.
4. **Save draft**: `PUT /flows/:flowId`.
5. **Publish**: ghi `v<N>` immutable, xoá draft.
6. **Default**: `PUT /flows/default`; chỉ published version.
7. **Workers tab**: đọc default flow; edges read-only; `PUT /workers` gửi edges ⇒ 422.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `EDGES_MOVED_TO_FLOW` | `PUT /workers` còn gửi edges |
| `FLOW_INVALID` | worker/edge không hợp lệ |
| `FLOW_CYCLE` | không dùng cho loop; loop là warning |
| `NO_DRAFT` | publish khi không có draft |
| `VERSION_NOT_FOUND` | pin/default version không tồn tại |
| `CONSUMER_NOT_FOUND` | consumer không tồn tại |

## 7. Bề mặt `/consumers/:id/flows` — `PAGE-FLOWS`

> Cùng `F-39`; mã lỗi ở SRS `04` §6; tiêu chí `AC-42-1…11`; UI [`05.consumer-flows`](../../../08.ui-design/20.pages/05.consumer-flows.md).

| | |
|---|---|
| **Actor** | `A-01` operator |
| **Đầu vào** | `:id` · danh sách flow của consumer · worker set đã lưu |
| **Đầu ra** | flow draft/published · default pointer · kết quả validate |
| **Trạng thái** | `no flow` · `draft` · `published` · `default` · `validating` · `publishing` · `error` |

**Xử lý**

1. **Danh sách**: hiện mọi flow (`name · id · v · status · default`); rỗng ⇒ `No flow yet.`
2. **Chọn flow**: tải definition; badge `status v<version>`, thêm `default` nếu là default.
3. **Tạo**: chỉ khi worker set đã lưu; chưa có ⇒ `FLOW_WORKERS_REQUIRED`.
4. **Đổi tên**: inline; `Enter` lưu, `Escape` huỷ; tên rỗng ⇒ không lưu.
5. **Sửa canvas**: di chuyển node; tạo cạnh phải có `on`; xoá cạnh; sửa `on`/guard.
6. **Công cụ**: undo/redo (lịch sử cục bộ) · fit · snap grid · auto arrange.
7. **Validate**: gọi server; loop là **warning**, không phải lỗi; invalid ⇒ nêu lỗi.
8. **Save draft**: ghi `PUT /flows/:id`.
9. **Publish**: validate → save → publish; bản published **immutable**; draft biến mất.
10. **Set default**: chỉ flow `published`.
11. **Delete draft**: hỏi xác nhận; **không** ảnh hưởng bản published.
12. **SLP proposal** (nếu có): hiện nguồn + số node/edge + warning; `Apply` mới ghi.
13. Lỗi: **mã + message**; `401/403` ⇒ `FLOW_DENIED`, `404` ⇒ `FLOW_NOT_FOUND`, còn lại ⇒ `FLOW_UPSTREAM_FAILED`.

**Không làm:** sửa worker/skill (thuộc settings) · pin flow cho host (F-39 §2.7, API) · sửa bản published.
