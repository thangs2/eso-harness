# FRD `F-39` — Consumer worker flow

**Trace:** `P1` · `P4` → `G-T` → `BR-44` · `BR-32`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · `D16` · Phase B done

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | consumer id; workers đã lưu; flow definition (nodes/edges) |
| **Đầu ra** | flow draft/published version; default pointer; worker edge index derived |
| **Luật** | `BR-44` (flow là source duy nhất), `BR-32` (published immutable) |
| **Trạng thái** | no flow · draft · valid · published · default |

## 2. Luồng

1. **Open**: `/consumers/:id/flows`, không phải Settings tab.
2. **Edit**: read-only canvas Phase A; sửa edge `on` + guard.
3. **Validate**: worker tồn tại; edge endpoint; edge id; cycle chỉ warning `FLOW_HAS_LOOP`.
4. **Save draft**: `PUT /flows/:flowId`.
5. **Publish**: ghi `v<N>` immutable, xoá draft.
6. **Default**: `PUT /flows/default`; chỉ published version.
7. **Workers tab**: đọc default flow; edges read-only; `PUT /workers` gửi edges ⇒ 422.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `EDGES_MOVED_TO_FLOW` | `PUT /workers` còn gửi edges |
| `FLOW_INVALID` | worker/edge không hợp lệ |
| `FLOW_CYCLE` | không dùng cho loop; loop là warning |
| `NO_DRAFT` | publish khi không có draft |
| `VERSION_NOT_FOUND` | pin/default version không tồn tại |
| `CONSUMER_NOT_FOUND` | consumer không tồn tại |
