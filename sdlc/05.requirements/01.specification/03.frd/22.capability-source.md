# FRD `F-22` — Chọn nguồn năng lực host

**Trace:** `P1` → `G-C` → `MET-05`
**Actor:** A-05 (host) · hệ thống · **Giai đoạn:** Expansion

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | host + capability cần (memory · skill · subagent · hooks · MCP) |
| **Đầu ra** | `choice ∈ host-native · eso-native · external · none` + lý do |
| **Luật** | `MET-05` (host thiếu ⇒ **ghi `none`**, không giả vờ) |
| **Trạng thái** | đã chọn · `none` |

## 2. Xử lý

1. Đọc khai báo năng lực **thật** của host (đo được, không đoán từ tên host).
2. Thứ tự: `host-native` → `eso-native` → `external` → **`none`**.
3. Ghi lựa chọn + `reason`; nếu `none` ⇒ ghi rõ *"host không cấp"* (không im lặng).
4. Không tự cài thêm harness vào host ở Expansion (P1: không phải host nào cũng có).

## 3. Từ chối

| Mã | Khi |
|---|---|
| `UNKNOWN_CAPABILITY` | capability không có trong danh mục |
| `INVALID_TASK` | host không khai được năng lực |

## 4. Dữ liệu chạm

`host_capability` (theo consumer) + event `capability_selected`.

## 5. Phi chức năng

- Cùng capability, host khác ⇒ kết quả khác là **đúng**.
- Không ghi "native" khi chưa đo.
