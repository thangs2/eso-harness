# FRD `F-01` — Control plane UI

**Trace:** `B-00` · `P4` · `P7` → `G-M` → `D5` → `UC-01` · `UC-03` · `BR-05`
**Actor:** A-01 (operator) · **Giai đoạn:** GĐ1

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | operator mở UI trên `127.0.0.1:4200`; credential ở `sessionStorage` |
| **Đầu ra** | màn hình: đăng nhập · danh sách consumer · wizard đăng ký · chi tiết consumer |
| **Luật** | `BR-05` (chỉ người) · `BR-06` (trạng thái hiển thị đúng) |
| **Trạng thái màn** | `loading` · `empty` · `error` · `denied` — không có màn "bịa số" |

## 2. Xử lý

1. Chưa có credential → hiện form đăng nhập; đăng nhập đúng → lưu Basic vào `sessionStorage`, gọi `/api/v1/auth/me`.
2. Danh sách: gọi `GET /api/v1/consumers`; mặc định **ẩn `deleted`**; có filter theo `status`.
3. Wizard đăng ký: id · name · root (chọn thư mục) · sdlcRoot · ghi chú; nút "đăng ký" gọi `POST /api/v1/consumers`.
4. Chi tiết: hiện id · status · version · root · lần cập nhật; nút theo trạng thái: sửa · retire/reactivate · soft delete/restore · purge · **kiểm drift**.
5. Mọi lỗi API hiển thị **mã lỗi + thông điệp** từ server, không tự diễn giải.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `AUTH_REQUIRED` | chưa đăng nhập |
| `AUTH_INVALID` | sai credential |
| lỗi server khác | hiện nguyên văn, không nuốt |

## 4. Dữ liệu chạm

- Đọc/ghi qua API; UI **không** truy cập DB, không đọc file.
- Không lưu credential ở `localStorage`.

## 5. Phi chức năng

- Không hardcode base URL: đọc runtime config (mặc định `http://127.0.0.1:8787`).
- Không hiển thị số liệu không có nguồn (BR-12).
- GĐ1 tối thiểu: S1 (work) · S2 (why) · S5 (audit) — xem OPEN.
