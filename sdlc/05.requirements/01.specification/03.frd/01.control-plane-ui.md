# FRD `F-01` — Control plane UI

**Trace:** `B-00` · `P4` · `P7` → `G-M` → `D5` → `UC-01` · `UC-03` · `BR-05`
**Actor:** A-01 (operator) · **Giai đoạn:** baseline

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | operator mở UI trên `127.0.0.1:4200`; credential ở `sessionStorage` |
| **Đầu ra** | màn hình: đăng nhập · danh sách consumer · wizard đăng ký · chi tiết consumer |
| **Luật** | `BR-05` (chỉ người) · `BR-06` (trạng thái hiển thị đúng) |
| **Trạng thái màn** | `loading` · `empty` · `error` · `denied` — không có màn "bịa số" |

## 2. Xử lý

1. Chưa có credential → hiện form đăng nhập; đăng nhập đúng → lưu Basic vào `sessionStorage`, gọi `/api/v1/auth/me`.
2. Danh sách: gọi `GET /api/v1/consumers`; mặc định **ẩn `deleted`**; có filter theo `status`.
3. Wizard đăng ký: id · name · root (chọn thư mục) · sdlcRoot · ghi chú; nút "đăng ký" gọi `POST /api/v1/consumers`.
4. Chi tiết: hiện id · status · version · root · lần cập nhật; nút theo trạng thái: sửa · retire/reactivate · soft delete/restore · purge · **kiểm drift**.
5. Mọi lỗi API hiển thị **mã lỗi + thông điệp** từ server, không tự diễn giải.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `AUTH_REQUIRED` | chưa đăng nhập |
| `AUTH_INVALID` | sai credential |
| lỗi server khác | hiện nguyên văn, không nuốt |

## 4. Dữ liệu chạm

- Đọc/ghi qua API; UI **không** truy cập DB, không đọc file.
- Không lưu credential ở `localStorage`.

## 5. Phi chức năng

- Không hardcode base URL: đọc runtime config (mặc định `http://127.0.0.1:8787`).
- Không hiển thị số liệu không có nguồn (BR-12).
- baseline tối thiểu: S1 (work) · S2 (why) · S5 (audit) — xem OPEN.

## 7. Bề mặt `/consumers` — `PAGE-CONS`

> **Ranh giới:** surface này là UI của `F-01` (`REQ-15`); hành vi danh sách/lọc thuộc `F-03` (`REQ-04`) — cùng một page, hai năng lực khác nhau.

**Chain:** US-04 · AC-04-4…7 · SCN-04 · RTM-CON-01

> Bề mặt của **cùng** `F-01`; không phải F mới (luật phòng *mỗi `F` một file*). Mã lỗi định nghĩa ở SRS `04` §6;
> tiêu chí ở `AC-04-4…7`; bề mặt UI ở [`02.consumers`](../../../08.ui-design/20.pages/02.consumers.md).

| | |
|---|---|
| **Actor** | `A-01` operator |
| **Đầu vào** | danh sách consumer đã tải (`GET /consumers`, ẩn `deleted`/`purged` theo `BR-06`) |
| **Đầu ra** | 3 số tổng quan · bảng consumer · lối vào tạo mới / chi tiết / event |
| **Trạng thái** | `loading` · `empty` (chưa có) · `empty` (bộ lọc không khớp) · `error` |

**Xử lý**

1. Tải danh sách một lần; sắp theo `updatedAt` giảm dần (server đã sắp).
2. Hiện 3 số: **tổng consumer** · **số `ready`** · **lần cập nhật gần nhất** — tất cả tính từ danh sách đã tải, không gọi thêm.
3. **Lọc theo `status` phía client** (`all` / `ready` / `retired`) trên danh sách đã tải; không gọi lại server (trang không phân trang).
4. Bảng 6 cột: consumer (name + id) · repo (`root`) · status · version · updated · hành động.
5. Mỗi dòng có 2 lối: **Details** → `/consumers/:id` · **Events** → `/events?consumer=:id`.
6. `Create consumer` → `/setup` (không mở wizard trong trang này).
7. Lỗi: hiện **mã + message**; `401/403` ⇒ `CONS_DENIED`, còn lại ⇒ `CONS_UPSTREAM_FAILED`.

**Không làm:** phân trang · sort tuỳ chọn · sửa/xoá consumer · đổi trạng thái · ước lượng "đủ/thiếu" trên UI.
