# FRD `F-24` — Tự nâng skill có duyệt

**Trace:** `P5` → `G-F` → `MET-06` · `BR-05`
**Actor:** A-02 (đề xuất) · A-01 (duyệt) · **Giai đoạn:** GĐ2

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `proposal = { skill, diff, reason, expected_effect }` |
| **Đầu ra** | skill mới **chỉ sau khi người duyệt**; kèm bản ghi đo trước/sau |
| **Luật** | `BR-05` · `MET-06` (defect_rate không tăng) |
| **Trạng thái** | `proposed` · `approved` · `applied` · `rejected` · `rolled_back` |

## 2. Xử lý

1. Agent chỉ được **đề xuất**; không tự ghi skill.
2. Người duyệt xem diff + lý do + tác động dự kiến; `approved` mới apply.
3. Sau apply: đo lại cửa sổ (defect rate, gate pass) so trước.
4. Nếu kém hơn ⇒ `rolled_back` + ghi lý do.
5. Mọi bước ghi event (ai duyệt, khi nào, diff hash).

## 3. Từ chối

| Mã | Khi |
|---|---|
| `NEEDS_APPROVAL` | agent cố apply/duyệt |
| `FORBIDDEN_ACTOR` | actor không có quyền duyệt skill |
| `INVALID_STATE` | apply khi chưa approved, hoặc rollback khi chưa applied |

## 4. Dữ liệu chạm

`skill_change` + `skill_apply` + event; skill file trong repo consumer (chỉ khi approved).

## 5. Phi chức năng

- Không có "tự học" ngầm: mọi thay đổi skill phải có bản ghi duyệt.
- MET-06: defect_rate không tăng sau khi áp.
