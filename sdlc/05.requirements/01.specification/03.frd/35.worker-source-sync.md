# FRD `F-40` — Worker source sync

**Trace:** `P1` · `P7` → `G-U` → `BR-45` · `BR-23` · `BR-24`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · `D16`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `agents/subagents/*.md`; `.agents/agents/*.md` projection |
| **Đầu ra** | source/projection counts; drift list; reindexed worker index |
| **Luật** | `BR-45` (một chiều), `BR-23` (canonical state), `BR-24` (projection generated) |
| **Trạng thái** | in sync · drift · missing projection · orphan projection |

## 2. Luồng

1. **Status**: so hash source với projection.
2. **Sync sources**: rebuild worker index từ files; flow không đổi.
3. **Drift**: hiện file + kind.
4. **Promote**: copy một chiều projection → source; reindex.
5. **Discard**: khôi phục projection từ generator; không ghi source.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `SYNC_DRIFT` | projection khác source |
| `PROJECTION_CONFLICT` | projection không có marker ESO |
| `NOT_A_PROJECTION` | file không phải projection |
| `PROJECTION_NOT_FOUND` | promote file không tồn tại |
| `WORKER_INVALID` | source parse lỗi |

## 4. Dữ liệu chạm

```text
agents/subagents/*.md
.agents/agents/*.md
.cursor/agents/*.md
knowledge_worker
```

## 5. Phi chức năng

- Không sync hai chiều.
- Không tự overwrite source.
- Không watcher nền; sync là explicit.

| | |
|---|---|
| **Actor** | `A-01` operator |

| **Đầu ra** | counts source/projection · drift list · index rebuild |
| **Trạng thái** | in sync · drift · missing projection · orphan projection |

**Xử lý**

1. Hiện counts + trạng thái sync; lệch ⇒ drift list (file + kind).
2. `Sync sources` ⇒ rebuild worker index; **flow không đổi**.
3. `Promote` một projection → source (một chiều) rồi reindex.
4. Không tự xoá source; không sửa flow.
5. Lỗi hiện **mã + message**.

**Hiển thị (từ code):** summary `n source files · n projections`; không drift ⇒ `In sync`; có drift ⇒ badge `n external changes` + list `file · kind`; chỉ `projection_changed` mới có nút `Promote`; `Loading…` khi đang tải (`ws:22-40`).
