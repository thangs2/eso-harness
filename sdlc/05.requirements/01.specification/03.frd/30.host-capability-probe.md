# FRD `F-30` — Host capability probe

**Trace:** `P1` → `G-C` → `BR-22`
**Actor:** A-05 (host) · A-01 (chạy) · **Giai đoạn:** Expansion

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `host.id` + `host.version` + quyền chạy probe |
| **Đầu ra** | `host-capability.json` + evidence; level `L0…L4` theo 6 chiều |
| **Luật** | `BR-22` (đo, không suy từ docs) |
| **Trạng thái** | measured · partial · unknown |

## 2. Sáu chiều

| Chiều | Đo gì |
|---|---|
| observe | session/prompt/turn/tool events |
| inject | rules/skills/system context |
| memory read | đọc memory cross-session |
| memory write | ghi memory + đọc lại |
| mcp/tools | MCP client/server, tool visibility |
| multi-agent/remote/CI | subagent, headless, remote |

## 3. Level

```text
L0 none
L1 observe session/prompt/turn
L2 L1 + inject context
L3 L2 + memory read
L4 L3 + memory write + cross-session retrieval
```

## 4. Xử lý

1. Cài probe adapter/plugin; chỉ ghi event, không ghi secret.
2. Chạy scripted session: start → prompt → tool → file edit → end.
3. Mở session mới, thử đọc memory/context.
4. Chạy headless/CI nếu host hỗ trợ.
5. Xuất card + evidence path; publish cho UI/source matrix.

## 5. Từ chối

| Mã | Khi |
|---|---|
| `UNSUPPORTED_HOST` | host ngoài danh mục |
| `PROBE_BLOCKED` | thiếu quyền/chính sách chặn |
| `INSUFFICIENT_EVIDENCE` | probe chạy nhưng không đủ để kết luận (ghi `unknown`) |

## 6. Dữ liệu chạm

`host-capability.json` + evidence; bảng/artifact `host_capability` khi persist.

## 7. Phi chức năng

- Không lưu secret; evidence tối thiểu.
- Card có host version + ngày probe; version đổi ⇒ probe lại.
- UI không bật source nếu level chưa đo.
