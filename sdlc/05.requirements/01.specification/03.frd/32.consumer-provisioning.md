# FRD `F-32` — Consumer provisioning

**Trace:** `P3` · `P7` → `G-R` → `BR-26` · `BR-28` · `BR-29` · `BR-30`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · `D3`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | consumer id + root + material options |
| **Đầu ra** | schema `c_<id>` + bảng nền · material bundle · setup info read-back |
| **Luật** | `BR-26/28/29/30` · `D-125` schema-expanded |
| **Trạng thái** | provisioned · partial · error |

## 2. Material bundle

```text
AGENTS.md
agents/        (rules · skills · hooks · mcp · subagents)
.harness/config.json
.harness/manifest.json
schema c_<id> + bảng nền
setup metadata
```

## 3. Xử lý

1. Validate consumer tồn tại/ready; root tồn tại; id khớp.
2. Tạo/verify schema `c_<id>` + bảng nền; idempotent.
3. Ghi material bundle: file/folder thiếu tạo; file ESO-owned hash lệch ⇒ conflict.
4. Persist setup info: consumer id, schema, material version, hash, status.
5. Read-back: trả trạng thái provision.
6. Lỗi ⇒ `status=error`, giữ phần đã ghi; retry idempotent.

## 4. Từ chối

| Mã | Khi |
|---|---|
| `CONSUMER_NOT_FOUND` | consumer không tồn tại |
| `INVALID_STATE` | không `ready` |
| `ROOT_NOT_FOUND` | root thiếu |
| `SCHEMA_MISMATCH` | `c_<id>` khác consumer |
| `MATERIAL_FAILED` | ghi material lỗi |
| `SETUP_INFO_MISSING` | không persist/read-back được |
| `PROVISION_FAILED` | lỗi transaction/tổng hợp |

## 5. Dữ liệu chạm

`platform.consumer` · schema `c_<id>` · `AGENTS.md` · `agents/**` · `.harness/**` · setup metadata.

## 6. Phi chức năng

- Idempotent; chạy lại không duplicate.
- Schema-expanded; không shared schema, không database riêng.
- Không ghi đè file người dùng ngoài marker/hash.
- Không host projection (F-33).

## 7. OPEN

Không còn OPEN. Bảng nền và setup metadata thuộc spec đã chốt; implementation theo `AC-40-1`.
