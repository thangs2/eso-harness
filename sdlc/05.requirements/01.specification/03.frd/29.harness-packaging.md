# FRD `F-29` — Harness adapter packaging

**Trace:** `P1` · `P2` → `G-C` · `G-P` → `BR-22`
**Actor:** A-05 (host) · A-01 (cài/kiểm) · **Giai đoạn:** Expansion

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | host id + version + adapter manifest |
| **Đầu ra** | package `eso/harness/...` + capability manifest + conformance result |
| **Luật** | `BR-22` (capability phải đo) |
| **Trạng thái** | build được · không build được |

## 2. Xử lý

1. Kiểm host thuộc danh mục `cursor · antigravity · claude · codex · dsh · paseo · orca`.
2. Build `core` host-agnostic; adapter chỉ capture/inject/capability.
3. Manifest khai host, version, capability, entrypoint; thiếu ⇒ fail.
4. Chạy conformance suite chung cho adapter; không đạt ⇒ fail.
5. Publish package + capability card (từ F-30).

## 3. Cấu trúc bắt buộc

```text
eso/harness/
├── protocol/
├── core/
├── adapters/{cursor,antigravity,claude,codex,dsh,paseo,orca}/
└── manifests/
```

## 4. Từ chối

| Mã | Khi |
|---|---|
| `UNSUPPORTED_HOST` | host ngoài danh mục |
| `MISSING_MANIFEST` | thiếu manifest/entrypoint/capability |
| `CONFORMANCE_FAILED` | adapter không đạt suite |
| `VERSION_MISMATCH` | manifest không khớp protocol/core |

## 5. Dữ liệu chạm

Package + manifest dưới `eso/harness/`; không ghi DB.

## 6. Phi chức năng

- `core` không import host SDK; kiểm bằng lint/architecture test.
- Cùng protocol version cho mọi adapter; bump version khi breaking.
- Paseo/Orca là orchestrator adapter, không phải harness source.
