# FRD `F-23` — Host parity

**Trace:** `P1` → `G-P` → `MET-20`
**Actor:** A-05 · A-01 · **Giai đoạn:** GĐ2

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | cùng một task, chạy trên 2 host: có harness native và không có |
| **Đầu ra** | bảng so sánh: phần giống · phần khác · phần `none` |
| **Luật** | `MET-20` (parity 100% hành vi thiết yếu) |
| **Trạng thái** | parity · khác biệt có lý do · thiếu năng lực |

## 2. Xử lý

1. Chạy cùng kịch bản trên 2 host; ghi kết quả từng bước.
2. So **hành vi thiết yếu** (verdict · evidence · scope); khác biệt phải có lý do (`none` do host thiếu).
3. Khác biệt **không** có lý do ⇒ finding parity.
4. Trả báo cáo diff; không sửa host.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `UNKNOWN_CAPABILITY` | host không khai đủ để so |
| `INVALID_TASK` | kịch bản không chạy được trên host |

## 4. Dữ liệu chạm

Kết quả chạy (evidence) + báo cáo parity; read-only với host.

## 5. Phi chức năng

- Kịch bản phải **tái lập**: mỗi lần chạy cho cùng cấu trúc báo cáo.
- Không hạ chuẩn để "cho giống": khác biệt do thiếu năng lực phải hiện.
