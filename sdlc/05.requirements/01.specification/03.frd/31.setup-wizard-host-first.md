# FRD `F-31` — Host-first setup wizard

**Trace:** `P4` → `G-M` → `BR-05` · `BR-21`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · `D5`

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | host · harness source · consumer (`id/name/root/sdlcRoot`) · observation consent |
| **Đầu ra** | preview + profile snapshot + materialized `.harness/config.json` |
| **Luật** | `BR-05` (người quyết) · `BR-21` (provenance) |
| **Trạng thái** | draft · preview · applied · error |

## 2. Sáu bước

| Bước | Nội dung |
|---|---|
| 1 | **Host + connection**: chọn host; cài/kết nối harness layer; probe capability |
| 2 | **Harness source**: chỉ hiện source khả dụng (`market` · `eso-native` · `host-native`) |
| 3 | **Consumer**: `id` · `name` · `root` · `sdlcRoot` |
| 4 | **Observation + consent**: event kinds, redaction, retention |
| 5 | **Preview**: profile + endpoint + quyền; không ghi file |
| 6 | **Apply**: F-02 + F-05; ghi event audit |

## 3. Quy tắc

1. **Host-first**: source khả dụng phụ thuộc host; source-first bị loại.
2. Không field `tier/recipe/hostPack/memoryAdapter`.
3. `eso-native` chưa build ⇒ disable + lý do; không giả chạy.
4. Preview bắt buộc trước apply.
5. Không tự tạo schema/không gọi DB ở UI; server quyết.

## 4. Từ chối

| Mã | Khi |
|---|---|
| `HOST_UNSUPPORTED` | host ngoài danh mục |
| `SOURCE_INCOMPATIBLE` | source không hợp host/capability |
| `SOURCE_NOT_AVAILABLE` | source chưa build (eso-native) |
| `INVALID_CONSUMER` | id/root/slug sai |
| `PREVIEW_REQUIRED` | apply khi chưa preview |

## 5. Dữ liệu chạm

Profile snapshot + `config.json` + `platform.consumer_event`.

## 6. Phi chức năng

- Wizard v1 `/onboarding` đã xoá; F-01 baseline giữ 4 field tới khi `D13` mở.
- Không hiển thị option không đo được (BR-22).
- Mọi lỗi hiển thị mã + message từ server.
