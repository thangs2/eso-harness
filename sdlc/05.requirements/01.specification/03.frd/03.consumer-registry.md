# FRD `F-03` — Registry consumer

**Trace:** `B-00` → `G-L` → `D3` → `UC-03` · `UC-04` · `BR-09`
**Actor:** A-01 · **Giai đoạn:** baseline

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `GET /api/v1/consumers` (filter `status`, `include_deleted`) · `GET /api/v1/consumers/<id>` · `PUT /api/v1/consumers/<id>` (body profile + `expected_version`) |
| **Đầu ra** | danh sách/chi tiết record; update trả `version+1` |
| **Luật** | `BR-09` (optimistic lock) · `BR-06` (ẩn `deleted` mặc định) |

## 2. Xử lý

1. List: đọc `platform.consumer`; mặc định loại `deleted` và `purged`; `retired` vẫn hiện; sắp theo `updated_at` giảm dần.
2. Detail: trả toàn bộ trường + `profile` + `materialized_hash`; không trả credential/DSN.
3. Update:
   1. kiểm `expected_version` = `version` hiện tại, nếu khác ⇒ `409 STALE_VERSION`;
   2. validate body như F-02 (trừ `id`);
   3. update trong transaction: `version+1`, `updated_at`, ghi event `updated`;
   4. materialize lại file + cập nhật hash (F-05).
4. Không có endpoint xoá cứng; xoá thuộc F-04.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `CONSUMER_NOT_FOUND` | id không tồn tại / `retired` / `deleted` (cùng thông điệp) |
| `STALE_VERSION` | `expected_version` khác hiện tại |
| `MATERIALIZE_FAILED` | ghi file lỗi sau commit |

## 4. Dữ liệu chạm

`platform.consumer` (read/update) · `platform.consumer_event` (`updated`) · `<root>/.harness/config.json`.

## 5. Phi chức năng

- Update là **idempotent theo version**: gửi lại cùng `expected_version` sau khi thành công ⇒ `STALE_VERSION`.
- Hai tab sửa cùng lúc: một thắng, một `STALE_VERSION` — không mất thay đổi im lặng.
- `id` bất biến; nếu body có `id` khác ⇒ `400 INVALID_CONSUMER_ID`.

## 6. OPEN

| id | Câu hỏi |
|---|---|
| `O-F03` | List có cần phân trang ở baseline (5–10 consumer/năm ⇒ có thể không)? |
| `O-F03b` | Có cho sửa `root` qua update hay phải là API riêng (đổi root kéo theo materialize ở chỗ mới)? |

## 8. Bề mặt `/consumers/:id/settings?tab=profile` — `PAGE-SETTINGS-PROFILE`

> Cùng `F-03` (update record) + `F-05` (materialize). Bản đồ 7 tab: [`20.pages/00.index`](../../../08.ui-design/20.pages/00.index.md).
> Cấu trúc code (chốt 2026-11-23, commit `44374c8`): `settings-core/base` + `settings-{stack,hosts,tail}.base.ts` + component theo tab (`profile-panel`, `stack-tab`, …).

| | |
|---|---|
| **Actor** | `A-01` operator |
| **Đầu vào** | consumer `:id` · form các trường profile hiện có |
| **Đầu ra** | `PUT /consumers/{id}` → `version+1`; file `<root>/.harness/config.json` materialize lại + `materialized_hash` |
| **Luật** | `BR-03` (DB là nguồn) · `BR-04` (drift phải phát hiện) · `BR-09` (optimistic lock) |

**Xử lý**

1. Mở tab `profile` = tab 1/7; nạp record hiện tại; `version` hiển thị cạnh tiêu đề.
2. Sửa trường ⇒ `dirty`; `Save changes` disabled khi không dirty.
3. Save gửi update kèm `expected_version` = version đang hiện.
4. Server trả `version+1` ⇒ nạp lại record; banner "saved".
5. `409 STALE_VERSION` ⇒ **không** ghi đè; hiện mã + message; người dùng nạp lại rồi sửa lại.
6. `id` bất biến: form không cho sửa `id`.
7. Trường sửa được của tab: `name` · `owner` · `locale` · `tags` · `description`.
8. Lỗi: hiện **mã + message** — `PROFILE_STALE_VERSION` (409) · `PROFILE_DENIED` (401/403) · `PROFILE_UPSTREAM_FAILED` (5xx/network) · `PROFILE_JEV_NEEDS_CONSENT` · `PROFILE_JEV_THRESHOLD` (validate client).

**Không làm:** đổi `root` tại đây (thuộc `F-03` `OPEN` `O-F03b`) · xoá/retire (`F-04`) · sửa file tay (file là artifact sinh ra).

## 7. Bề mặt `/consumers/:id` — `PAGE-DETAIL`

> Cùng `F-03`; mã lỗi ở SRS `04` §6; tiêu chí `AC-05-4…6`; UI [`04.consumer-detail`](../../../08.ui-design/20.pages/04.consumer-detail.md).

| | |
|---|---|
| **Actor** | `A-01` operator |
| **Đầu vào** | `:id` trên URL · tuỳ chọn `?created=1` (vừa tạo từ `/setup`) |
| **Đầu ra** | 4 panel read-only: Profile · Knowledge base · Team & gates · Protected paths |
| **Trạng thái** | `loading` · `ready` · `created` (banner) · `error` |

**Xử lý**

1. Đọc `:id` từ route; tải chi tiết một lần.
2. `?created=1` ⇒ hiện banner "Consumer saved…"; không có ⇒ không hiện.
3. Panel **Profile**: canonical (agents/harness) hoặc host fallback · source policy · description · version + status.
4. Panel **Knowledge base**: sdlcRoot · headerProfile · presetVersion · danh sách zone.
5. Panel **Team & gates**: roles · gates bật · sources bật (chỉ hiện key `true`).
6. Panel **Protected paths**: danh sách path hoặc "No protected paths configured".
7. `Open settings` → `/consumers/:id/settings`.
8. Lỗi: **mã + message**; `404` ⇒ `DETAIL_NOT_FOUND`, `401/403` ⇒ `DETAIL_DENIED`, còn lại ⇒ `DETAIL_UPSTREAM_FAILED`.

**Không làm:** sửa trường trên trang này · xoá/retire (thuộc F-04, chưa có UI) · hiện credential/DSN.
