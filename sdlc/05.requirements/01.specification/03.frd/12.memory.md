# FRD `F-12` — Memory native của ESO

**Trace:** `P1` · `P4` → `G-E` → `MET-09`
**Actor:** A-02 · A-03 (ghi qua hook) · **Giai đoạn:** Expansion

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `fact = { key?, text, source, actor, scope }` |
| **Đầu ra** | fact được lưu trong schema consumer; đọc lại được ở turn sau |
| **Luật** | `BR-05` (chỉ người duyệt tri thức bền) · `BR-16` (không bịa nguồn) |
| **Trạng thái** | `proposed` · `approved` · `rejected` |

## 2. Xử lý

1. Ghi fact ở trạng thái `proposed` (kể cả agent đề xuất).
2. Người duyệt: `approved` ⇒ fact bền, đọc được; `rejected` ⇒ giữ record nhưng không dùng.
3. Đọc: trả fact `approved` khớp scope; nêu `source` + `at`.
4. Ghi trùng (gần trùng) ⇒ cảnh báo, không tự nhập.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `NEEDS_APPROVAL` | fact chưa duyệt mà caller đòi dùng như tri thức bền |
| `NEAR_DUPLICATE` | đã có fact gần trùng |

## 4. Dữ liệu chạm

Bảng `memory_fact` (+ `memory_source`) trong schema `c_<id>`.

## 5. Phi chức năng

- Fact phải **đọc lại được** (MET-09 = 100%).
- Agent không được tự `approved` (F-25).
