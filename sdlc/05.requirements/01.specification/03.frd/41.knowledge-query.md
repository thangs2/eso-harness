# `41` — Knowledge query (`F-38`)

**Luật:** `BR-17` (index phải phản ánh nguồn) · `BR-12` (số phải có nguồn đo)

**Chain:** US-57 · AC-57-1…3 · SCN-57 · RTM-KNOWLEDGE-QUERY-01

| | |
|---|---|
| **REQ** | `REQ-53` |
| **Actor** | A-01 |
| **Endpoint** | `POST /api/v1/consumers/{id}/knowledge/retrieve` |
| **UI** | tab knowledge → khối `Hybrid retrieval` (`knowledge-tab:70-89`) |

## 1. Đặc tả

Query trả tối đa `limit` kết quả, mỗi kết quả có `doc_id` · `path` · `why` (provenance) · `rrf` (điểm tổng hợp) + cờ nguồn `fts`/`graph`/`vector`.

## 2. Xử lý

1. Chuẩn hoá query; nếu vector tắt ⇒ trả `reason` và vẫn chạy FTS/graph.
2. Hợp nhất theo **RRF**; sắp giảm dần.
3. Không có kết quả ⇒ mảng rỗng + `empty` message ở UI.
4. Chỉ doc thuộc schema `c_<id>`.

## 3. Từ chối

`CONSUMER_NOT_FOUND` (404) · `KNOWLEDGE_DISABLED` (chưa bật index) · query rỗng ⇒ `INVALID_STATE`.

## 4. Dữ liệu chạm

`knowledge_doc` · `knowledge_doc_chunk` · `knowledge_edge` (graph) · `knowledge_doc_search` (FTS) — [`29`](../../../07.technical/02.data-design/29.consumer-schema.md).

## 5. Phi chức năng

`limit` mặc định 20, tối đa 100; trả trong 1 request; không embeddings call tại chỗ.

## 6. Không làm

Không index tại query · không trả nội dung file · không sửa dữ liệu.
