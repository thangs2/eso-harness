# FRD `F-25` — Authority (ai được quyết định)

**Trace:** `P5` · `P6` → `G-O` → `MET-19` · `BR-05`
**Actor:** A-01 (người) · mọi actor khác · **Giai đoạn:** GĐ2

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | `(actor, action)` — action thuộc: duyệt tri thức · `Done` · bypass · đổi ngưỡng · purge · apply skill |
| **Đầu ra** | `allowed` hoặc `denied` + lý do |
| **Luật** | `BR-05` (chỉ người) · `MET-19` (0 vi phạm) |
| **Trạng thái** | allowed · denied |

## 2. Xử lý

1. Tra bảng thẩm quyền (BRD `03` §3) theo `actor_kind` + `role`.
2. `actor_kind = machine` ⇒ **deny** các action thuộc người (duyệt · `Done` · bypass · đổi ngưỡng), kể cả khi prompt xin.
3. Deny ⇒ trả mã + ghi event `authority_denied`; không "thử lại bằng đường khác".
4. Bypass của operator ⇒ cho phép nhưng **bắt buộc** ghi lý do + audit.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `FORBIDDEN_ACTOR` | actor không có quyền với action |
| `UNKNOWN_ACTOR` | không xác định được actor |
| `NEEDS_APPROVAL` | action cần người nhưng chưa có |

## 4. Dữ liệu chạm

`authority_decision` + event; đọc role/policy.

## 5. Phi chức năng

- Cùng action, actor khác ⇒ kết quả khác là **đúng**.
- Không có ngoại lệ "agent tự động vì tiện".
