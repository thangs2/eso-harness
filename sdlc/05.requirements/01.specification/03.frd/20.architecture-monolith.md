# FRD `F-20` — Kiến trúc monolith

**Trace:** `P2` → `G-B1` → `MET-03` · `MET-04` · `BR-16`
**Actor:** A-01 · A-02 · **Giai đoạn:** GĐ2 (sớm)

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | repo monolith (module · import graph · entrypoint) |
| **Đầu ra** | trả lời câu hỏi kiến trúc: *"đổi module X chạm ai"* · vòng phụ thuộc · blast radius |
| **Luật** | `BR-16` (derived ⊆ source) · `MET-03` (5/5 câu × 3 project) |
| **Trạng thái** | trả lời được · không đủ dữ liệu |

## 2. Xử lý

1. Dựng graph module từ import/require (không đoán từ tên file).
2. Với mỗi câu hỏi: trả lời kèm **đường dẫn chứng** (file:line) trong source.
3. Phát hiện vòng phụ thuộc; nêu module nằm trong vòng.
4. Không đủ dữ liệu (dynamic import không phân giải) ⇒ nêu `unknown`, không bịa.
5. `derived` không thêm khẳng định ngoài nguồn.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `DOC_CONTRACT_VIOLATION` | câu trả lời không dẫn xuất được từ graph |
| `INVALID_TASK` | câu hỏi không thuộc bộ câu hỏi kiến trúc |

## 4. Dữ liệu chạm

Đọc repo consumer (read-only) + graph index cục bộ; không sửa source.

## 5. Phi chức năng

- p95 phán quyết trên graph ấm ≤ 800 ms (MET-04).
- Không đọc cả repo mỗi lần: dùng graph index (cập nhật theo commit).
