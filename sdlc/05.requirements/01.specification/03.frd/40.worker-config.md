# FRD `F-45` — Worker configuration

**Trace:** `P1` · `P7` → `G-U` → `BR-49` · `BR-23`
**Actor:** A-01 operator · **Giai đoạn:** Phase 1 · chưa có quyết định riêng (`OPEN-F45-DECISION`)

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | consumer `:id` · danh sách agent file (`agents/subagents/*.md`) · role/layer/status · placement (runtime + model) |
| **Đầu ra** | worker dir đã lưu; placement theo runtime; audit import |
| **Luật** | `BR-49` (canonical + preview/audit) · `BR-23` (canonical state) |
| **Trạng thái** | empty · ready · dirty · importing · saving · error |

## 2. Xử lý

1. Đọc worker dir (`GET .../workers`) + placement (`GET .../worker-placement`).
2. Sửa identity: `name` · `role` · `layer` (`peer`/`gate`) · `status` (`declared`/`active`/`paused`/`retired`) · `prompt body`.
3. Placement: danh sách runtime được phép + model mỗi runtime; model rỗng ⇒ dùng tier.
4. `Save changes` ⇒ `PUT .../workers` (toàn bộ config) + lưu placement từng worker (`PUT .../workers/{workerId}/placement`).
5. Import agent file: `preview` trước (nêu `candidates`/`skipped`), áp dụng sau xác nhận, ghi audit (`/workers/import/audit`).
6. Policy check (nếu bật): trả `allow/deny` + lý do cho một hành động.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `WORKER_INVALID` | id/role/layer/status ngoài danh mục, hoặc id trùng |
| `WORKER_IMPORT_CONFLICT` | import khi chưa xác nhận/preview |
| `WORKER_POLICY_DENIED` | policy check từ chối hành động |
| `WORKER_CONFIG_DENIED` | 401/403 |
| `WORKER_CONFIG_FAILED` | 5xx/network |

## 4. Dữ liệu chạm

`agents/subagents/*.md` (canonical) · `.agents/agents/*.md` (projection, không sửa tay) · `knowledge_worker*` · `knowledge_worker_placement` · `knowledge_worker_host_policy`.

## 5. Phi chức năng

- Import idempotent theo danh sách file; file `skipped` phải nêu lý do.
- Không tạo worker rỗng; không xoá worker đang `active` mà không đổi status trước.
- Placement chỉ trỏ runtime đã đăng ký (F-30/F-33).

### 8.2 Hiển thị

### 8.4 Lỗi
