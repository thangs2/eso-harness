# FRD `F-07` — Operator auth

**Trace:** `P5` → `G-O` → `D2` → `UC-01` · `BR-05`
**Actor:** A-01 (Basic) · máy (Bearer) · **Giai đoạn:** baseline

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | header `Authorization: Basic <base64(user:pass)>` (UI) hoặc `Bearer <token>` (CLI/proxy) |
| **Đầu ra** | request được xử lý; hoặc `401` kèm mã lỗi |
| **Nguồn credential** | file `eso/.env` — `ESO_AUTH_USER` · `ESO_AUTH_PASSWORD` · `ESO_API_TOKEN` |
| **Luật** | `BR-05` (chỉ người được quyết định) · không account trong DB |

## 2. Xử lý

1. Khởi động: đọc `.env`; thiếu biến ⇒ **không khởi động** (fail fast, log rõ biến thiếu).
2. Mỗi request:
   - có `Basic` ⇒ so `user`/`pass` với env (so sánh constant-time);
   - có `Bearer` ⇒ so token với `ESO_API_TOKEN`;
   - không có / sai ⇒ `401` + mã lỗi; không tiết lộ hướng dẫn.
3. `GET /api/v1/auth/me` ⇒ trả `{ kind: 'operator' | 'machine', configured: true }` (không trả credential).
4. CORS: chỉ cho origin của UI (`http://127.0.0.1:4200`, `http://localhost:4200`); methods `GET,POST,PUT,DELETE,OPTIONS`.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `AUTH_REQUIRED` | không có header |
| `AUTH_INVALID` | sai user/pass/token |
| `AUTH_NOT_CONFIGURED` | `.env` thiếu biến (server từ chối khởi động, không nhận request) |

## 4. Dữ liệu chạm

Không chạm DB. Đọc `eso/.env` một lần lúc khởi động (không đọc lại mỗi request).

## 5. Phi chức năng

- **Không** log credential, không trả credential trong response/error.
- **Không** cookie, **không** session server-side ở baseline; UI giữ Basic trong `sessionStorage` và gửi mỗi request.
- Plaintext trong `.env` là **chấp nhận có chủ ý** (local-only, `D-111`); `.env` phải gitignored.
- Đổi credential = sửa `.env` + restart server.
