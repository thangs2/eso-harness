# FRD `F-14` — Inventory artifact

**Trace:** `P7` → `G-G` → `MET-10` · `MET-11`
**Actor:** A-01 · A-04 · A-08 · **Giai đoạn:** Expansion

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | KB của consumer + template `kind` của dự án |
| **Đầu ra** | `inventory = { kind, path, owner, instance_count, status }` |
| **Luật** | `BR-17` (đủ theo template) · `BR-18` (nêu cái không thấy) |
| **Trạng thái** | đủ · thiếu kind · mồ côi (không owner) |

## 2. Xử lý

1. Đọc template (danh mục `kind` bắt buộc của consumer).
2. Quét KB: mỗi artifact → `kind`, `path`, `owner` suy từ `kind`.
3. Đếm instance mỗi `kind`; `kind` không có instance ⇒ finding `MISSING_KIND`.
4. Artifact không map được `kind` ⇒ finding "mồ côi".
5. Trả inventory + findings; không sửa KB.

## 3. Từ chối

| Mã | Khi |
|---|---|
| `CONSUMER_NOT_FOUND` | consumer không `ready` |
| `INVALID_TASK` | template không đọc được |

## 4. Dữ liệu chạm

Đọc KB + template; không ghi.

## 5. Phi chức năng

- `owner` **suy được** cho 100% instance (MET-11); nếu không ⇒ finding, không im lặng.
- Kết quả tái lập theo (consumer, commit của KB).

| | |
|---|---|

**Xử lý**

1. Tải `GET .../knowledge/docs` — client **không** truyền `limit`; server cap **50** (max 200) dù copy UI ghi "All rows shown" (`kt:42`, `store:1878`).
2. 4 stat: Documents · Graph edges · Open findings (warn khi >0) · **Embedded chunks x/y** (`ko:15-18`).
3. Header index: `n docs · n edges · n findings` + manifest line + embedding line (`kt:20-25`).
4. `Run check` (preflight) và `Index now` (index lại tài liệu) là **nút** ở overview (`ko:9-10`).
5. Preflight: `status` + `n checks`, `FAIL` nổi bật (`kt:31-38`).
6. Bảng doc **`Document · Type · Status · Sections`**; rỗng ⇒ `No indexed documents yet. Click Index now.` (`kt:49-60`).
7. Findings: khối **ẩn khi 0**, nhưng stat/counter vẫn in `0` (`kt:62`, `ko:17`) — không phải "no findings" text.
8. Hybrid retrieval: `n results · FTS · graph · vector`, lý do khi vector off, bảng `# · Document · Why · RRF`; `Coverage by type` `Type · Docs · Sections · Findings` (`kt:70-104`).
9. Detail doc: Outgoing · Incoming · Transitive (depth) · Sections ≤8 (`kt:105-126`).
10. Lỗi hiện message; không map mã riêng ở tab; không sửa KB từ khối này.
