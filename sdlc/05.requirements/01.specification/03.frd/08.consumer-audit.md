# FRD `F-08` — Audit consumer

**Trace:** `P5` · `P7` → `G-O` → `D4` → `UC-14` · `BR-15`
**Actor:** hệ thống ghi · A-01/A-04 đọc · **Giai đoạn:** Bootstrap

## 1. Đặc tả

| | |
|---|---|
| **Đầu vào** | mọi thay đổi trạng thái/registry của consumer (từ F-02 · F-03 · F-04 · F-05) |
| **Đầu ra** | bản ghi `platform.consumer_event` (append-only) · `GET /api/v1/consumers/<id>/events` |
| **Luật** | `BR-15` (mọi hành động nhạy cảm phải có audit) |

## 2. Bảng `consumer_event`

| Cột | Kiểu | Ghi chú |
|---|---|---|
| `id` | bigserial | |
| `consumer_id` | text | không FK cứng tới consumer (purge vẫn giữ audit) |
| `event_type` | text | `created · updated · retired · reactivated · deleted · restored · purged · materialized · materialize_failed` |
| `actor_kind` | text | `operator` · `machine` · `system` |
| `actor_label` | text | tên từ auth (không lưu credential) |
| `at` | timestamptz | giờ server |
| `detail` | jsonb | `{version, changed: [...], hash, error}` — không chứa credential |

## 3. Xử lý

1. Ghi event **trong cùng transaction** với thay đổi trạng thái/registry (F-02/F-03/F-04).
2. Materialize (F-05) ghi `materialized` hoặc `materialize_failed` sau commit.
3. Đọc: `GET .../events?limit=50` trả mới nhất trước; chỉ đọc, không sửa/xoá.
4. Không có endpoint `PUT/PATCH/DELETE` cho event — kể cả operator.

## 4. Từ chối

| Mã | Khi |
|---|---|
| `CONSUMER_NOT_FOUND` | id không tồn tại (kể cả `purged` ⇒ không có event route) |
| `AUTH_REQUIRED` · `AUTH_INVALID` | chưa đăng nhập |

## 5. Dữ liệu chạm

`platform.consumer_event` (insert/select) · `platform.consumer` (read).

## 6. Phi chức năng

- **Append-only**: không sửa, không xoá; retention chưa giới hạn ở Bootstrap.
- Purge xoá schema + file nhưng **giữ** event + record `purged` ⇒ truy được lịch sử.
- Event không chứa nội dung profile đầy đủ (chỉ diff/hash) để tránh rò dữ liệu.
