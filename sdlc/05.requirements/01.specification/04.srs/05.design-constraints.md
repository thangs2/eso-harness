# `05` — Ràng buộc thiết kế

Ràng buộc là thứ **không chọn khác** ở giai đoạn này. Nguồn: PRD `06` + `D-109…D-116`.

## 1. Ràng buộc kỹ thuật

| id | Ràng buộc | Nguồn | Hệ quả thiết kế |
|---|---|---|---|
| `C-01` | **Postgres only** (không SQLite/Neo4j) | `D-92` · `D-93` | test + runtime dùng Postgres thật |
| `C-02` | **schema-per-consumer**: `platform` + `c_<id>`; `public` trống | `D-110` | mọi query qua `search_path`; không predicate `project` |
| `C-03` | **ba database** `cp`·`ctx`·`graph` khi mở rộng | `D-73` · `D-106` | GĐ1 chỉ `cp`; GĐ2 mở cùng kiểu schema |
| `C-04` | **Node + `pg`**; `bun` chỉ cài/build UI | `D-115` | `PlatformDb` interface; đổi driver không sửa nghiệp vụ |
| `C-05` | **local-only** `127.0.0.1:8787` | `D-111` | không bind mạng; lên B mới HTTPS/proxy |
| `C-06` | **auth từ `eso/.env`**; không account DB | `D-111` | Basic cho UI, Bearer cho máy |
| `C-07` | **UI Angular 22**, build `bun`, origin riêng + CORS allowlist | `D-115` · SRS `04` | base URL runtime config |
| `C-08` | **không ORM**; SQL + migration runner tuần tự | `D-115` | migration idempotent, có `schema_version` |
| `C-09` | driver DB **không lộ** ra nghiệp vụ | `D-115` | chỉ một implementation `PlatformDb` |
| `C-10` | migration phải **idempotent** và chạy lại an toàn | SRS `06` | `eso migrate` không lỗi khi đã chạy |
| `C-11` | ghi file profile **nguyên tử** (tmp + rename) | `D-113` | không để file nửa vời |
| `C-12` | credential không vào log/response/DB | `D-111` | auth so sánh constant-time |
