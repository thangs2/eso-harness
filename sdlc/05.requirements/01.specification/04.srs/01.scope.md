# `01` — Phạm vi hệ thống

## 1. Hệ gồm gì

| Thành phần | Có ở baseline | Có ở Expansion |
|---|---|---|
| Control plane HTTP (NestJS + Fastify, Node) | ✅ | mở rộng |
| UI (Angular, origin riêng) | ✅ | mở rộng |
| Postgres: `platform` + `c_<id>` mỗi consumer | ✅ | thêm bảng miền |
| CLI `eso` (`DDL` · `serve` · `consumer`) | ✅ | thêm lệnh |
| `.harness/config.json` (artifact) | ✅ | thêm hook/turn files |
| Tính năng giải pain (`F-09…F-27`) | ❌ | ✅ |
| `.env` auth file | ✅ | lên B thì đổi mô hình auth |

## 2. Hệ **không** gồm

- SaaS đa khách / tenant tự đăng ký (`BR-14`).
- Sinh code, thay CI, thay review; sở hữu domain của consumer.
- Multi-user remote ở baseline (chỉ operator local).
- Danh tính agent/hook trong consumer ở baseline.

## 3. Actor (chi tiết ở BRD `03`)

A-01 operator (người duy nhất ở baseline) · A-02 lead agent · A-03 peer agent · A-04 auditor · A-05 host · A-06 provider · A-07 consumer project (bản ghi, **không** phải identity) · A-08 document custodian.

## 4. Triển khai baseline

| | |
|---|---|
| Chạy | `eso serve` trên máy operator, `127.0.0.1:8787`; UI dev `127.0.0.1:4200` |
| DB | 1 Postgres local (docker), user `baplatform`, DB riêng của ESO |
| Auth | Basic (UI) + Bearer (máy), credential từ `eso/.env` |
| Dữ liệu consumer | schema `c_<id>`; `public` trống; mapping lấy từ `platform.consumer` |

## 5. Phụ thuộc ngoài

| Phụ thuộc | Bắt buộc | Nếu thiếu |
|---|---|---|
| Postgres ≥ 14 | ✅ | server không khởi động |
| Node ≥ 20 (dev: 26) | ✅ | không chạy |
| `bun` (chỉ build UI) | ⬜ | build UI bằng npm được, không ảnh hưởng runtime |
| Reverse proxy (traefik/nginx) | ⬜ | chỉ cần khi lên B |
