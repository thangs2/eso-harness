# `04` — Giao diện ngoài

|---|---|---|---|
| `GET /api/v1/auth/me` | kiểm credential + loại actor | REQ-01 | `AUTH_REQUIRED` · `AUTH_INVALID` |

| `PUT /api/v1/hosts/{hostId}/runtimes/{runtimeId}` · `/heartbeat` | host runtime registration/liveness (`P1` · roadmap 16) | roadmap 16 | `HOST_RUNTIME_INVALID` · `HOST_RUNTIME_NOT_FOUND` |

| `POST /api/v1/hosts/{hostId}/runtimes/{runtimeId}/tokens` · `DELETE /tokens/{tokenId}` | scoped host token issue/revoke (`P2` · roadmap 16) | roadmap 16 | `HOST_RUNTIME_NOT_FOUND` · `HOST_TOKEN_NOT_FOUND` |
| `GET /api/v1/consumers/{id}/config-snapshot` | read-only host config snapshot (`P2` · roadmap 16) | roadmap 16 | `HOST_RUNTIME_INVALID` · `AUTH_INVALID` |
| `POST /api/v1/consumers/{id}/observations` · `GET` | host observation ingest/read (`P2` · roadmap 16) | roadmap 16 | `OBSERVATION_INVALID` · `AUTH_INVALID` |

**Mã lỗi host placement** (P0.2/P2 · roadmap 16, chưa cấp REQ id trong bảng trên): `HOST_RUNTIME_INVALID` (422) · `HOST_RUNTIME_NOT_FOUND` (404) · `WORKER_NOT_FOUND` (404) · `WORKER_PLACEMENT_INVALID` (422) · `HOST_TOKEN_NOT_FOUND` (404) · `OBSERVATION_INVALID` (422). `detail` mang chi tiết field, ví dụ `defaultModel is required` hoặc `defaultModel must be one of <effective models>`.

**Envelope lỗi** (mọi endpoint): `{ code, message, detail? }`; `code` thuộc BRD `06` hoặc bảng host placement ở trên; HTTP status: 400 (invalid) · 401 (auth) · 404 (not found) · 409 (conflict/state) · 422 (invalid/validation) · 500 (unexpected).

**Auth:** `Authorization: Basic` (UI) hoặc `Bearer` (máy). Host token Bearer chỉ dùng cho config snapshot đọc và observation ghi, scope `(hostId, runtimeId, consumerId)`; không cấp quyền operator. `GET /api/v1/c/...` cũng cần auth; consumer lấy từ **path**, không từ token.

## 2. Database

| Thành phần | Hợp đồng |
|---|---|
| `platform.consumer` | id · name · root · sdlc_root · schema_name · status · version · storage_mode · materialized_hash · created_at · updated_at |
| `platform.consumer_event` | id · consumer_id · event_type · actor_kind · actor_label · at · detail(jsonb) |
| `c_<id>.*` | bảng dữ liệu consumer (baseline: schema rỗng; Expansion: thêm bảng miền) |
| Truy cập | chỉ qua `PlatformDb` (`query/exec/transaction`); **không** ORM |
| Phiên | `SET LOCAL search_path = c_<id>, platform, public` **trong transaction** của request |
| `public` | để trống; thiếu `search_path` ⇒ fail-closed |

## 4. CLI

| Lệnh | Hợp đồng |
|---|---|
| `eso serve` | khởi động control plane; fail fast nếu thiếu `.env`/DB |
| `eso consumer list/check/materialize <id>` | dùng bearer token từ `.env` |

## 5. UI ↔ API

- Origin UI: `http://127.0.0.1:4200`, `http://localhost:4200`; CORS allowlist đúng các origin này, methods `GET,POST,PUT,DELETE,OPTIONS`.
- Credential ở `sessionStorage`; mỗi request gắn Basic; 401 ⇒ quay về form đăng nhập.
- Không gọi API khác origin ngoài allowlist.
