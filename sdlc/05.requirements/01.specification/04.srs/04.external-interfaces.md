# `04` — Giao diện ngoài

## 1. HTTP API (GĐ1)

| Method · Path | Mục đích | REQ | Lỗi chính |
|---|---|---|---|
| `GET /api/v1/auth/me` | kiểm credential + loại actor | REQ-01 | `AUTH_REQUIRED` · `AUTH_INVALID` |
| `GET /api/v1/consumers?status=&include_deleted=` | danh sách | REQ-04 | `AUTH_*` |
| `POST /api/v1/consumers` | đăng ký consumer | REQ-02 · REQ-03 | `ROOT_NOT_FOUND` · `CONSUMER_EXISTS` · `INVALID_CONSUMER_ID` |
| `GET /api/v1/consumers/{id}` | chi tiết | REQ-05 | `CONSUMER_NOT_FOUND` |
| `PUT /api/v1/consumers/{id}` | sửa profile (`expected_version`) | REQ-06 | `STALE_VERSION` · `MATERIALIZE_FAILED` |
| `POST /api/v1/consumers/{id}/retire` · `/reactivate` | tạm ngừng / bật lại | REQ-07 | `INVALID_STATE` |
| `POST /api/v1/consumers/{id}/delete` · `/restore` | soft delete / restore | REQ-08 | `INVALID_STATE` |
| `POST /api/v1/consumers/{id}/purge` | xoá hẳn (`confirm_id`) | REQ-09 | `PURGE_CONFIRM_MISMATCH` · `INVALID_STATE` |
| `GET /api/v1/consumers/{id}/profile` | profile + hash | REQ-05 | `CONSUMER_NOT_FOUND` |
| `POST /api/v1/consumers/{id}/profile/check` | kiểm drift | REQ-11 | `PROFILE_DRIFT` |
| `POST /api/v1/consumers/{id}/profile/materialize` | ghi lại artifact | REQ-10 | `ROOT_NOT_FOUND` · `PROFILE_INVALID` |
| `GET /api/v1/consumers/{id}/events` | audit timeline | REQ-14 | `CONSUMER_NOT_FOUND` |
| `* /api/v1/c/{consumer}/…` | dữ liệu consumer-scoped | REQ-12 · REQ-13 | `INVALID_CONSUMER_ID` · `CONSUMER_NOT_FOUND` |

**Envelope lỗi** (mọi endpoint): `{ code, message, detail? }`; `code` thuộc BRD `06`; HTTP status: 400 (invalid) · 401 (auth) · 404 (not found) · 409 (conflict/state) · 422 (root) · 500 (unexpected).

**Auth:** `Authorization: Basic` (UI) hoặc `Bearer` (máy). `GET /api/v1/c/...` cũng cần auth; consumer lấy từ **path**, không từ token.

## 2. Database

| Thành phần | Hợp đồng |
|---|---|
| `platform.consumer` | id · name · root · sdlc_root · schema_name · status · version · storage_mode · materialized_hash · created_at · updated_at |
| `platform.consumer_event` | id · consumer_id · event_type · actor_kind · actor_label · at · detail(jsonb) |
| `platform.schema_version` | version của `platform` |
| `c_<id>.*` | bảng dữ liệu consumer (GĐ1: `schema_version`; GĐ2: thêm bảng miền) |
| Truy cập | chỉ qua `PlatformDb` (`query/exec/transaction`); **không** ORM |
| Phiên | `SET LOCAL search_path = c_<id>, platform, public` **trong transaction** của request |
| `public` | để trống; thiếu `search_path` ⇒ fail-closed |

## 3. Hệ thống file

| Đường dẫn | Hợp đồng |
|---|---|
| `eso/.env` | `ESO_AUTH_USER` · `ESO_AUTH_PASSWORD` · `ESO_API_TOKEN` · `ESO_DB_URL` — gitignored |
| `<root>/.harness/config.json` | artifact generated: `_generated`, `_schema`, id/name/root/sdlcRoot/profile/zones/hash |
| `eso/migrations/*.sql` | migration tuần tự; `eso migrate` chạy idempotent |

## 4. CLI

| Lệnh | Hợp đồng |
|---|---|
| `eso migrate` | chạy migration còn thiếu; in version trước/sau; exit ≠ 0 nếu lỗi |
| `eso serve` | khởi động control plane; fail fast nếu thiếu `.env`/DB |
| `eso consumer list/check/materialize <id>` | dùng bearer token từ `.env` |

## 5. UI ↔ API

- Origin UI: `http://127.0.0.1:4200`, `http://localhost:4200`; CORS allowlist đúng các origin này, methods `GET,POST,PUT,DELETE,OPTIONS`.
- Credential ở `sessionStorage`; mỗi request gắn Basic; 401 ⇒ quay về form đăng nhập.
- Không gọi API khác origin ngoài allowlist.
