# `01` — Sản phẩm là gì, không là gì

## 1. Sản phẩm

> **ESO là harness chứng minh được** — nó biến *"agent nói nó ổn"* thành khẳng định **kiểm chứng được**
> (vision §1), cho **từng consumer** (một repo/đội) mà operator đăng ký.

Ba thứ ESO **có**:

1. **Control plane** — nơi operator đăng ký consumer, cấu hình, xem phán quyết.
2. **Tri thức có cấu trúc theo consumer** — mỗi consumer một vùng dữ liệu riêng (schema riêng), cấu hình do consumer khai.
3. **Bằng chứng** — mỗi quyết định/đánh giá để lại bản ghi, truy được *vì sao*.

## 2. Consumer — không phải tenant

| | **Consumer (ESO)** | **Tenant (SaaS)** |
|---|---|---|
| Là gì | một **đối tượng thụ hưởng** cụ thể: một repo/đội | một khách hàng của dịch vụ đa khách |
| Do ai tạo | operator đăng ký (một người) | tự đăng ký qua web |
| Cô lập bằng | **schema riêng** trong DB (vật lý, cùng instance) | thường bằng `tenant_id`/RLS |
| Số lượng | 5–10 / năm | hàng trăm → hàng nghìn |
| Mô hình bán | cài đặt/chạy trực tiếp | SaaS thuê bao |

⇒ **Không xây multi-tenant SaaS** (`BR-14`). "Nhiều consumer" không phải "nhiều tenant".

## 3. Ranh giới — sản phẩm **không** làm

| Không làm | Vì sao |
|---|---|
| sinh code thay người · thay CI/review | vision hứa **khả năng chứng minh**, không hứa chất lượng code |
| tự ký `Done` | quyền của A-01 |
| tự duyệt tri thức / tự nâng luật | vi phạm P5 + P7 |
| sở hữu giá trị miền của consumer | sản phẩm không chứa domain/service của một dự án cụ thể |
| thay host làm logging/monitoring | chỉ **đọc** trạng thái; không mutate thứ nó hiển thị |
| SaaS đa khách | xem §2 |

## 4. Ranh giới theo giai đoạn

| | **GĐ1 — beneficiary** | **GĐ2 — giải pain** |
|---|---|---|
| Có gì | control plane UI · đăng nhập operator · đăng ký/sửa/retire/xoá consumer · profile một nguồn + drift check · cô lập consumer | P1–P7: verdict trước thực thi · kiến trúc monolith rồi microservices · memory · tri thức có chủ · tự nâng skill có duyệt · … |
| Chưa có | mọi tính năng giải pain | microservices · multi-user remote (B) |
| Đo bằng | E2E 9 bước + 6 test cô lập + 1 smoke UI | metric của từng goal |

## 5. Triển khai

| | GĐ1 | Tương lai (B) |
|---|---|---|
| Chạy | local `eso serve` @ `127.0.0.1:8787` | server cài đặt, team remote |
| Auth | account trong `eso/.env` (Basic) + bearer token cho máy | HTTPS + account/role |
| DB | 1 Postgres local, `platform` + schema mỗi consumer | cùng mô hình, có thể tách DB theo deployment (D-73/D-106) |
| UI | Angular riêng origin, CORS allowlist | như nhau |
