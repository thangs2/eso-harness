# `03` — Năng lực sản phẩm (`F-nn`)

Mỗi năng lực trace `≥1 P` + `≥1 G` (luật PRD §2). **Trạng thái = as-is của code trong `eso/`** (đo 2026-11-23, xem [`10.matrix`](../../../02.governance/02.records/10.matrix.md)).
Dòng chưa đo giữ `chưa có`; dòng đã đo ghi rõ `có` / `một phần` + bằng chứng.
