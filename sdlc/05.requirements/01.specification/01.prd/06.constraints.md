# `06` — Ràng buộc và giả định

Ràng buộc là thứ **không thể chọn khác** ở giai đoạn này. Giả định là thứ **đang tin nhưng chưa chứng minh** — nếu sai
phải mở lại PRD.

## 1. Ràng buộc kỹ thuật

| id | Ràng buộc | Lý do / quyết định | Ảnh hưởng |
|---|---|---|---|
| `C-01` | **Postgres only** (không SQLite/Neo4j) | `D-92` · `D-93` | DB local + test dùng Postgres thật |
| `C-02` | **schema-per-consumer**: `platform` + `c_<id>`; `public` trống | G1-01 (thay `D-105`) | mọi query qua `search_path`; không predicate `project` |
| `C-03` | **Ba database** `cp`·`ctx`·`graph` khi mở rộng | `D-73` · `D-106` | baseline chỉ dùng `cp`; Expansion mở `ctx`/`graph` cùng kiểu schema |
| `C-04` | **Node + `pg`** cho control plane; `bun` chỉ để cài/build UI | G1-09 | `PlatformDb` interface để đổi driver sau |
| `C-05` | **Local-only** `127.0.0.1:8787`; không bind mạng | G1-02 | lên B mới có HTTPS/proxy |
| `C-06` | **Auth từ `eso/.env`** (Basic cho UI, Bearer cho máy) | G1-03 | không account trong DB ở baseline |
| `C-07` | **UI Angular 22** build bằng bun; tách origin + CORS allowlist | G1-04/G1-03a | base URL từ runtime config |
| `C-08` | **Không ORM**; SQL trực tiếp qua `PlatformDb` | giữ đơn giản | không DDL runner |
| `C-09` | Driver/interface DB **không lộ ra nghiệp vụ** | tránh rework | chỉ một implementation thay được |

| id | Giả định | Nếu sai thì |
