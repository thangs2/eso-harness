# `04` — Phạm vi release

Mỗi deliverable có acceptance; deliverable không trace được bị cắt. **Không có phase gate** (`D-122`).

## 1. Delivered baseline — `D1…D6`

| # | Deliverable | Năng lực | Acceptance (pass khi) |
|---|---|---|---|
| `D1` | **DB + registry**: `platform` schema, `platform.consumer`, `consumer_event`; `CREATE SCHEMA c_<id>` trong transaction tạo consumer | F-03 · F-08 | CP start bảo đảm `platform.consumer` tồn tại (`CREATE TABLE IF NOT EXISTS`); tạo consumer trong transaction (insert registry + create schema); event ghi được |
| `D2` | **Server + auth**: `eso serve` local `127.0.0.1:8787`, đọc `eso/.env`, Basic (UI) + Bearer (máy) | F-07 | login đúng/sai; thiếu token → 401; sai → 401; `me` trả đúng |
| `D3` | **Consumer API + provisioning**: tạo/list/get/update, `CREATE SCHEMA` trong 1 transaction | F-02 · F-03 | tạo consumer → record + schema; root sai → 422; trùng id → 409 |
| `D4` | **Profile + lifecycle**: materialize `.harness/config.json`, `check` drift, retire/soft delete/restore/purge, event log | F-04 · F-05 · F-08 | sửa tay file → DRIFT; retire giữ data; purge xoá schema + giữ audit |
| `D5` | **UI**: login · danh sách · setup host-first · chi tiết · đổi profile · retire/xoá · kiểm drift | F-01 · F-31 | operator làm được toàn bộ qua UI, không cần CLI |
| `D6` | **Cô lập + DoD**: 6 test đối kháng + E2E 9 bước + JSON report + 1 smoke screenshot | F-06 | 6/6 pass, E2E exit 0, screenshot lưu |

**Thứ tự làm:** `D1` → `D2` → `D3` → `D4` → `D5` → `D6`.

## 2. Chưa nằm trong baseline hiện tại — kèm lý do

| Không làm | Vì sao |
|---|---|
| mọi năng lực `F-09…F-31` (giải pain) | baseline chỉ tạo beneficiary; chưa có dữ liệu consumer thật thì không đo được |
| microservices · CQRS · ES · multi-tenant pattern | thuộc capability roadmap, và chỉ sau monolith |
| multi-user / team remote (B) | chưa cần; local-only trước |
| danh tính cho agent/hook trong consumer | roadmap, khi có tính năng ghi evidence |
| DAO/ORM, cache, hàng đợi, realtime | chưa có nhu cầu ở baseline |
| dashboard đẹp, theme, i18n | giao diện là **cách**, không phải goal |

## 4. Không đưa vào release khi chưa có bằng chứng

- Không tuyên bố `D7…D13` "đã xong" nếu chưa có metric + test tương ứng.
- Không dùng "có code chạy" làm bằng chứng — bằng chứng là E2E/metric (BR-12).
