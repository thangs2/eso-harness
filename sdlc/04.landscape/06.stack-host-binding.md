# Stack ↔ Host binding — mô hình, quan hệ, 5W1H

Tài liệu này chốt **ngôn ngữ chung** cho `Stack`, `Host`, `Host binding`, `Capability resolution`.
Nó giải thích vì sao mô hình cũ sai, mô hình hiện tại đúng ở đâu, và UI phải phản ánh gì.

Phạm vi: consumer settings (`/consumers/:id/settings`), tab **Stack** và **Host bindings**.
Không mô tả wiring code chi tiết; schema kỹ thuật ở
[`21.harness-domain-schema.md`](../07.technical/01.architecture/21.harness-domain-schema.md).

## 1. Kết luận trước

```text
Stack        = WHAT   — policy/definition
Host runtime = WHERE  — agent loop + host-owned config
Host binding = WHO × WHERE × WHICH — developer × host × stack version
Capability   = HOW    — source + provider cho từng capability trên binding
```

Ba câu không được trộn:

```text
Stack cần gì?
Host binding giải quyết thế nào trên host đó?
Host runtime đang chạy gì?
```

## 2. Full name và định nghĩa

| Term | Full name | Định nghĩa | Không phải |
|---|---|---|---|
| Stack | **Consumer Harness Stack Definition** | Định nghĩa versioned: layer nào bật, policy ra sao, material gì, document graph cấu hình gì | Không phải host config; không phải runtime |
| Host | **Agent Host Runtime** | Môi trường chạy agent loop, sở hữu native config: `.cursor/`, `.agents/`, `.claude/`, profile DSH/Paseo/Orca | Không phải stack; không phải binding |
| Host binding | **Developer Host Binding** | Join entity: developer × host runtime × một published stack version + capability resolution | Không phải bản sao Stack; không phải folder |
| Capability resolution | **Host Capability Resolution** | Quyết định source/provider cho memory/code graph trên một host binding | Không phải stack policy |
| Provider | **Capability Provider** | Implementation cụ thể: ESO-native, host-native, market MCP | Không phải host |
| Material | **Harness Material Set** | rules · skills · hooks · subagents files | Không phải stack policy |

Trong code cũ, `HostProfile` là tên nội bộ của **Host binding**. UI dùng term `Host binding`.

## 3. Actor — Subject — Object

| Actor | Action | Subject | Object | Kết quả |
|---|---|---|---|---|
| Operator / repo owner | define, version, publish | Consumer | `HarnessStack` | Stack version bất biến |
| Operator / repo owner | create | Developer | `HostBinding` | Binding được tạo |
| Operator / repo owner | pin | HostBinding | `HarnessStackVersion` | Binding chạy đúng version |
| ESO | resolve | HostBinding | `CapabilityBinding` | source/provider cho host |
| ESO | project | HostRuntime | Material | files/rules/skills/hooks tới host |
| HostRuntime | execute | Turn | Agent loop | công việc thực tế |
| Developer | use | HostRuntime | Binding đã tạo | làm việc bình thường |
| ESO | record | Consumer | Evidence | log/verdict |

Câu UI phải nói rõ:

```text
Ai làm gì, cho ai, trên object nào.
```

Ví dụ đúng:

```text
Operator tạo Host binding cho developer dev1 trên host Cursor, pin Stack v2.
ESO resolve memory/code graph cho binding đó.
```

## 4. 5W1H

### 4.1 Stack

| Câu hỏi | Trả lời |
|---|---|
| What | Versioned policy definition của consumer |
| Why | Định nghĩa harness độc lập với host; host nào cũng realize được |
| Who | Operator / repo owner |
| Whom | Mọi Host binding của consumer |
| Where | Consumer settings; lịch sử version trong `settings.harness.stack` |
| When | Onboarding; thay đổi policy; publish version mới |
| How | Layer policy + allowed sources + material + document graph |

### 4.2 Host runtime

| Câu hỏi | Trả lời |
|---|---|
| What | Agent execution environment |
| Why | Chạy agent loop; sở hữu native config |
| Who | Host vendor cung cấp; operator cài |
| Whom | Developer dùng host đó |
| Where | Máy/repo: `.cursor/`, `.agents/`, `.claude/`, profile DSH/Paseo/Orca |
| When | Luôn tồn tại; ESO chỉ detect khi có marker |
| How | Native files; ESO adapter chỉ project file/block có marker |

### 4.3 Host binding

| Câu hỏi | Trả lời |
|---|---|
| What | Developer × Host runtime × Stack version + resolution |
| Why | Nối Stack với host thật; cho phép nhiều dev/host dùng chung một Stack |
| Who | Operator / repo owner |
| Whom | Một developer trên một host runtime |
| Where | Consumer settings; project/host tương ứng |
| When | Khi ESO cần quản lý host đó; optional |
| How | Tạo binding, chọn published Stack version, resolve, project |

### 4.4 Capability resolution

| Câu hỏi | Trả lời |
|---|---|
| What | Source/provider cho memory và code graph trên binding |
| Why | Cùng Stack nhưng host khác nhau có khả năng khác nhau |
| Who | ESO resolve mặc định; operator chỉnh nếu cần |
| Whom | Một Host binding |
| Where | Binding record |
| When | Khi tạo/sửa binding; khi Stack policy đổi |
| How | Stack allowed sources + host capability + MCP discovery |

## 5. Quan hệ và cardinality

```text
Consumer
├── 1..* HarnessStackVersion     (definition lineage)
└── * HostBinding                (assignment)

Developer     1 ─── * HostBinding
HostRuntime   1 ─── * HostBinding
HostBinding   * ─── 1 HarnessStackVersion
HostBinding   1 ─── * CapabilityBinding
CapabilityBinding * ─── 1 Provider
```

| Quan hệ | Cardinality | Ý nghĩa |
|---|---|---|
| Consumer → Stack version | 1 → * | Một lineage, nhiều version |
| Consumer → Host binding | 1 → * | Nhiều dev/host |
| Developer → Host binding | 1 → * | Một dev dùng nhiều host |
| Host runtime → Host binding | 1 → * | Một host dùng cho nhiều dev |
| Host binding → Stack version | * → 1 | Pin đúng một published version |
| Host binding → Capability binding | 1 → * | Thường memory + code graph |

## 6. Ownership / source of truth

| Fact / artifact | Owner / SoT | ESO được ghi? |
|---|---|---|
| Consumer, stack, binding records | ESO DB (`platform`) | có |
| Stack version history | ESO settings DB (hiện tại JSON) | có |
| `.harness/config.json` | ESO projection | có |
| `AGENTS.md` canonical block | ESO-owned | chỉ block có marker |
| `agents/` material | ESO-owned | file có marker |
| `.cursor/` config | Cursor | chỉ projection có marker |
| `.agents/` config | AGY | chỉ projection có marker |
| `.claude/` config | Claude | chỉ projection có marker |
| Host MCP config | Host/máy | chỉ đọc |
| Evidence / verdict | ESO DB | append-only |

**Federated SoT:** mỗi fact có một owner. Không có một folder làm SoT cho tất cả.

## 7. Vì sao mô hình cũ sai

### 7.1 Anti-pattern

```text
Stack:        Memory source = market → provider agentmemory
Host binding: Memory source = host-native → provider DSH
```

Hai nơi chọn cùng một fact. Không có luật thắng. Đây là **duplicate source of truth**.

### 7.2 Các lựa chọn

| Phương án | Ưu | Nhược | Kết luận |
|---|---|---|---|
| Stack chọn source/provider | Một chỗ | Không thể khác host; host không theo policy | Loại |
| Host chọn tất cả | Linh hoạt host | Stack mất vai trò policy; không governance | Loại |
| **Stack policy + Host resolution** | Một policy, nhiều resolution; host-aware | Cần phân biệt rõ UI | **Chọn** |

### 7.3 Quy tắc chốt

```text
Stack:      required + allowedSources + document graph + material
Binding:    source + provider + MCP config
```

Ví dụ:

```text
Stack policy:
  Memory required; allowed [host-native, eso-native, market]

DEV1 / DSH:    source host-native · provider DSH
DEV2 / Cursor: source market · provider agentmemory
DEV3 / Cursor: source eso-native
```

## 8. Capability matrix

| Layer | Stack owns | Binding resolves | UI |
|---|---|---|---|
| Multi-agent / SLP | roles, workers, workflow policy | không | inherited |
| Rules / law | material/files | projection status | inherited |
| Skills | material/files | projection status | inherited |
| Hooks | material/files | projection status | inherited |
| Memory | required + allowed sources | source + provider | **resolved** |
| Code graph | required + allowed sources | source + provider | **resolved** |
| Document graph | enabled + Postgres config | chỉ status | inherited |
| Topology | deferred | không | inherited |
| Material | install set | projection only | inherited |
| MCP | không thuộc Stack | config ref | read-only |

## 9. State machines

### 9.1 Stack version

```text
draft ──publish──► published ──retire──► retired
  ▲                    │
  └── new version ◄────┘
```

| State | Sửa | Bind mới | Binding cũ |
|---|---|---|---|
| draft | có | không | không |
| published | không | có | giữ |
| retired | không | không | giữ/upgrade |

### 9.2 Host binding

```text
detected ──bind──► pending ──project──► partial ──► installed
                        │                  │
                        └──── error ◄──────┘
```

`detected` không phải binding; chỉ là marker.

### 9.3 Capability

```text
resolved   source/provider hợp lệ
disabled   Stack tắt layer
missing    market nhưng MCP không có provider
```

## 10. Flows

### 10.1 Thêm host binding

```text
1. Operator bấm New host binding
2. Chọn/tạo developer
3. Chọn host runtime
4. Chọn published Stack version
5. ESO resolve memory/code graph
6. Save → binding pending
7. ESO project material
8. Host chạy bình thường
```

### 10.2 Stack disable memory

```text
Stack tắt Memory
→ binding không hiện Memory resolution
→ memory source = none
→ effective binding: Memory disabled
```

### 10.3 Publish phiên bản mới

```text
v1 published
→ New version → v2 draft
→ sửa v2
→ Publish v2
→ binding v1 vẫn v1
→ upgrade binding riêng nếu muốn
```

### 10.4 Tool không có adapter

```text
Dev dùng tool lạ
→ không marker / không adapter
→ không binding
→ ESO không can thiệp
→ tool vẫn chạy
```

## 12. Anti-patterns

| Anti-pattern | Vì sao sai |
|---|---|
| Stack và binding cùng chọn source/provider | Hai SoT |
| HostProfile như một Stack thu nhỏ | Nhân bản cấu hình |
| Bắt buộc add developer riêng | Developer là thuộc tính của binding |
| Ép mọi host phải có binding | ESO optional |
| Sửa published version tại chỗ | Binding đổi ngầm, mất rollback |
| Binding tự theo latest Stack | Không reproducible |
| Coi `.harness` là SoT toàn repo | Chỉ là projection của ESO |

## 13. Decisions — chốt 2026-11-11

| ID | Decision | Ghi chú |
|---|---|---|
| O-SH1 | **Stack version lưu Postgres** | Settings JSON chỉ là projection/cache, không phải SoT |
| O-SH2 | **Cho Reopen published → draft nếu chưa có binding** | Có audit; published đã có binding thì phải New version |
| O-SH3 | **Retired không nhận binding mới/upgrade/rollback** | Binding đang pin retired vẫn hợp lệ đến khi upgrade đi |
| O-SH4 | **Memory tier không phải product tier; nếu là scope thì thuộc Stack memory layer** | Chưa thêm field cho đến khi định nghĩa rõ |
| O-SH5 | **Adapter capability matrix là bắt buộc** | Unknown = unknown, không giả định |
| O-SH6 | **Bulk upgrade có preview + explicit confirm** | Không auto; skip binding không tương thích |

### 13.1 O-SH1 — Stack versions trong Postgres

Trong schema consumer (Postgres):

```text
harness_stack
  id, consumer_id, created_at

harness_stack_version
  id, stack_id, version_number, status,
  layers_json, published_at, created_at

host_binding
  id, consumer_id, developer_id, host_runtime_id,
  stack_version_id, capability_bindings_json,
  mcp_config_ref, install_state, created_at
```

Rule:

```text
DB = SoT
settings.harness.stack = projection/cache
.harness/config.json = projection ra repo
```

Hiện UI vẫn đọc/ghi settings JSON; đây là **target architecture**, chưa migrate DB.

### 13.2 O-SH2 — Reopen published

Cho phép:

```text
published version
  + 0 host binding
→ Reopen as draft
→ sửa
→ publish lại
```

Không cho:

```text
published version
  + ≥1 host binding
→ phải New version
```

Lý do: không làm thay đổi binding đang chạy.

### 13.3 O-SH3 — Retired

```text
retired version:
  new binding        = không
  upgrade vào        = không
  rollback vào       = không
  binding đang pin   = vẫn hợp lệ
  upgrade ra         = có
```

Retired chỉ dùng để giữ lịch sử/evidence, không dùng làm target mới.

### 13.4 O-SH4 — “Memory tier” là gì

Câu hỏi gốc không rõ vì “tier” có thể là:

| Nghĩa | Thuộc đâu | Quyết định |
|---|---|---|
| Product tier (Lite/Pro) | — | **Không tồn tại**; đã bỏ |
| Memory scope: turn/session/project/team/long-term | Stack memory layer | Thêm `scope[]` khi cần; không thuộc binding |
| Provider tier/model class | Provider config | Không thuộc Stack hay binding |

Nếu sau này cần memory scope, thêm vào **Stack memory layer**:

```json
{
  "memory": {
    "required": true,
    "allowedSources": ["host-native", "eso-native", "market"],
    "scope": ["session", "project", "long-term"]
  }
}
```

Binding **không** được override scope; binding chỉ resolve source/provider.

### 13.5 O-SH5 — Host adapter capability matrix

Mỗi host adapter phải khai manifest:

```json
{
  "id": "cursor",
  "capabilities": ["rules", "skills", "subagents", "hooks", "mcp"],
  "nativePaths": { "rules": ".cursor/rules", "skills": ".cursor/skills" },
  "writeMode": "marked-projection",
  "verifiedAt": "2026-11-08",
  "source": "measured"
}
```

Matrix:

| Host | rules | skills | subagents | hooks | mcp | memory | code graph | document graph |
|---|---|---|---|---|---|---|---|---|
| Cursor | yes | yes | yes | yes | yes | no | no | ESO-only |
| AGY | yes | yes | yes | unknown | yes | no | no | ESO-only |
| DSH | via AGENTS.local | yes | no discovery | plugin | profile | profile-scoped | no | ESO-only |
| Claude | unknown | unknown | unknown | unknown | unknown | no | no | ESO-only |
| Codex | AGENTS.md | no | no | no | no | no | no | ESO-only |
| Paseo | no | no | no | no | profile | no | no | ESO-only |
| Orca | no | no | no | no | profile | no | no | ESO-only |

Rule:

```text
capability not in adapter matrix
→ resolution = unsupported
→ không silent fallback
```

### 13.6 O-SH6 — Bulk upgrade binding

Flow:

```text
1. Chọn target published version
2. Preview: binding nào sẽ đổi, binding nào skip
3. Confirm
4. Upgrade từng binding
5. Trả per-binding result + audit event
```

Skip tự động:

```text
retired target
binding đang error
host adapter thiếu capability
```

Không auto-upgrade khi publish version mới.

### 13.7 Trạng thái implementation (2026-11-11)

| ID | Code/UI | Ghi chú |
|---|---|---|
| O-SH1 | ✅ table + API + UI save/load | `platform.harness_stack_version`; settings JSON vẫn ghi kèm |
| O-SH2 | ✅ Reopen as draft | chỉ khi version chưa có binding |
| O-SH3 | ✅ Retire version | retired không xuất hiện trong published selector |
| O-SH4 | ⏸ chưa thêm `scope[]` | chờ định nghĩa memory scope |
| O-SH5 | ⏸ matrix tài liệu, chưa có manifest runtime | cần adapter khai capabilities |
| O-SH6 | ✅ Bulk upgrade cơ bản | preview count + target; chưa per-binding skip report |
