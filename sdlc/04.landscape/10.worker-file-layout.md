# 10 — Worker files: source, flow, projection

**Câu hỏi:** worker, host binding, flow và projection được lưu ở đâu; đâu là source?

## 1. Nguyên tắc

```text
mỗi artifact có đúng một source
```

```text
agents/subagents/*.md      worker identity
agents/rules/*slp*.mdc     SLP intent / flow proposal
.harness/flows/*.json      flow definition
.harness/flows/index.json  default flow pointer
.agents/agents/*.md        projection
.cursor/agents/*.md        projection
.harness/placements.json   worker × host binding
.harness/bindings/*.json   host binding
```

Không có:

```text
.harness/formation.json
settings.harness.workerEdges
worker definition trong DB
```

## 4. Flow file

```text
.harness/flows/that-tinh-tran.v1.json
```

```json
{
  "id": "that-tinh-tran",
  "name": "7 Tinh Trận",
  "version": 1,
  "status": "published",
  "nodes": [
    { "workerId": "worker-scout", "x": 60, "y": 50 }
  ],
  "edges": [
    { "id": "e-scout-plan", "from": "worker-scout", "to": "worker-plan", "on": "PASS" }
  ],
  "viewport": { "x": 0, "y": 0, "zoom": 1 }
}
```

Quy tắc:

```text
draft       mutable
v<N>        immutable
publish     ghi v<N>, xoá draft
edit        tạo draft version kế tiếp
```

Default:

```text
.harness/flows/index.json
{
  "defaultFlowId": "that-tinh-tran",
  "defaultFlowVersion": 1
}
```

`index.json` chỉ chọn default flow; không định nghĩa edges.

## 5. Placement và binding

Binding:

```json
{
  "id": "hb-dev-cursor",
  "developer": "dev",
  "hostId": "cursor",
  "stackVersion": 1,
  "flowId": "that-tinh-tran",
  "flowVersion": 1,
  "memorySource": "host-native",
  "codeGraphSource": "eso-native",
  "installState": "installed"
}
```

Placement:

```json
[
  { "workerId": "worker-scout", "hostBindingId": "hb-dev-cursor" }
]
```

Binding pin `stackVersion` và optionally `flowId/flowVersion`.

## 6. Projection

Generate từ `agents/subagents/*.md`:

```text
.cursor/agents/<worker>.md
.agents/agents/<worker>.md
```

Marker:

```text
<!-- generated by eso worker projection; source agents/subagents/ -->
```

Không sửa projection. Nếu sửa:

```text
drift detected
→ Promote one-way về agents/subagents
hoặc discard
```

## 7. Read path

```text
Workers tab
  → GET /workers
  → worker files + default flow summary
  → read-only edges

Flows page
  → flows JSON
  → edit draft / validate / publish / set default

Policy handoff
  → DB worker edge index
  → rebuilt from default flow
```

## 8. Write path

```text
worker identity
  → UI or IDE edits agents/subagents/*.md
  → POST /workers/sync
  → reindex

flow
  → Flows page
  → PUT /flows/:id
  → publish
  → default pointer
  → reindex worker edges

projection
  → generated only
  → never a source
```

`PUT /workers` không nhận edges:

```http
422 EDGES_MOVED_TO_FLOW
```

## 9. SLP

`agents/rules/*slp*.mdc` có thể chứa structured block:

````markdown
```slp-flow
{
  "id": "slp-proposal",
  "name": "SLP Proposal",
  "edges": [
    { "from": "worker-scout", "to": "worker-plan", "on": "PASS" }
  ]
}
```
````

ESO parse block này thành **proposal**:

```text
GET  /slp/flow-proposal
POST /slp/flow-proposal/apply
```

Proposal chỉ tạo draft. Không publish, không overwrite default flow.

Nếu `slp.md` chỉ có văn xuôi:

```text
NO_STRUCTURED_SLP_FLOW
```

Không parse văn xuôi.

## 10. Invariants

```text
INV-1  Worker file là source duy nhất cho worker identity.
INV-2  Flow JSON là source duy nhất cho edges.
INV-3  formation.json không tồn tại.
INV-4  PUT /workers không ghi edges.
INV-5  Workers tab không mutate edges.
INV-6  DB worker edge index derived từ default flow.
INV-7  Projection không phải source.
INV-8  Default flow phải là published version.
```
