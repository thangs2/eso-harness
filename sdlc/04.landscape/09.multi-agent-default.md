# 09 — Multi-Agent default: Seven-Star Formation

**Trạng thái:** DRAFT · setup default 2026-11-12.

## 1. Nguồn

`Seven-Star Formation` (Vietnamese alias: *Thất Tinh Trận*) không phải tên trang trí. Nguồn:

```text
P6 multi-agent SLP
D-48 — vai mở, động từ đóng; 7 vai là preset nội dung
03.v2-high-level-design §4.2 — actor graph là dữ liệu khai
agents/subagents/*-runtime.md — 7 worker hiện có
```

Câu gốc của operator:

```text
"có bao nhiêu con worker tham gia vào dự án (SLP) (dynamic)
 mỗi worker có roles gì, skills gì, knowledge base ra sao
 workflow được phép như thế nào (A xong đến B)
 kéo thả, như bộ 'thất tinh trận'"
```

## 2. Seven positions

| # | Worker | Vai | Layer | Scope mặc định |
|---|---|---|---|---|
| 1 | Scout | recon / sự thật | peer | `/tmp/slp/recon/` · read/write |
| 2 | Plan | chia slice | peer | `/tmp/slp/plan/` · read/write |
| 3 | Build | peer developer | peer | `agents/`, `scripts/`, `tools/` · read/write/append |
| 4 | Fixbug | sửa lỗi đã biết | peer | `findings` · read/write |
| 5 | Verify | cổng xác định | gate | `/tmp/slp/verify/` · read/write/approve · evidence `verify PASS` |
| 6 | Audit | chấm độc lập | gate | `/tmp/slp/audit/` · read/write/approve · evidence `rubric >=85`, `critical ==0` |
| 7 | QC | chạy scenario | gate | `/tmp/slp/qc/` · read/write/append/approve · evidence `scenario executed` |

## 3. Trận pháp — edge là dữ liệu hạng nhất

```text
Scout → Plan        context ready
Plan  → Build       slice ready
Build → Verify      implemented
Verify → Audit      PASS
Verify → Fixbug     FAIL
Audit  → Fixbug     findings
Fixbug → Verify     fixed
Audit  → QC         PASS · operator asks
```

Không phải danh sách 7 người. Cùng 7 người, nối edge khác ⇒ quy trình khác.

## 4b. Worker definition vs host placement

Không đặt lại 7 role cho từng host.

```text
Worker definition = name · role · layer · scope
Host placement    = worker × host binding
```

Một worker được gán nhiều host binding:

```text
7 workers × 3 host bindings = 21 placements
nhưng chỉ 1 lần khai 7 role
```

UI:

```text
Apply formation to host bindings
  [host A] [host B] [host C]
  Apply to all workers
→ 7 workers × 3 hosts
```

Per-worker override vẫn được:

```text
Host bindings (multi-select)
```

Layer:

```text
peer = may write inside scope
gate = verify or judge only; never implement
```

Role → layer chỉ là **gợi ý**; người khai được đổi.

## 6. Gate guardrail trong control plane

Gate layer không phải "cấm mọi write". Gate được ghi **evidence** trong scope của mình:

```text
gate write /tmp/slp/verify/...   ALLOW
gate write agents/...            DENY GATE_WRITE_OUTSIDE_EVIDENCE_SCOPE
gate configure                   DENY
```

Gate `approve` chỉ ALLOW khi typed evidence đạt bar:

```text
verify  → { kind: "verify", status: "PASS" }
audit   → { kind: "audit", rubric: 90, critical: 0 }
qc      → { kind: "scenario", executed: true }
```

Handoff có condition:

```text
verify → audit  on PASS
verify → fixbug on FAIL
```

Thiếu outcome hoặc sai outcome:

```text
DENY HANDOFF_OUTCOME_REQUIRED
DENY HANDOFF_CONDITION_MISMATCH
```
