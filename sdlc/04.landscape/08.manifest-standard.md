# 08 — Manifest standard — decision record

**Trạng thái:** DRAFT · ghi lại quyết định ngày **2026-11-12**.

**Câu hỏi gốc:**

> Làm sao để AI tìm đúng file, hiểu cấu trúc tài liệu, đi theo quan hệ giữa các file,
> và dùng ticket/provider — mà không crawl cả repo?

**Câu trả lời đã chốt:**

```text
File      = content source of truth
Header    = authored contract
Manifest  = generated machine-readable index
Postgres  = derived hybrid index (graph + FTS + vector)
Ticket    = external reference
```

## 2. Header standard

### 2.1 Ba nhóm

```text
Identity / shape

Provenance / owner
  owner · source_of_truth · human_sot · origin

Lifecycle / readiness
  status · kt_state · liveness · phase
```

### 2.5 Không đưa vào header

```text
path              locator, không phải identity
content_hash      generated
derived_from      multi-valued relation
references        multi-valued relation
supersedes        relation
external_refs     provider relation
```

Chỉ giữ pointer đơn:

```text
source_of_truth
human_sot
```

### 2.6 Pointer

Canonical:

```text
doc:<doc_id>
```

Legacy vẫn đọc:

```text
relative/path.md
relative/path.md#section
```

Path được resolve về `doc_id`; unresolved là **finding**, không phải edge im lặng.

```text

```

## 4. Relative / linking / ref

### 4.1 Link kinds

```text
references
derived_from
source_of_truth
human_sot
supersedes
owns_kinds
mentions_ticket
```

### 4.2 Resolution

```text
doc.md
../dir/doc.md
doc.md#heading
doc:ID
provider:id
```

Rules:

```text
relative to document
reject absolute / escape root
resolve path → doc_id
resolve anchor → heading
unresolved = finding
record raw + resolved + provenance
```

### 4.3 Provenance

```text
declared  from header
derived   from link/text
```

Declared thắng derived; conflict là flag, không xóa.

## 5. Postgres hybrid

### 5.1 Đã test thật 2026-11-12

Trong một transaction:

```text
graph   TMP-1 → TMP-2 → TMP-3  depth 2
fts     "requirement" → 2 docs
vector  cosine 0.000000
```

Rollback.

Kết luận:

```text
Postgres làm được graph + FTS + vector + transaction
trong cùng một database/schema.
```

### 5.2 Phân vai

```text
Graph  = liên quan gì / vì sao
FTS    = từ/ký tự chính xác
Vector = gần nghĩa
```

Không thay thế nhau.

### 5.3 Giới hạn

```text
recursive CTE không có graph optimizer
depth/fanout lớn sẽ nổ
HNSW approximate
filter + ANN có thể thiếu kết quả
index update không miễn phí
embedding model/dimension phải cố định
```

Không dùng vector tạo edge.
