## 4. Link — theo lane BAP §3

```text
Quartet Blocks : unit → impl → coverage
                 impl → qc
Quartet Relates: qc ↔ impl · qc ↔ unit · qc ↔ coverage
Top-level Blocks: theo WBS DAG thật (16 cạnh), vd L1.1 → L1.2/L2.1/L3.1/L4.4
Top-level Relates: sibling cùng epic + UI ↔ profile/isolation
```

Top-level: `Blocks` theo WBS DAG; `Relates` sibling cùng Epic. Mỗi ticket **khai** 4 quan hệ trong `h4. Relations`; root/sink khai `none` + lý do (không bịa gate).
