# `15` — Đặc tả hành vi page (STD-PAGE-BEHAVIOR)

> **SUPERSEDED** — luật nay ở [`16.master-standard`](16.master-standard.md). File này chỉ còn giá trị lịch sử.

> **Vấn đề:** "page doc có inventory" vẫn chưa đủ. Người đọc cần biết: **điều kiện nào để có dữ liệu**, **if/else nào
> đổi giao diện**, **CTA nào bật/tắt vì sao**, **dữ liệu đến từ đâu**, **bấm thì gì xảy ra**, **lỗi nào hiện gì**.
> Chuẩn này bắt mỗi page phải có 10 khối dưới, mỗi dòng có `file:line`.

## 1. Mười khối bắt buộc

| Khối | Nội dung | Ví dụ câu trả lời |
|---|---|---|
| **B1 Entry** | route · guard · query param (và alias) · điều kiện tiên quyết | "`?consumer=` sai ⇒ dừng, không fallback" |
| **B2 Load sequence** | thứ tự gọi API, song song/tuần tự, nhánh lỗi từng bước | "consumers → (observations) → (flows ∥ consumer)" |
| **B3 Data graph** | field hiển thị ← computed ← endpoint ← bảng | "`Failures` ← `failureCount()` ← `observations` ← `GET .../observations`" |
| **B4 Branch table** | **mọi if/else** có ý nghĩa người dùng: predicate → kết quả | "`flows.length === 0` ⇒ text `No published flow`, **không** phải lỗi" |
| **B5 CTA table** | control → điều kiện bật → hành động → API → nhánh lỗi → state reset | "`Play` disabled khi `pulsePlaying`; chạy 450 ms/event" |
| **B6 State machine** | state × trigger → state kế | "`playing` --hết event--> `ready`" |
| **B7 Error paths** | status/code → UI hiện gì → retry? | "401/403 ⇒ `OBS_DENIED`; 500 ⇒ `OBS_UPSTREAM_FAILED`" |
| **B8 Derived** | công thức computed, thứ tự ưu tiên, edge case | "flow = default → published mới nhất → `flows[0]`" |
| **B9 Timing/live** | poll · SSE · interval · cleanup | "poll 5 s; SSE server 1.5 s; `ngOnDestroy` clear" |
| **B10 A11y/nav** | keyboard · focus · deep-link · back | "row không `tabindex` ⇒ **không** keyboard (gap)" |

## 2. Luật viết

1. **Mỗi dòng phải có `file:line`** — không có nghĩa là chưa đo.
2. **Branch table phải phủ hết `@if`/`@else`/ternary** trong template + `if/return` trong handler.
3. **CTA table phải nêu điều kiện disabled** thật (không chép lời hứa).
4. **Data graph phải chỉ ra bảng** (nếu có) — nếu là JSON/file thì ghi rõ.
5. **Không lặp rule FRD**: B4/B5 mô tả *hành vi UI thấy*, FRD mô tả *luật nghiệp vụ*.
6. **Gap phải ghi**: nếu code không có a11y/không có retry ⇒ ghi `GAP`, không né.

## 3. Đo độ sâu

| Chỉ số | Cách đo | Ngưỡng tối thiểu |
|---|---|---|
| `branch` | số dòng B4 | ≥ 8 với page phức tạp, ≥ 3 với page tĩnh |
| `cta` | số dòng B5 | = số control tương tác |
| `error` | số dòng B7 | ≥ 3 |
| `derived` | số dòng B8 | = số computed ảnh hưởng UI |

Page chưa đạt ngưỡng ⇒ ghi `DEPTH: n/m` trong page doc và giữ `DONE ✗`.

## 6. Vì sao **10** — và vì sao **không đủ** (v1.1)

> **Trả lời thẳng:** 10 khối không phải chuẩn hoàn chỉnh. Nó là tập **suy ra từ 175 mục thiếu** phát hiện khi reverify
> (element không có nhà, điều kiện không được mô tả). Đo lại theo mô hình dưới đây thì 10 khối phủ **6/15 chiều**;
> phần còn thiếu chính là lý do "doc vẫn sơ sài" dù đã có B1–B10.

### 6.1 Mô hình phủ (dùng để biết thiếu gì, không phải để đếm cho đẹp)

| Chiều | Giá trị | B1–B10 phủ? |
|---|---|---|
| **Trigger** | entry · user · system(timer) · browser(back/refresh) · network · session | entry/user/system ✅ · browser ⚠️ · network ⚠️ · **session ❌** |
| **Observable** | content · visibility · enabled · copy · nav · error · **progress** | content/vis/enabled/copy/nav/error ✅ · **progress ❌** |
| **Layer** | route · data · state · **permission** · **format** · **limit** | route/data/state ✅ · permission/format/limit ❌ |
| **Time** | load · live · **long-running** · **conflict** · **expiry** | load/live ✅ · long-running/conflict/expiry ❌ |

### 6.2 Bổ sung bắt buộc từ v1.1 — B11…B20

| Khối | Nội dung | Vì sao thiếu là sai |
|---|---|---|
| **B11 Permission** | control nào **ẩn** vs **disable** theo quyền; nguồn quyền | UI không tự quyết quyền; không ghi ⇒ không biết ai thấy gì |
| **B12 Concurrency** | 409/stale version/multi-tab; merge hay chặn | `settings` có `PROFILE_STALE_VERSION`, nhiều page không |
| **B13 Session** | 401 giữa thao tác, hết phiên, redirect `returnUrl` | 15 page không mô tả; mất dữ liệu đang nhập |
| **B14 Limits** | page size, cap server, debounce, volume, virtualization | `cap 50` vs "all rows" đã thành BUG-15 |
| **B15 Responsive** | breakpoint nào đổi layout gì | **25 file** có `@media` chưa doc nào ghi |
| **B16 Format** | locale/timezone/số/đơn vị/tương đối | `Intl` dùng ở 4 chỗ, không doc ⇒ sai múi giờ |
| **B17 Security/privacy** | prompt body, credential, storage, XSS | `BUG-11` (env hard-code) lẽ ra bị bắt bởi khối này |
| **B18 Telemetry** | page có gửi trace/error report không | không ghi ⇒ không đo được lỗi thật |
| **B19 Lifecycle** | `ngOnDestroy`, AbortController, timer, SSE cleanup | `/events` có AbortController nhưng không doc |
| **B20 Long-running** | tiến trình dài: progress/cancel/partial failure | import/publish/provision đều dài, doc chỉ "saving" |

### 6.3 Áp dụng

- Page doc mới: **bắt buộc B1–B20**.
- 24 page hiện có: giữ B1–B10 (đã đo), khai `EXT: n/10` cho B11–B20; [`17.behavior-gaps`](../../02.governance/02.records/17.behavior-gaps.md) ghi phần thiếu.
- `DEPTH` mở rộng: `branch · cta · error · derived · ext`.
