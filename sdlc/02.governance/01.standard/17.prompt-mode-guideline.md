# `17` — Prompt mode guideline: `mode=A|B` (user contract)

> Đây là **hướng dẫn người dùng**, không phải luật mới. Cơ chế/limit: [`36.prompt-mode-router`](../../07.technical/01.architecture/36.prompt-mode-router.md).

## 1. Ba câu phải nhớ

```text
1. mode=A/B chọn NƠI worker chạy — không phải chọn SLP.
2. Target lấy từ worker-placement; KHÔNG viết to= trong prompt.
3. Không có mode= ⇒ chat bình thường, router không can thiệp.
```

## 2. Decision table — chọn loại prompt

| Mày muốn | Prompt | Workload | Mode | Target | Trạng thái |
|---|---|---|---|---|---|
| Chat một agent, không worker | `<task>` | host-native agent | — | host đang chat | ✅ hiện tại |
| Một worker chạy local | `mode=A <task>` | 1 worker | A | runtime local | ✅ skill router |
| Một worker chạy host khác | `mode=B <task>` | 1 worker | B | remote trong placement | ✅ skill router |
| SLP team, local | `impl <KEY> slp g` | SLP team | — | host hiện tại | ✅ SLP skill |
| SLP + chỉ định mode | `impl <KEY> slp g mode=A\|B` | SLP team | A/B | theo placement | ❌ chưa nối router |
| Auto A/B | không có `mode=auto` | — | — | — | ❌ không hỗ trợ |

## 3. Matrix prompt × host (ví dụ allowedHosts)

Giả sử placement:

```text
allowedHosts = [agy:agy, dsh:main-chat, cursor:cursor-agent]
modes        = [A, B]
default flow = that-tinh-tran
entry worker = worker-scout
```

| Host gõ | Prompt | Target thực tế |
|---|---|---|
| AGY (`agy:agy`) | `mode=A review X` | `agy:agy` local |
| AGY | `mode=B review X` | `dsh:main-chat` remote |
| DSH (`dsh:main-chat`) | `mode=A review X` | `dsh:main-chat` local |
| DSH | `mode=B review X` | `agy:agy` remote |
| Cursor (`cursor:cursor-agent`) | `mode=A review X` | `cursor:cursor-agent` local |
| Cursor | `mode=B review X` | `agy:agy` remote |

Target **không cố định theo host**; nó là host đầu tiên trong `allowedHosts` thoả mode.

## 4. Config prerequisite matrix

| Prompt | `modes` | `allowedHosts` | Khác |
|---|---|---|---|
| `mode=A` | có `A` | có local runtime | default flow + entry worker |
| `mode=B` | có `B` | có remote runtime | remote `serve`, `ESO_REMOTE_URL/TOKEN` |
| `mode=A` hoặc `mode=B` | cả `A`,`B` | cả local + remote | thứ tự allowed quyết target |
| `impl … slp g` | không bắt buộc | SLP dùng worker riêng | skill SLP đã load |

## 5. Prompt chuẩn / phản ví dụ

### Đúng

```text
mode=A review file X
mode=B review file X
MODE=A review file X        # case-insensitive
impl ESO-123 slp g          # SLP only
```

### Sai

| Prompt | Lỗi |
|---|---|
| `mode=A` | thiếu task |
| `mode=B review X to=dsh:main-chat` | `to=` bị cấm; target từ config |
| `mode=auto review X` | không có auto |
| `A review X` | thiếu `mode=` |
| `--mode A review X` | không phải directive |
| `impl ESO-123 slp g mode=A` | SLP+mode chưa nối; dùng `mode=A` standalone hoặc SLP riêng |

## 6. Hành vi lỗi (fail-closed)

| Tình huống | Kết quả |
|---|---|
| worker không bật mode | `does not enable mode B` |
| mode B không có remote | `no allowed remote` |
| không có default flow | `no default flow configured` |
| flow không có entry worker | `default flow has no entry worker` |
| thiếu task | `mode directive needs a task` |
| có `to=` | `to= is not allowed` |

Không fallback sang chat/SLP.

## 7. Cách xem đã chạy đúng

| Mode | Dấu hiệu |
|---|---|
| A | plan `local: true`, target = runtime local |
| B | plan `local: false`, target = remote; observation `remoteObservationId` |
| SLP | worker trail của SLP, không có mode directive |

Dry-run trước khi chạy thật:

```bash
node .harness/hooks/eso-mode-router.mjs --host agy --prompt 'mode=A review X' --dry-run
node .harness/hooks/eso-mode-router.mjs --host dsh --prompt 'mode=B review X' --dry-run
```

## 8. Giới hạn hiện tại

- AGY + DSH có **hard injector** (`eso-mode-guard.mjs`): prompt `mode=` được chèn đúng lệnh router; model không chọn có route hay không.
- Cursor **không có** prompt-time context injection theo contract chính thức; vẫn skill-followed.
- Hook **không** tự chạy worker; model vẫn phải chạy lệnh router. Full execution hook không dùng vì Mode B có thể vượt timeout hook.
- `SLP + mode` chưa nối; router từ chối.
- Mode B cần remote server + token; không có thì fail.
- Single agent chat **không** phải Mode A/B formal.

## 9. Master matrix — prompt × host × mode × protocol

Điều kiện ví dụ:

```text
allowedHosts = [agy:agy, dsh:main-chat, cursor:cursor-agent]
modes        = [A, B]
default flow = that-tinh-tran
entry worker = worker-scout
```

| # | Host | Prompt | Mode | Protocol (trigger → execute) | Target | Trạng thái |
|---|---|---|---|---|---|---|
| 1 | AGY | `review X` | — | chat-native | AGY local | ✅ |
| 2 | DSH | `review X` | — | chat-native | DSH local | ✅ |
| 3 | Cursor | `review X` | — | chat-native | Cursor local | ✅ |
| 4 | AGY | `mode=A review X` | A | AGY PreInvocation `injectSteps.userMessage` → router → `host-runtime run` | `agy:agy` | ✅ hard injector |
| 5 | DSH | `mode=A review X` | A | DSH `UserPromptSubmit` `additionalContext` → router → `run` | `dsh:main-chat` | ✅ hard injector |
| 6 | Cursor | `mode=A review X` | A | skill `mode-router` → router → `run` | `cursor:cursor-agent` | ⚠️ skill-followed |
| 7 | AGY | `mode=B review X` | B | AGY inject → router → `host-runtime dispatch` | `dsh:main-chat` | ✅ hard injector |
| 8 | DSH | `mode=B review X` | B | DSH inject → router → `dispatch` | `agy:agy` | ✅ hard injector |
| 9 | Cursor | `mode=B review X` | B | skill → router → `dispatch` | `agy:agy` | ⚠️ skill-followed |
| 10 | AGY | `impl ESO-123 slp g` | — | SLP skill → subagents | AGY local | ✅ SLP |
| 11 | DSH | `impl ESO-123 slp g` | — | SLP skill → subagents | DSH local | ✅ nếu skill loaded |
| 12 | Cursor | `impl ESO-123 slp g` | — | SLP skill → subagents | Cursor local | ✅ nếu skill loaded |
| 13 | any | `impl ESO-123 slp g mode=A` | A | router **rejects** | — | ❌ chưa nối |
| 14 | any | `impl ESO-123 slp g mode=B` | B | router **rejects** | — | ❌ chưa nối |
| 15 | any | `mode=B … to=…` | B | router **rejects** | — | ❌ sai cú pháp |
| 16 | any | `mode=A` (không task) | A | router **rejects** | — | ❌ thiếu task |
| 17 | any | `mode=auto …` | auto | không hỗ trợ | — | ❌ |

### 9.1 Protocol matrix — host dialect

| Host | Prompt hook | Output protocol | Inject command? |
|---|---|---|---|
| **AGY** | `PreInvocation` | `injectSteps:[{userMessage}]` / `{systemMessage}` | ✅ |
| **DSH** | `UserPromptSubmit` | `hookSpecificOutput.additionalContext` / `decision:"block"` | ✅ |
| **Cursor** | `beforeSubmitPrompt` | chỉ `continue` / `user_message` | ❌ không có context field |

### 9.2 Mode × execution

| Mode | Execution | Ai chọn target | Config bắt buộc |
|---|---|---|---|
| A | `host-runtime run` | host đang chat | `modes` có A · local trong `allowedHosts` · default flow |
| B | `host-runtime dispatch` | remote đầu tiên trong `allowedHosts` | `modes` có B · remote trong `allowedHosts` · remote server + token |
| — | chat-native | host đang chat | không cần flow |
| SLP | subagents | SLP skill | skill SLP loaded |

### 9.3 Config → target

| `allowedHosts` | Host gõ prompt | Mode A | Mode B |
|---|---|---|---|
| `[agy, dsh, cursor]` | AGY | `agy` | `dsh` |
| `[agy, dsh, cursor]` | DSH | `dsh` | `agy` |
| `[agy, dsh, cursor]` | Cursor | `cursor` | `agy` |
| `[dsh, agy]` | AGY | `agy` | `dsh` |
| `[cursor, agy]` | DSH | không có local → **fail** | `cursor` |

## 10. Execution shape — subagent vs swarm (SLP)

SLP có **shape** thứ ba bên cạnh workload và mode. Shape không phải mode và không đổi target.

```text
impl <KEY> slp g                    → subagent (mặc định, mọi host)
impl <KEY> slp g swarm              → swarm, scope all (AGY)
impl <KEY> slp g swarm=build        → chỉ phase build dùng swarm (AGY)
impl <KEY> slp g swarm=qc           → chỉ phase qc dùng swarm (AGY)
```

| Shape | Prompt | Host | Mode | Trạng thái |
|---|---|---|---|---|
| subagent | `impl K slp g` | AGY · DSH · Cursor | — | ✅ hiện tại |
| swarm | `impl K slp g swarm` | **AGY** | — | ✅ |
| swarm=build/qc | `impl K slp g swarm=qc` | **AGY** | — | ✅ |
| swarm | `impl K slp g swarm` | DSH | — | ❌ block (`ESO_SWARM_SUPPORTED=1` để mở) |
| swarm | `impl K slp g swarm` | Cursor | — | ❌ skill-followed, giới hạn host |
| swarm | `mode=B impl K slp g swarm` | any | B | ❌ reject — worker swarm không được vượt trace |
| swarm scope lạ | `swarm=abc` | any | — | ❌ reject |
| trộn shape trong 1 turn | — | — | — | ❌ cấm |

### 10.1 Luật swarm

1. **AGY only** — swarm là capability của host, không phải của ESO.
2. **Một shape / turn** — không trộn swarm + subagent.
3. **Lead giữ bảng tin** — worker chỉ post cho Lead (`post_message` → `read_board`).
4. **Đóng trước khi trả lời** — `swarm_wait` hết worker; worker còn sống sau câu trả lời là run chưa đóng.
5. **Không Mode B** — worker bền vượt ranh giới trace.
6. **Evidence** — observation mang `executionShape` (`swarm` | `subagent`) và `swarmScope`; Stage 5 hiển thị `Workers … · swarm|subagent|not reported`.
