# `14` — Kiểm tra & bổ sung tài liệu theo code (STD-DOC-CODE-AUDIT)

> **SUPERSEDED** — luật nay ở [`16.master-standard`](16.master-standard.md). File này chỉ còn giá trị lịch sử.

> **Vấn đề:** "viết page doc từ 50 dòng đầu của component" là **quá sơ sài** — nó tạo tài liệu nghe hợp lý nhưng bỏ sót
> field/action/state/error, và không có bằng chứng nào cho từng câu. Chuẩn này chặn đúng lỗi đó.

## 1. Thế nào là "đủ" (và thế nào là sơ sài)

| Sơ sài (cấm) | Đủ |
|---|---|
| Đọc 1 phần file rồi viết § surface | **Inventory toàn bộ** element của surface, mỗi element có `file:line` |
| Không đối chiếu FRD/AC/SCN/UI đã có | Bảng **map** element → nhà hiện tại → trạng thái (có/thiếu/mâu thuẫn) |
| Không nói cái gì **không** làm | Ghi rõ non-goal + OPEN khi chưa chốt |
| Không có cách kiểm lại | **Coverage matrix** element → § doc; đếm `n/N` |
| Số liệu không nguồn | Mọi con số (số field, số state, số endpoint) phải kèm lệnh/đường dẫn đo |

## 2. Quy trình C0–C6

| Bước | Việc | Output bắt buộc |
|---|---|---|
| **C0** | Xác định surface: route · component · service · endpoint | 1 dòng định danh |
| **C1** | **Inventory** từ code: field · action · state · error · endpoint · data | bảng `E# | element | file:line` |
| **C2** | **Đối chiếu** tài liệu hiện có (FRD/SRS/AC/SCN/TECH/UI/ledger) | bảng `E# → nhà → có/thiếu/mâu thuẫn` |
| **C3** | **Gap list** + phân loại: thiếu · lệch · trùng · chưa có F | danh sách, không sửa gì |
| **C4** | **Bổ sung** chỉ phần thiếu, vào đúng phòng; mỗi claim gắn `file:line` | diff tài liệu |
| **C5** | **Coverage matrix**: mỗi E# trỏ § doc; tính `n/N` | bảng trong page doc |
| **C6** | Gate + cập nhật ledger với **% coverage**, không chỉ ✅ | gate output |

## 3. Luật bất biến

1. **Không bịa**: element không thấy trong code ⇒ không viết; chưa chốt ⇒ `OPEN-…`.
2. **Không implement**: gặp thiếu code ⇒ ghi gap, dừng; không tự sửa code/test.
3. **Một element một nhà**: field/action thuộc FRD; bố cục/a11y thuộc UI; endpoint thuộc TECH.
4. **Số phải đo được**: "7 host type" phải chỉ được `HOST_CATALOG` trong code.
5. **Coverage matrix là bằng chứng**, không phải lời hứa: `12/18` nghĩa là còn 6 element chưa vào doc.
6. **Mỗi § surface phải có `**Chain:**`** — trỏ đủ `US · AC · SCN · RTM`. Thiếu chain ⇒ surface đó **chưa xong**, dù FRD viết dài.
   Gặp surface chưa có AC ⇒ tạo `US/AC/SCN/RTM` (docs) và ghi test `MISSING`; **không** để trống rồi coi là hoàn thành.

## 4. Áp dụng

- Page doc mới **bắt buộc** có §"Inventory" + §"Coverage".
- Page doc cũ **chưa audit sâu** phải ghi `audit: chưa` ở ledger; không được coi là xong.
