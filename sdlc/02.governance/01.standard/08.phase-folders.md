# `08` — Phase execution folders

**Một chủ đề:** phase là **workspace thực thi**; standard là luật dùng chung. Không copy yêu cầu vào phase.

## 1. Cấu trúc

```text
sdlc/
├── 01.agent-manifests/       # global
├── 02.governance/            # global: standard · records · policies · diagrams
├── 03.inception/             # global: pain · vision · decision log
├── 05.requirements/          # global: BRD · PRD · FRD · SRS
├── 06.analysis/              # global: US · AC · SCN
├── 07.technical/             # global: architecture · planes
├── 08.ui-design/             # global: UI design
├── 09.wbs/                   # historical index; active WBS đã chuyển
├── 10.test/                  # global: test standard/history
├── 98.delivery/              # global: delivery
└── 12.phases/
    ├── 00.index.md
    ├── 01.phase-1/
    │   ├── 00.index.md
    │   ├── 01.charter.md
    │   ├── 02.wbs/           # WBS + packets
    │   ├── 03.go-no-go/
    │   ├── 04.decisions/     # filtered index → global log
    │   ├── 05.records/       # status · risks · metrics · lessons
    │   ├── 06.acceptance/    # matrix · evidence · SCN
    │   └── 07.closure/       # closure criteria/status
    ├── 02.phase-2/
    └── 03.phase-n/
```

## 2. Luật

1. **Global vs phase:** requirements/design/standard sống ở folder toàn cục; phase chỉ giữ execution.
2. **Không copy:** phase không copy FRD/AC/SCN; chỉ link + filter.
3. **Gate:** phase chỉ mở/đóng khi `03.go-no-go/` có kết quả; gate không tick ⇒ không tuyên bố.
4. **Decision một log:** phase `04.decisions` là index; quyết định nằm ở `03.inception/02.decision-log`.
5. **WBS thuộc phase:** active WBS + packet nằm trong `02.wbs/`; `09.wbs` chỉ còn historical.
6. **Status toàn cục:** `02.governance/02.records/01.document-status` vẫn là nguồn đo; phase record link tới.
7. **Tên:** `NN.phase-N`; phase chưa mở chỉ tạo `00.index.md`, không tạo subfolder rỗng.
8. **Frontmatter `phase`** vẫn là thuộc tính artifact; folder phase là **phạm vi thực thi**, không thay frontmatter.
