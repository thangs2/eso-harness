## §4 Page contract (không thiếu trường hợp)

Mỗi page doc **bắt buộc**:

1. `§Pipeline` — `F → FRD → REQ → US/AC → SCN → RTM → TECH → Test`.
2. `§Inventory` — mọi element + `file:line`; `Coverage n/N`.
3. `§Behavior` — **B1…B20** (định nghĩa: `19` §3):
   `Entry · Load · Data · Branch · CTA · State · Error · Derived · Timing · A11y · Permission · Concurrency · Session · Limits · Responsive · Format · Security · Telemetry · Lifecycle · Long-running`.
4. `DEPTH: branch · cta · error · derived · ext` — **dòng cuối** §Behavior; `branch/cta/error/derived` đếm từ số dòng B4/B5/B7/B8; `ext` = B11–B20 có ≥1 anchor hoặc N/A+anchor.
5. **Đúng 20 heading** `### B1`…`### B20`, mỗi cái một lần, theo thứ tự; không gộp, không lặp.
5. `GAP` cho mọi thứ code không có; `N/A — lý do + anchor` khi không tồn tại hành vi.
6. Bug mở của page (nếu có) + test status.
