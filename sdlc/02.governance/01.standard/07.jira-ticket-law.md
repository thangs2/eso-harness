# Jira ticket law — ESO

**Normative.** Dùng MUST / MUST NOT / SHOULD như RFC 2119. Nguồn thi hành cho agent:
[`delivery.jira-agent-execution`](../../../agents/rules/delivery.jira-agent-execution.mdc). Nền tảng kỹ thuật:
[`17.jira-slp-operating`](../../07.technical/01.architecture/17.jira-slp-operating.md) §2–§3.

## 1. Phạm vi

| Tập | Áp dụng | Ghi chú |
|---|---|---|
| **Active set** = issue `project = ESO` **trừ** label `legacy-v1` | **MUST** tuân luật này | gồm baseline + Expansion |
| **Legacy v1** = Epic cũ (`F-01…F-24`, `T-0x`) | MUST mang label `legacy-v1`, **không** làm việc, không tạo con | giữ lịch sử, không sửa cấu trúc |
| Ticket đã `Done`/`Closed` | MUST giữ nguyên lịch sử | luật chỉ áp ticket **đang hoạt động** |

## 2. Hierarchy — đúng 3 hình dạng

```text
Epic (feature) → Story → Subtask
Epic (feature) → Task  → Subtask
Epic (feature) → Bug            (Bug MUST có ≥1 Subtask tái hiện)
```

- Story/Task/Bug MUST thuộc đúng **1 Epic** (field `parent`).
- Subtask MUST thuộc đúng **1 Story/Task/Bug**; MUST NOT mồ côi.
- MUST NOT lồng Epic trong Epic, Subtask trong Subtask.
- Epic MUST có **≥1** ticket con (Story/Task/Bug).

## 3. Subtask — TDD quartet (MUST)

Mỗi Story/Task/Bug MUST có **đúng 4** Subtask quartet; slice runtime (`ESO-525` · `ESO-528` · `ESO-531`) có thêm `load` + `stress` ⇒ **6**:

| Label | Summary | Story points |
|---|---|---|
| `tdd-unit` | `[be]/[fe] <leaf> — unit tests` | **2** |
| `tdd-impl` | `[be]/[fe] <leaf> — Implement (DEV)` | **= WBS dev SP** |
| `tdd-coverage` | `[be]/[fe] <leaf> — coverage gate` | **1** |
| `tdd-qc` | `[qc] <leaf> — run SCN + evidence` | **3** |
| `tdd-ba` | `[ba] <leaf> — clarify AC` | **2** | chỉ khi AC chưa đọc được; baseline = **OUT + lý do** |
| `tdd-perf` | `[qc] <leaf> — decide NFR` | **5** | **Task độc lập** (`D-75`/`D-78`), không subtask |
| `tdd-load` | `[qc] <leaf> — load test` | **5** | chỉ slice runtime (đo hệ đang chạy) |
| `tdd-stress` | `[qc] <leaf> — stress test` | **5** | chỉ slice runtime |

- **8 loại** (`D-75` + `17.jira-slp-operating` §2): unit · impl · coverage · qc · ba · perf · load · stress.
- `ba` OUT cho baseline (AC đã rõ); `perf` = 1 Task độc lập; `load`/`stress` chỉ cho slice runtime (ESO-525 · ESO-528 · ESO-531).
- MUST NOT tạo Story/Task "đơn độc" 1–2 subtask (J-11).

## 4. Bốn quan hệ — **khai báo**, không bịa link (MUST)

Mọi ticket MUST khai **bốn quan hệ** (trong description, mục `h4. Relations`): `subtasks` · `relates` · `blocks` · `is blocked by`.

| Quan hệ | Áp cho | Tối thiểu |
|---|---|---|
| `subtasks` | Story · Task · Bug | **≥1**, hoặc `none` + **lý do** (ticket nguyên tử) |
| `subtasks` | Epic | **≥1** ticket con |
| `subtasks` | Subtask | `none — Jira prohibits subtasks on a subtask` |
| `relates` | **mọi** ticket | khai; `none` + lý do được |
| `blocks` | **mọi** ticket | khai cái nó chặn; `none` + lý do (sink) được |
| `is blocked by` | **mọi** ticket | khai cái chặn nó; `none` + lý do (root) được |

- `blocks` và `is blocked by` là **hai chiều của cùng link type** nhưng là **hai câu hỏi khác nhau** — MUST khai cả hai.
- `none` MUST kèm lý do; im lặng MUST NOT.
- MUST NOT tạo link giả (gate/cross-lane) chỉ để "đủ nhóm"; link chỉ biểu diễn quan hệ thật.
- Link thật: quartet lane `unit → impl → coverage`, `impl → qc`; `relates` `qc ↔ impl/unit/coverage`; top-level `Blocks` theo WBS DAG; `Relates` sibling cùng Epic.
- Máy: `scripts/jira-rebuild-structure.mjs` (dry-run) + `scripts/jira-audit-tickets.mjs`.

## 5. Story points — Fibonacci, rollup (MUST)

- Thang: **1 · 2 · 3 · 5 · 8 · 13**; MUST NOT số khác.
- Nhập điểm **chỉ trên Subtask**.
- `Task/Story` điểm = **Σ Subtask**; `Epic` = **Σ task/story con**.
- MUST NOT nhập tay điểm parent; lệch ⇒ `POINTS_MISMATCH`.
- Máy: `scripts/jira-points-rollup.mjs` · `scripts/jira-audit-tickets.mjs`.

## 6. Ngôn ngữ — English-only (MUST)

`summary` · `description` · `comment` · `label` · tên attachment MUST là **English**. Mã `AC-*`/`SCN-*`/`REQ-*`/
`BR-*`/`INV-*`/error code/slug/path MUST giữ nguyên. Ticket có summary/description tiếng Việt MUST NOT được tạo.

## 7. Sprint và trạng thái

- Ticket active MUST thuộc **đúng 1 sprint** đang mở (baseline: `ESO Sprint 1`, board 69, sprint 73). Subtask thừa hưởng sprint của parent.
- Agent MUST NOT set `Done`/`Closed`; MUST NOT reopen `Done`/`Closed`.
- Status rollup theo `delivery.jira-agent-execution` §5, chạy sau **mỗi** child transition.

## 8. Ngoại lệ (đóng — không tự mở rộng)

| Đối tượng | Miễn gì | Điều kiện |
|---|---|---|
| **Epic** | quartet + 3 nhóm | là container; MUST vẫn có ≥1 con + relates |
| **Legacy v1** | toàn bộ cấu trúc | MUST có label `legacy-v1`; không làm việc |

## 9. Thi hành và thay đổi

- **Audit:** `node scripts/jira-audit-tickets.mjs` (dry-run) — in vi phạm theo key; exit ≠ 0 nếu có.
- **Tạo hàng loạt:** `scripts/jira-rebuild-structure.mjs` (dry-run mặc định) + `scripts/jira-fix-baseline-quartet.mjs`.
- **Sửa luật:** MUST bump `sot_doc_version`, cập nhật rule `delivery.jira-agent-execution`, chạy audit lại toàn bộ active set.
- **Vi phạm:** MUST fix trước khi ticket chuyển `Human In Review`; không "fix sau".
