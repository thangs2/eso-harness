# 11 — Harness migration pipeline

> Chuẩn cho **mọi consumer** còn legacy host harness (`.cursor/**`, `.agents/**`, v1 `.harness`).
> Migration là pipeline có preview → apply → verify → cleanup; không phải copy tay.

## 1. Nguyên tắc

```text
ESO là nguồn duy nhất
legacy host trees là nguồn migrate
host trees sau migrate là projection
không overwrite canonical ESO
không migrate secret / path máy
operator quyết định
```

## 2. Destination

| Legacy | ESO canonical |
|---|---|
| `.cursor/rules/*.mdc` · `.agents/rules/*.md` | `agents/rules/*.md` |
| `.cursor/skills/<id>/SKILL.md` · `.agents/skills/<id>` | `agents/skills/<id>/SKILL.md` |
| `.cursor/agents/*.md` · `.agents/agents/*.md` | `agents/subagents/*.md` |
| `.cursor/hooks/*` · `.agents/hooks/*` | `agents/hooks/*` |
| `.cursor/mcp.json` · `.agents/mcp_config.json` | **host-local — không migrate** |
| `AGENTS.md` | giữ product content + ESO canonical block |
| `.harness/decision-policy.json` · `integrations.json` · `harness.config.json` | map field hỗ trợ; báo field bỏ |

## 3. Hai entry point

### A. Manual migration

```text
Settings → Migration pipeline
→ Preview migration
→ đọc counts/conflicts
→ Migrate to ESO
```

Chỉ operator bấm mới apply.

### B. Finish settings

```text
Finish
→ save settings
→ detect legacy
   ├─ không có legacy → provision → finish
   └─ có legacy → hỏi
        ├─ No  → save only, KHÔNG provision, KHÔNG finish
        └─ Yes → migration → provision → finish
```

Không được:

```text
auto migrate khi save
finish khi No
provision trước migration khi Yes
```

## 4. Pipeline stages

```text
M1 Inventory
M2 Diff .cursor ↔ .agents
M3 Map canonical
M4 Conflict detection
M5 Preview plan + hash
M6 Apply canonical
M7 Material/provision
M8 Verify
M9 Cleanup legacy
```

### Status

```text
new      target chưa tồn tại → copy
same     target tồn tại, nội dung giống (bỏ generated marker) → skip
conflict target tồn tại, nội dung khác → skip, operator chọn
```

Apply chỉ copy `new`; `same` + `conflict` ghi manifest.

`agents/subagents/README.md` là scaffold material, không phải subagent — migration bỏ qua README để tránh conflict vĩnh viễn.

### Conflict resolution

Conflict không được resolve bằng `Migrate`.

```text
keep ESO canonical   → bỏ entry legacy
adopt legacy         → operator copy/merge source → target
exclude scaffold     → README/generated files
```

Chỉ migrate `new`; `conflict` phải được xử lý riêng.
Nếu chỉ có conflict, UI không cho migrate.

Implementation:

```text
POST /consumers/:id/harness-migration/conflicts/:entryId/resolve
  strategy = keep-eso | adopt-legacy

.harness/migration-resolutions.json
  entryId · strategy · sourceHash · targetHash · actor · at
```

`adopt-legacy` backup canonical vào `.harness/archive/migration-conflicts/`.
Resolution stale nếu source/target hash đổi → conflict hiện lại.

## 4.5 UI visibility

`Migration pipeline` là **action queue**, không phải status dashboard.

```text
detected=false                 → ẩn
detected=true, all same        → ẩn
new>0 hoặc conflict>0          → hiện
```

Finish cũng chỉ hỏi migration khi có `new`/`conflict`; `same` không chặn finish.

Lý do: tránh panel thường trực gây hiểu nhầm "còn việc phải migrate" sau khi migration đã xong.

## 5. Manifest

```text
.harness/migration-manifest.json
  generated
  consumerId
  planHash
  createdAt
  actor
  applied[]
  skipped[]
```

## 6. Verification

```text
[ ] canonical files tồn tại
[ ] ESO core files không bị overwrite
[ ] material manifest/config consistent
[ ] host dry-run PASS
[ ] rules/skills/workers load
[ ] hooks không mất hành vi
[ ] không secret trong git
```

## 7. Cleanup

Chỉ sau khi verify PASS:

```text
xoá legacy .cursor/.agents entries đã migrate
xoá host-pack legacy nếu hook migration PASS
xoá harness.config.json/integrations/decision-policy đã map
```

Archive nằm dưới `<root>/.harness/archive/` và bị gitignore (D9).
Không archive ra ngoài repo. Nếu cần rollback, snapshot tạm **trong repo** và xoá sau.

## 8. Tests bắt buộc

```text
preview read-only
apply new files
conflict không overwrite
manifest hash đúng
finish No không provision
finish Yes migration → provision
legacy secret path không bị copy
```

## 9. API

```text
GET  /api/v1/consumers/:id/harness-migration/preview
POST /api/v1/consumers/:id/harness-migration/apply
GET  /api/v1/consumers/:id/legacy-harness
POST /api/v1/consumers/:id/legacy-harness/archive
```
