# `10` — SDLC Master Pipeline: rule

**Normative.** Diagram nguồn: [`04.diagrams/01.main-pipeline`](../04.diagrams/01.main-pipeline.md).
Đây là pipeline chính `S1…S14` + `G1…G13`; Intent Pipeline là **zoom-in `S1…S7`**.

## 1. Luật thứ tự

1. `S1 → S2 → … → S14` MUST theo thứ tự; MUST NOT nhảy stage.
2. Mỗi gate `G1…G13` MUST có bằng chứng trước khi sang stage kế.
3. `S1` MUST chứa Intent Pipeline `I1…I3` (pain → mission/vision → goals).
4. `S2…S7` MUST khớp Intent Pipeline `I4…I7`; không có hai nguồn song song.
5. `S8`/`S9` MUST trace `I7 AC`; ticket không có AC MUST NOT được tạo.
6. `S14` MUST do **người** ký; agent MUST NOT ký `Done`.
7. `S11` MUST code theo packet; MUST NOT code ngoài `allowed_files`.
8. `S12` MUST chạy SCN trước khi tuyên bố DoD; SCN đỏ MUST quay lại `S11`.
9. CR loop chỉ theo đường đã khai trong diagram; MUST NOT dùng CR để bypass gate.

## 2. Gate map

| Gate | Từ → đến | Kiểm tối thiểu |
|---|---|---|
| `G1` | S1 → S2 | pain trace goal |
| `G2` | S2 → S3 | BR/UC trace P |
| `G3` | S3 → S4 | F trace P + G |
| `G4` | S4 → S5 | F đủ 6 mục + ≥1 từ chối |
| `G5` | S5 → S6 | REQ trace F + BR |
| `G6` | S6 → S7 | mọi REQ có ≥1 AC |
| `G7` | S7 → S8 | packet cite được |
| `G8` | S8 → S9 | leaf có AC + owner + size |
| `G9` | S9 → S10 | packet §9 `READY` = DoR |
| `G10` | S10 → S11 | mọi AC có SCN đã khai |
| `G11` | S11 → S12 | không code ngoài packet |
| `G12` | S12 → S13 | SCN xanh · RTM đủ |
| `G13` | S13 → S14 | đủ 4 điều kiện thoát |

## 3. Quan hệ với Intent Pipeline

| Nếu | Thì |
