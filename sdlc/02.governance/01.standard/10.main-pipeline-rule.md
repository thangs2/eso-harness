# `10` — SDLC Master Pipeline: rule

**Normative.** Diagram nguồn: [`04.diagrams/01.main-pipeline`](../04.diagrams/01.main-pipeline.md).
Đây là pipeline chính `S1…S17` + `G1…G16` cùng 3 trạm kiểm định chất lượng bắt buộc (**CHK1 Cross-checks**, **CHK3 Pre-flight DoR**, **CHK2 Go / No-Go**). Intent Pipeline là **zoom-in `S1…S7`**.

## 1. Luật thứ tự & Quyền lực một chiều

1. `S1 → S2 → … → S17` MUST theo thứ tự; MUST NOT nhảy stage hoặc đốt cháy giai đoạn.
2. Mỗi gate `G1…G16` MUST có bằng chứng tài liệu/phép đo trước khi bước sang stage kế tiếp.
3. `S1…S2` MUST chứa Intent Pipeline `I1…I3` (pain → vision/mission → goals & objectives có metric đo lường).
4. `S3…S7` MUST khớp Intent Pipeline `I4…I7`; không có hai nguồn tài liệu song song đối nghịch.
5. **Khối Kỹ thuật (`S8…S10`)** MUST hoàn thành trước khi mở kế hoạch thi công:
   - `S8` API contracts MUST tuân thủ luật zero-turn-path (`D-46`) và bảng mã lỗi chuẩn.
   - `S9` Data Design MUST chứng minh zero-drift giữa Entity và Schema thực tế.
   - `S10` Architecture MUST khai đủ C4 L1–L3 và NFR specs có ngưỡng đo.
6. `S11` WBS MUST trace trực tiếp `S7 AC`; ticket không có AC MUST NOT được tạo.
7. `S12` BIP/FIP packet MUST khóa cứng phạm vi `allowed_files` và chỉ định rõ tầng kiểm soát invariants.
8. `S13` Scenario Matrix MUST phủ 1:1 với AC (đủ các nhánh happy, edge, failure, rbac/tenant).
9. **Trạm kiểm soát bắt buộc:**
   - **CHK1 (Yêu cầu)**: Cross-checks `X1, X2, X4–X7, X16–X20` xanh mới được chuyển giao cho TECH thiết kế (không chứa `X3` vì SCN chưa lập).
   - **CHK3 (DoR từng slice)**: Pre-flight Readiness Checklist đạt trọn vẹn **8/8 dòng pre-code (Stage 0–7)** kèm `X3` (1:1 AC ↔ SCN) mới được phép chuyển tiếp.
   - **CHK2 (Kế hoạch cấp Increment)**: Go / No-Go Dashboard đạt `Docs Ready` đầy đủ (`REQ ∩ US/AC ∩ SCN ∩ IF ∩ DATA` + `BIP/FIP`) và pass các cross-checks kỹ thuật (`X8, X8a, X9, X10, X21, X22, X34–X36`) mới được giải ngân thi công `S14`.
10. `S14` Code MUST viết theo packet; MUST NOT code ngoài `allowed_files`; tuân thủ TDD Quartet (unit RED → impl GREEN → coverage ≥80%).
11. `S15` QC MUST chạy kịch bản SCN thật và ghi nhận `evidence.json` trước khi chuyển sang đánh giá DoD.
12. `S16` DoD Checklist (`D-116`) MUST đạt 0 CRITICAL lỗi tồn đọng.
13. `S17` MUST do **người (PO & PM)** ký nghiệm thu; agent hoặc hệ thống tự động MUST NOT ký `Done` (BR-05).
14. CR loop chỉ đi theo đường phản hồi đã khai trong diagram; MUST NOT dùng CR để bypass gate.

## 2. Gate map chi tiết

| Gate | Từ → đến | Role chủ trì | Kiểm tối thiểu | Bằng chứng bắt buộc |
|---|---|---|---|---|
| `G1` | S1 → S2 | PO | Pain trace Vision & Mission | Problem statement + Vision charter |
| `G2` | S2 → S3 | PO (PM consult) | Goals & Objectives có metric đo được (`X17`) | Bảng MET-* có ngưỡng đo và công thức |
| `G3` | S3 → S4 | BA | Mọi Business Rule / Use Case trace Goal | BRD với danh mục BR-* và Actor rights |
| `G4` | S4 → S5 | PO | Mọi Feature trace Objective | PRD Feature Catalog F-01…F-nn (in/out scope) |
| `G5` | S5 → S6 | BA | FRD đủ 6 mục + ≥1 điều kiện từ chối + mã lỗi | FRD specs chi tiết từng chức năng |
| `G6` | S6 → S7 | BA | REQ trace FRD + BR | SRS REQ-01…REQ-nn |
| `G7` | S7 → CHK1 | BA | 100% REQ có ≥1 AC kiểm được | User Stories & Acceptance Criteria table |
| **CHK1** | CHK1 → S8 | **QC & PM** | **Cross-checks X1, X2, X4–X7, X16–X20 PASS** | Báo cáo kiểm định tài liệu yêu cầu |
| `G8` | S8 → S9 | TECH | API contracts khớp nghiệp vụ FRD/SRS | `07.technical/03.api/` (idempotency, errors) |
| `G9` | S9 → S10 | TECH | Entity ↔ Schema zero-drift, DuckDB models | `07.technical/02.data-design/` (DDL, RLS) |
| `G10` | S10 → S11 | TECH | C4 all levels + NFR specs có ngưỡng | `07.technical/01.architecture/` + NFR specs |
| `G11` | S11 → S12 | PM | Leaf task có AC + owner + Story Points | WBS master plan + WBS dictionary |
| `G12` | S12 → S13 | TECH | BIP/FIP khóa cứng `allowed_files` | BIP (backend) / FIP (frontend) packets |
| `G13` | S13 → CHK3 | QC | 1:1 AC ↔ SCN (happy, edge, error, rbac) | Scenario Matrix SCN-* + Traceability Matrix |
| **CHK3** | CHK3 → CHK2 | **PM & QC** | **Pre-flight DoR: X3 + đủ 8/8 dòng pre-code (0–7)** | Phiếu nghiệm thu sẵn sàng thi công từng slice |
| **CHK2** | CHK2 → S14 | **PM & QC** | **Go / No-Go: Docs Ready (+ X8, X8a, X9, X10, X21, X22, X34–X36)** | Dashboard nghiệm thu Increment (Docs Ready = REQ ∩ AC ∩ SCN ∩ IF ∩ DATA + BIP/FIP) |
| `G14` | S14 → S15 | DEV | Code xanh, coverage ≥80%, trong allowed_files | Test logs + Coverage report |
| `G15` | S15 → S16 | QC | 100% SCN Pass, cập nhật RTM status | `evidence.json` + Test execution runbook |
| `G16` | S16 → S17 | PM & QC | Đạt trọn vẹn 4 điều kiện thoát DoD D-116 | Báo cáo nghiệm thu kỹ thuật (0 CRITICAL) |
| **SIGN**| S17 → Done | **PO & PM** | **Human Sign-off hoàn tất** | Chữ ký nghiệm thu đóng giai đoạn |
