## 1. Kết luận naming

| Tên v1 | Sai vì | Tên dùng từ nay |
|---|---|---|
| `Lite` | nghe như bản yếu, nhưng thực chất là **market harness** (MCP có sẵn) | **market** |
| `Pro` | nghe như bản mạnh, nhưng thực chất là **ESO tự viết memory + code graph + docs graph** | **eso-native** |
| `DSH native` | là **host**, không phải nguồn harness cùng cấp | **host-native** trên host `dsh` |

- **Không** còn `lite` / `pro` / `dsh-native` trong contract, UI, docs v2.
- **Không** có “3 hay 4 tier”. Có **3 harness source** và **các host**.
- **Không** có Edition (`community/team/enterprise`): operator chốt **một sản phẩm duy nhất** (2026-11-10).

## 2. Ba khái niệm tách biệt

| Khái niệm | Trả lời câu hỏi | Giá trị |
|---|---|---|
| **Harness source** | Memory/graph/docs của ai, có portable không? | `market` · `eso-native` · `host-native` |
| **Host** | Agent chạy ở đâu, hook/plugin/API nào? | cursor · antigravity · claude · codex · dsh · paseo · orca |
| **Product edition** | Bán/license cấp gì? | **không có** — một sản phẩm |

`Tier` chỉ tồn tại nếu operator mở edition; hiện **không**.

## 3. Ba harness source — định nghĩa đã chốt

| Source | Định nghĩa | Portable | Trạng thái |
|---|---|---|---|
| **market** | Dùng MCP có sẵn: agentmemory · codegraph · docgraph · graphify… | ❌ mỗi host cấu hình MCP riêng; data ở tool ngoài | có |
| **eso-native** | ESO tự viết **memory + code graph + docs graph** | ✅ một SoT, host là adapter | planned (G-B/G-E) |
| **host-native** | Host tự cung cấp harness (session/skills/rules/memory) | ❌ gắn host | có một phần; capability tuỳ host |

**Quyết định operator 2026-11-10:** `host-native` **không chỉ DSH**. Claude / Antigravity / Cursor cũng được
xem là host-native, dù hiện chưa có đủ harness (MCP hoặc memory dài hạn) — đó là **capability level**, không phải
định nghĩa lại source. DSH là host-native mạnh nhất hiện tại; Codex là future.

| Nhóm | Host | Sở hữu agent loop | ESO cắm qua |
|---|---|---|---|
| **IDE-native** | Cursor · Antigravity | ✅ | hooks · MCP · rules/skills |

| **orchestrator** | Paseo · Orca | ❌ (delegate) | plugin · API · timeline · CLI |

## 5. `host-native` — capability, không phải tên host

`host-native` chỉ nói **nguồn harness do host cung cấp**; mức cung cấp khác nhau:

| Host | Session/skills/rules | Memory dài hạn | Đánh giá |
|---|---|---|---|
| Cursor | có (rules/skills/session) | cần đo | host-native **partial** |
| Antigravity | có (skills/rules/session) | cần đo | host-native **partial** |
| Claude | có (CLAUDE.md/skills/session) | cần đo | host-native **partial** |
| DSH | có (session/skills/plugin) | có | host-native **strong** |
| Codex | chưa đo | chưa đo | **future** |
| Paseo/Orca | timeline/session của orchestrator | không phải harness | **không phải host-native source** |

**Luật:** không được quảng cáo “host-native” cho một host nếu chưa có probe/AC cho capability level tương ứng.
Host-native là **source**, level là **dữ liệu đo**.

## 6. Paseo / Orca — orchestrator, không phải harness source

- Paseo/Orca quản nhiều agent, worktree, remote, mobile; **không tự viết agent loop/harness**.
- Chúng host session/timeline, nhưng timeline đó **không phải memory/code graph/docs graph** của ESO.
- Vì vậy: ESO **không** coi Paseo/Orca là `market`/`eso-native`/`host-native` source.
- ESO cắm vào bằng **plugin / API / CLI / timeline**; đây là **orchestration surface**, không phải harness source.

## 7. ESO có hai phần — operator chốt 2026-11-10

| Phần | Vai trò | Trạng thái |
|---|---|---|
| **`eso`** | **độc lập**: view / observatory / control plane; Docker đã cài; action xảy ra ở host; prompt request được ghi lại để phân tích | có |
| **`eso-harness`** (harness layer) | **plugin** đưa harness vào host; hiện plugin vào **eso-native**; tương lai plugin vào **DSH**, hoặc bộ **Paseo/Orca** | future/partial |

Hệ quả:
- `eso` không phụ thuộc host; host chỉ gửi evidence/request.
- Harness layer là **adapter/plugin**, không phải control plane.
- DSH + ESO native là **composition**; DSH không phải “loại harness thứ tư”.
- Paseo/Orca là nơi **orchestrate**, không phải nơi ESO thay thế memory/graph.
