## 0. Định danh

| | |
|---|---|

## 0.1 Hành vi (page làm gì)

- `Enable observation` bật/tắt; chọn event sẽ ghi (append-only).
- `Refresh evidence` tải observation; timeline chỉ đọc.
- JEV: `mode`, `auto/confirm threshold`, `confidence` → `Evaluate decision`.

## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ Observation                                  │
│  [x] Enable observation                      │
│  Recorded events (n / total)                 │
│   [x] event A  [ ] event B ...               │
├──────────────────────────────────────────────┤
│ Evidence plane · Observatory                 │
│  3 KPI (observations · hosts · last)         │
│  [Xem chi tiết → /observatory?consumer=:id]  │
├──────────────────────────────────────────────┤
│ JEV integration: mode · auto · confirm · conf│
└──────────────────────────────────────────────┘
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| `Enable observation` | off ⇒ khoá event + JEV |
| Recorded events | mỗi event append-only khi host gửi; đếm `n / total` |
| KPI | observations · hosts · last evidence; **không** phải verdict |
| Link Observatory | sang page `/observatory`, không dựng lại timeline chi tiết |
| JEV | `mode` off/shadow/active · auto/confirm threshold · confidence |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| consent off | control disabled; JEV cảnh báo |
| dirty | Save enabled |
| `PROFILE_JEV_NEEDS_CONSENT` | mã + message |
| `PROFILE_JEV_THRESHOLD` | mã + message |
| lỗi đọc timeline | mã + message |

## 4. Không quyết định

UI không quyết: event hợp lệ · verdict/sufficiency · chạy JEV · host gửi gì.

## 5. A11y

Toggle có label; danh sách event dùng checkbox + mô tả; lỗi `role="alert"`; link Observatory mô tả đích.
