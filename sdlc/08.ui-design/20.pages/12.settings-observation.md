## 0.1 Hành vi (page làm gì)

- Bật/tắt `Enable observation`; chọn 4 loại event sẽ ghi.
- Link `Open Observatory` sang `/observatory?consumer={id}` để xem evidence (row, trace, KPI).
- **Không** còn timeline, KPI, hay JEV (xem §9 "Ranh giới").

## 2. Bố cục

```
hero (E1-E5)  ·  events card (E6-E7)
```

Bỏ khỏi bề mặt này (đã chuyển hoặc xoá): 4 KPI, `Refresh evidence`, `Observation timeline`, `<details>Evidence`, `JEV integration`, `Evaluate decision`.

## 3. Trạng thái

`ready` · `consent off` (chỉ event bị khoá) · `dirty` (draft cấp page) · `error` (cấp page footer).

Không còn state `loading/error` riêng của panel: panel không gọi API.

## 4. Không quyết định

Event nào host gửi · verdict · JEV band · nội dung evidence.
Consent **không** phải quyền: nó chỉ khoá event checkbox, không chặn host gửi observation.

## 5. A11y

Toggle có label text; checkbox label + description trong `mat-checkbox`; link Observatory là `<a>` thật (keyboard + middle-click được).

## 6. Coverage

**7/7** element. Đổi so với `1.3.0`: bỏ E8–E23 (observatory KPI + JEV + timeline) theo quyết định operator 2026-11-26.

## 8. Ranh giới — cái gì nằm ở đâu (quyết định 2026-11-26)

| Bề mặt | Nội dung | Lý do |
|---|---|---|
| `settings?tab=observation` | consent + phạm vi event | Config surface |
| `settings?tab=stack` (group `Judgment · JEV`) | `jev.mode` · `autoThreshold` · `confirmThreshold` · `Evaluate decision` | JEV là **policy**; cùng chỗ với gates/layers/versions |
| `/observatory` | observation row, trace, KPI, live pulse, trace detail | Data surface |

Ràng buộc giữa hai tab: `mode ≠ off` cần `consent = true`. Stack cảnh báo inline + nút `Go to Observation`; Save vẫn là chốt (`PROFILE_JEV_NEEDS_CONSENT`). Chọn JEV mode ≠ off ở Stack **tự bật consent** (prerequisite), và việc tự bật này bị loại khỏi baseline dirty để form không báo "Unsaved changes" oan.
