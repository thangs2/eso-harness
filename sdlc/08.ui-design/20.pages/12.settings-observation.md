## 0.1 Hành vi (page làm gì)

- Bật/tắt `Enable observation`; chọn 4 loại event sẽ ghi.

- JEV: chọn mode + threshold + `confidence` → `Evaluate decision`.

## 2. Bố cục

## 3. Trạng thái

`loading` · `ready` · `consent off` (chỉ event bị khoá, **JEV mode vẫn chọn được**) · `error`.

## 4. Không quyết định

Event nào host gửi · verdict · "Gate: unknown ≠ absent" là nhãn tĩnh.

## 5. A11y

Toggle có label; lỗi `role=alert`; input number có min/max/step; timeline row không keyboard (gap).

## 6. Coverage

**27/27** element; sửa: **4 KPI** (không 3), consent-off **không** khoá JEV mode, **không** có link `/observatory`, timeline dựng đầy đủ + Evidence.
