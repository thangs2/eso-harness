## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ header: eyebrow · h1 · subtitle  [Create]    │
├──────────────────────────────────────────────┤
│ filter: Status [All|Ready|Retired]  n / m    │
├──────────────────────────────────────────────┤
│ stats: consumers · ready · last update       │
├──────────────────────────────────────────────┤
│ alert (chỉ khi lỗi)                          │
├──────────────────────────────────────────────┤
│ loading | empty (2 loại) | bảng 6 cột        │
└──────────────────────────────────────────────┘
```

## 2. Header & filter

| Thành phần | Hiển thị |
|---|---|
| eyebrow / h1 / subtitle | `Control Plane` · `Consumers` · 1 câu mô tả |
| `Create consumer` | nút → `/setup` |
| `Status` | select `All` · `Ready` · `Retired`; mặc định `All` |
| đếm | `số đang hiện / tổng` bên cạnh filter |

## 3. Stats (3 ô)

`consumers` = tổng đang tải · `ready` = số `status = ready` · `last update` = `updatedAt` lớn nhất (rút gọn 16 ký tự, `T`→space).
Ba số **không** đổi khi đổi filter.

## 4. Bảng

6 cột: **Consumer** (name + id nếu khác) · **Repo** (`root`, monospace) · **Status** (pill; xanh khi `ready`, vàng khi khác) · **Version** (`v<n>`) · **Updated** (`dd/MM/yyyy HH:mm`) · **Actions**.

Actions mỗi dòng: `Details` → `/consumers/:id` · `Events` → `/events?consumer=:id`.

## 5. Trạng thái hiển thị

| Trạng thái | UI |
|---|---|
| loading | panel `Loading consumers…` |
| empty — chưa có | `No consumers yet` + `Create consumer` |
| empty — lọc không khớp | `No consumers match this filter` + gợi ý bỏ lọc; **không** hiện nút tạo |
| error | một alert đầu trang, **mã + message** |

## 6. Không quyết định

UI **không** quyết: quyền xem · `exists` · "đủ/thiếu" của consumer · giá trị 3 số (tính từ danh sách server trả) · trạng thái consumer (chỉ hiển thị).

## 7. A11y

`role="alert"` cho lỗi · `aria-label="Consumer list"` cho bảng · `aria-label` cho select filter · bảng có `<thead>`, cột có `data-label` để chuyển dạng card trên mobile.
Thiếu: `aria-live` cho lúc tải xong; thông báo khi filter làm rỗng (hiện chỉ đổi nội dung).

## 8. Visual

Token từ shell (`--surface`, `--line`, `--muted`, `--space-*`). Pill status dùng màu + chữ. Bảng cuộn ngang khi hẹp; cột `Repo` ellipsis.
