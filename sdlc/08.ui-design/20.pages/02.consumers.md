## 0.1 Hành vi (page làm gì)

- Xem danh sách consumer + 3 số tổng (consumers · ready · last update).
- Lọc theo `Status` (All/Ready/Retired) — **phía client**; đếm `visible/total`.
- `Details` mở chi tiết; `Events` mở `/events?consumer=`.
- `Create consumer` → `/setup`; khi rỗng hiện CTA tạo.

### B6 State machine

```text
loading --list ok, items>0--> list(rows)
loading --list ok, items=0--> empty(create)
loading --list fail--------> error (alert + empty(create) cùng hiện)
list --statusFilter != all--> list(filtered)
list(filtered) --statusFilter = all--> list
error --(không có nút reload)--> error
```

| Từ | Trigger | Đến | Anchor |
|---|---|---|---|
| `loading` | `finally` sau list | `list` / `empty` / `error` | `consumers.page.ts:107`, `consumers.page.ts:46-54` |

| `empty(filter)` | filter = all | `list` | `consumers.page.ts:95` |
