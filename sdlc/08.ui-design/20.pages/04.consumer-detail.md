## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ header: eyebrow "Consumer · v<n>" · h1(name) │
│         subtitle: id · root   [Open settings]│
├──────────────────────────────────────────────┤
│ banner (chỉ khi ?created=1)                  │
├──────────────────────────────────────────────┤
│ grid 2×2: Profile | Knowledge base           │
│          Team & gates | Protected paths       │
└──────────────────────────────────────────────┘
```

## 2. Header

eyebrow `Consumer · v<version>` · h1 = `name` · subtitle = `id` + `root` · nút `Open settings` → `/consumers/:id/settings`.

## 3. Banner

Chỉ hiện khi `?created=1`: "Consumer saved. Setup is complete; you can now process cases." Không có nút đóng.

## 4. Bốn panel (read-only)

| Panel | Nội dung |
|---|---|
| **Profile** | Canonical (`agents / harness`) hoặc host fallback · Source policy · Description · Version + status |
| **Knowledge base** | SDLC root · Header profile · Preset · mỗi Zone (`name` · `path` · `headerProfile`) |
| **Team & gates** | Roles · Gates (chỉ key `true`) · Sources (chỉ key `true`) |
| **Protected paths** | danh sách path; rỗng ⇒ "No protected paths configured." |

Giá trị thiếu hiện `—`; danh sách rỗng hiện `—` (trừ Protected paths).

## 5. Trạng thái

| Trạng thái | UI |
|---|---|
| loading | panel `Loading consumer…` |
| ready | 4 panel |
| created | banner phía trên grid |
| error | một alert, **mã + message**; **không** hiện panel |

## 6. Không quyết định

UI không quyết: quyền xem · consumer tồn tại · giá trị canonical/host · "đủ/thiếu" · việc sửa (thuộc settings).

## 7. A11y

`role="alert"` cho lỗi · heading `h2` cho từng panel · `dl/dt/dd` cho cặp khoá–giá trị · link settings có nhãn rõ.
Thiếu: `aria-live` khi tải xong; thông báo khi consumer không tồn tại (hiện chỉ alert).

## 8. Visual

Token shell. Grid 2 cột (mobile 1). `path` và `id` dùng monospace. Banner dùng màu "saved" của shell.
