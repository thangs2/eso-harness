## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ tab bar (7 tab)                              │
├──────────────────────────────────────────────┤
│ Stack: Version [v3 ▾]                        │
│ Layers: rules · skills · agents · hooks · mcp │
│ Material / document graph                    │
├──────────────────────────────────────────────┤
│ Rules material (.mdc / .md)                  │
│  preview · conflict [keep-eso|adopt-legacy]  │
├──────────────────────────────────────────────┤
│ versions list (v1 · v2 · v3 active)          │
├──────────────────────────────────────────────┤
│ footer: Save changes                         │
└──────────────────────────────────────────────┘
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| `Version` | version active; đổi ⇒ nạp version đó |
| Layers | bật/tắt layer + allowed sources; sửa ⇒ dirty |
| Material / document graph | thuộc version, không phải host config |
| `Rules material` | `.mdc` = Cursor, `.md` = Markdown; đều canonical dưới `agents/rules/` |
| `Conflict` | chọn hướng khi import đè |
| versions list | version published bất biến; active có dấu |
| `Save changes` | gửi **toàn bộ** danh sách version |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| loading | panel chờ |
| dirty | Save enabled |
| saving | Save disabled |
| `STACK_VERSION_IMMUTABLE` | mã + message; không ghi |
| `RULES_IMPORT_CONFLICT` | mã + message; chờ chọn conflict |
| `STACK_DENIED` / `STACK_UPSTREAM_FAILED` | mã + message |

## 4. Không quyết định

UI không quyết: version hợp lệ · layer bắt buộc · publish bất biến · version nào host dùng (F-44).

## 5. A11y

Label cho mọi field; lỗi `role="alert"`; bảng version có header; trạng thái active không chỉ bằng màu.
**Chưa kiểm**: keyboard di chuyển giữa layer.
