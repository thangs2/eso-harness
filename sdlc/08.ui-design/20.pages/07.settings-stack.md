## 0.1 Hành vi (page làm gì)

- Chọn `Version`; `New version` tạo draft.
- Bật/tắt layer 2 nhóm; chọn `allowedSources`; layer `deferred` không bật được.

## 2. Bố cục

```
[Version ▾] [New version] [Publish draft] [Reopen] [Retire] [Delete]
Agent system: multiAgent · rules · skills · hooks (toggle + sources)
Knowledge & context: memory · codeGraph · documentGraph · topology (toggle + sources)
Rules material: [Import .mdc] [Import folder]
  preview: n candidates · n skipped · per-rule Conflict · [Import n selected]
  bảng rules + bảng Skipped
```

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| draft | layer/pills bật được; có `Publish draft`, `Delete draft` |
| published | toggle/pills disabled; có `Reopen as draft`, `Retire version` |
| retired | không sửa |
| importing | `Reading…`, import disabled |
| conflict chưa chọn | `Import n selected` vẫn theo `importableRuleCount` |

## 4. Không quyết định

Layer nào bắt buộc · version numbering · host nào dùng version (F-35) · nội dung rule sau import.

## 5. A11y

Toggle có label; bảng rules có `<thead>`; nút disabled đúng trạng thái; `Cancel` trong confirm/preview.
**Chưa kiểm**: keyboard chọn Conflict cho nhiều rule.
