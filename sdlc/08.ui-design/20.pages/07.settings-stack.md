## 3. Trạng thái

`draft` (editable) · `published` (immutable) · `retired` · importing (`Reading…`) · error (message thô; shell codes `PROFILE_*`).

## 4. Không quyết định

Layer bắt buộc · version numbering · host pin (F-35) · nội dung rule sau import.

## 5. A11y

Toggle/checkbox có label; bảng có header; nút disabled đúng; confirm inline không phải dialog.

## 6. Coverage

**48/48** element; sửa 3 WRONG: preview header render bug (in `vm().rule(s)`), reopen/delete cần thêm điều kiện **không bị host pin** (và `>1` version), mã lỗi thật là `PROFILE_*` (không `STACK_*`).
