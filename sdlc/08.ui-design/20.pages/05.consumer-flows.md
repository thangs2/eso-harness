## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| no flow | `No flow yet.` |
| draft | badge warn, có `Delete draft` |
| published | `Set default` bật khi chưa default |
| renaming | input thay tên, Enter/Esc |
| busy | nút đổi nhãn/disabled theo cờ |
| error | alert mã + message |

## 4. Không quyết định

Flow hợp lệ · loop (server trả warning) · version numbering · pin cho host (`F-35`) · chạy flow.

## 5. A11y

Rename input có `aria-label`; `role="alert"` cho lỗi; nút disabled đúng; `title` cho node/port.
**Chưa kiểm**: keyboard di chuyển node, `aria-live` cho validation.
