# `/consumers/:id/flows` — bề mặt UI

> **Nhà:** bố cục · thành phần · trạng thái · a11y. Hành vi ⇒ [`F-39` §7](../../05.requirements/01.specification/03.frd/34.consumer-flows.md) ·

| | |
|---|---|
| Page id | `PAGE-FLOWS` |
| Route | `/consumers/:id/flows` |
| Component | `eso/ui/apps/control-plane/src/app/features/consumers/pages/flows.page.ts` |

| Guard | `authGuard` |

## 1. Bố cục

```
┌────────────────────────────────────────────────────┐
│ header: eyebrow · h1 "Worker flow" · badge         │
│         subtitle                  [Save draft][Publish]
├────────────────────────────────────────────────────┤
│ flow picker: n defined · pills · [+ New flow]      │
├────────────────────────────────────────────────────┤
│ workbench head: id · tên (Rename) · meta           │
│   tools: Undo Redo | Fit Snap Auto | Default Validate Delete
├────────────────────────────────────────────────────┤
│ [confirm xoá draft] [SLP proposal banner]          │
├────────────────────────────────────────────────────┤
│ canvas (node · cạnh · inspector cạnh)              │
└────────────────────────────────────────────────────┘
```

## 2. Header

eyebrow `Consumer setup / Flows` · h1 `Worker flow` · badge `status v<version>` (warn khi `draft`) · badge `default`.
`Save draft` (disabled khi không có flow) · `Publish` (`Publishing…` khi chạy).

## 3. Flow picker

- `n defined`; rỗng ⇒ `No flow yet.`
- Mỗi pill: `name` · `id · v<version>` · chấm status · `default`.
- `+ New flow` (disabled khi `creating`).

## 4. Workbench

| Vùng | Thành phần |
|---|---|
| Title | `id` · `name` + `Rename` (inline: Enter lưu, Escape huỷ) · `n nodes` `n edges` `status v` |
| Undo/redo | disabled theo `history`/`future` |
| View | `Fit` · `Snap grid` · `Auto arrange` (không gọi API) |
| Flow ops | `Set default` (disabled nếu không `published`) · `Validate` · `Delete draft` (chỉ draft) |
| Confirm | khối `role="alert"` khi xoá draft: Cancel / Delete |
| Proposal | banner SLP: nguồn · node/edge · warning; Apply |
| Canvas | node kéo được; nối cạnh cần `on`; inspector sửa `on`/guard |

## 5. Trạng thái

| Trạng thái | UI |
|---|---|
| loading | (không có spinner riêng; nút disabled) |
| no flow | `No flow yet.` |
| draft | badge warn; có `Delete draft` |
| publishing / validating / saving | nhãn `…ing` trên nút tương ứng |
| error | `flow-error` đầu trang, **mã + message** |

## 6. Không quyết định

UI không quyết: worker tồn tại · flow hợp lệ · cycle (server trả warning) · version numbering · pin flow cho host · quyền.
Canvas chỉ hiển thị/sửa **definition**, không chạy gì.

## 7. A11y

`aria-label="Flows"` cho picker · `role="alert"` cho lỗi + confirm xoá · input rename có `aria-label` · nút disabled đúng trạng thái.
Thiếu: keyboard di chuyển node trên canvas · `aria-live` cho kết quả validate.

## 8. Visual

Token shell. Canvas nền chấm; cạnh xám, cạnh dim khi lọc; badge `default` dùng màu accent; pill active nền brand.
Mobile: workbench tools wrap; canvas giữ min-height, không tràn ngang 360px.
