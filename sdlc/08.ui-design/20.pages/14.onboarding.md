## 0.1 Hành vi (page làm gì)

- Chọn consumer `ready` → preview `schema c_<id>` + material (không host/tier).
- `Provision` chạy provisioning; thành công hiện `status`; lỗi hiện mã + HTTP status.
- Rỗng ⇒ blocked + CTA sang `/setup`.

## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ header: Onboarding Consumer                  │
├──────────────────────────────────────────────┤
│ alert-error (code · HTTP status · message)   │
│ alert-success (consumer · schema · status)   │
├──────────────────────────────────────────────┤
│ loading | blocked (không có consumer ready)  │
│  | chọn consumer + preview + [Provision]     │
└──────────────────────────────────────────────┘
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| Chọn consumer | chỉ consumer `ready`; đổi ⇒ preview đổi |
| Preview | `id` · `root` · schema `c_<id>` · material; **không** host/tier/recipe |
| `Provision` | gọi F-32; disabled khi đang chạy |
| Success | `role="status"`: consumer + schema + `status` |
| Blocked | danh sách rỗng ⇒ CTA sang `/setup` |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| loading | panel "Loading ready consumers…" |
| empty | blocked + CTA, **không** tự tạo |
| provisioning | nút disabled |
| error | `role="alert"`: **code + HTTP status + message** |

## 4. Không quyết định

UI không quyết: consumer đã provision chưa · schema hợp lệ · quyền · việc tạo schema (F-32).

## 5. A11y

Lỗi `role="alert"` · thành công `role="status"` · select có label · trạng thái loading có `role="status"`.
**Chưa kiểm**: focus sau provision.
