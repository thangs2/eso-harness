## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ header: event stream viewer · [Observatory]  │
│         [Office 3D] [Refresh]                │
├──────────────────────────────────────────────┤
│ filters: Consumer · Event · Outcome · Worker │
│          Trace · Order                       │
├──────────────────────────────────────────────┤
│ n events · m traces  [All][Requests][Failures]
├──────────────────────────────────────────────┤
│ danh sách event (lane theo worker)           │
├──────────────────────────────────────────────┤
│ detail của event đang chọn                   │
└──────────────────────────────────────────────┘
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| Consumer | select; đổi ⇒ tải lại |
| Event / Outcome | `all` + giá trị có trong dữ liệu |
| Worker / Trace | input chuỗi; trace khớp chính xác trước |
| Order | newest/oldest |
| chips | `All` · `Requests` (`prompt.submitted`) · `Failures` (`outcome=FAIL`) |
| Event list | chỉ đọc; mỗi event thuộc một worker lane |
| Detail | request/evidence; **không** prompt body |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| loading | nút `Refreshing…` |
| empty | nêu lý do, không hiện 0 giả |
| error | mã `OBS_*` + message |

## 4. Không quyết định

UI không quyết: event hợp lệ · outcome · quyền · nội dung prompt.

## 5. A11y

Filter có label; danh sách có thể đọc bằng keyboard; lỗi `role="alert"`.
**Chưa kiểm**: focus sau khi refresh.
