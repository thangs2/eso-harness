### B6 State machine
```
loading --ok--> ready
loading --lỗi--> error --?--> loading
ready --Install--> installing --ok--> ready (list mới)
installing --lỗi--> error-inline
```

### B7 Error paths
| Nguồn | Điều kiện | Hiện | Retry |
|---|---|---|---|
| load | 5xx/network | message thô | reload |
| install | JSON sai | `Manifest must be valid JSON` | sửa JSON |
| install | API từ chối | `reason` của server | thử lại |
| install | network | message thô | thử lại |
