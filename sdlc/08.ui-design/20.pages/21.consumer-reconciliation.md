## 0.1 Hành vi (page làm gì)

- Tải trạng thái quét gần nhất (`GET /reconciliation/gaps`) cho đúng `:id` consumer khi vào trang hoặc đổi consumer trên route.
- Cho phép chuyển phạm vi quét (`Full` | `Git Diff`), bấm **Run Scan** (`POST /reconciliation/scan`), hoặc bấm **Sync DB** (`POST /reconciliation/sync-index`).
- Hiển thị **3-Pillar Health Ribbon** (`GAP-A·B·D` · `GAP-C·E` · `GAP-F`) và **SDLC Pipeline Coverage (`S1–S17`)** chia 4 cột cân đối; click trụ hoặc ô stage sẽ lọc thẳng xuống danh sách.
- Hiển thị **Master-Detail Split Workbench**: danh sách GAP cô đọng ở cột trái + **Sticky Inspector Panel** ở cột phải với nút xử lý ngữ cảnh (`Re-verify & Re-lock Hash` · `Sync PostgreSQL Index` · `Generate Skeleton to Inbox` · `Extract Draft to Inbox` · `Copy Agent Prompt` · `Dismiss`).

### Quy ước bắt buộc
- **Zero OS Emoji:** 100% icon là inline monochrome SVG (`1.5px`–`1.6px` stroke, kế thừa `currentColor`).
- **Rem tokens only:** `--space-*`, `--text-*`, `--radius-*`, `--surface`, `--surface-2`, `--line`, `--ink`, `--muted`, `--brand`.
- **4 Phase Cards `.stage-col`:** `border-left: 3px solid` phân biệt 4 nhóm bằng 4 trục màu cách biệt (`A: #3b82f6` Blue, `B: #fb923c` Orange, `C: #10b981` Emerald, `D: #a855f7` Purple); `.stage-chip` bên trong giữ nền neutral `--surface-2` + dot semantic `6px`.
- **Responsive:** `≥1100px` 2 cột Master-Detail · `<1100px` Inspector stack dưới Ledger · `<860px` 3-Pillar stack 1 cột · `<360px` 0 tràn ngang (`horizontalOverflow: false`).

## 3. Trạng thái

| State | Kích hoạt | Hiển thị |
|---|---|---|
| `ready` | Có ≥1 GAP sau `loadGaps` / `scan` | Master-Detail split; dòng đầu tiên tự chọn trong Inspector |
| `scanning` | Đang gọi `POST /scan` | Nút `Run Scan` disable + spinner; nếu list rỗng hiện `empty-state` đang quét |
| `syncing` | Đang gọi `POST /sync-index` | Nút `Sync DB` disable + icon SVG quay |
| `busy-row` | Đang chạy `extract` / `relock` / `ignore` / `syncIndex` cho 1 GAP | Các nút action trong Inspector bị disable + label đang xử lý |
| `staged` | GAP có draft `proposed` trong Inbox | Badge `Staged`, Inspector hiện `Staged as proposed draft` + link `Open Artifacts Inbox` |
| `resolved` | GAP đã `relock` hoặc được Promote qua Gate S17 | Badge `Resolved`, dòng giảm opacity `0.7`, Inspector hiện `Reconciled & verified` |
| `empty` | `0` GAP & không lọc | `empty-state` xanh lá: "Source code, SDLC artifacts, and PostgreSQL knowledge index are synchronized." |
| `filtered-empty` | `0` GAP do filter | `empty-state` kèm nút `Clear all filters` |
| `error` | Lỗi HTTP / backend | `.error-banner` (`role="alert"`) hiển thị thông điệp lỗi thật + nút `Retry Scan` |

## 4. Không quyết định

UI **không** tự quyết định file nào hợp lệ, hash nào đúng, hay stage nào đạt Gate S17; mọi số đếm (`pipelineStages`, `postgresStats`, `gaps`, `ignoredCount`) và chuyển trạng thái (`staged_in_inbox`, `resolved`) đều nhận từ kết quả của `ReconciliationScannerService` & `ArtifactLifecycleService`.

- Roles chuẩn: `role="region"`, `role="tablist"` / `role="tab"` (`aria-selected`), `role="listbox"` / `role="option"` (`aria-selected`), `role="search"`, `role="alert"` (`aria-live="assertive"`), `role="status"`.
- Mọi control có `:focus-visible` (`outline: 2px solid var(--brand)`), hỗ trợ Tab keyboard hoàn chỉnh, `#recon-search-input` có `id` + `name` + `aria-label`.

## 6. Behavior Spec (STD-PAGE-BEHAVIOR)

Gốc anchor: `eso/ui/apps/control-plane/src/app/features/consumers/`.

| Ký hiệu | File |
|---|---|
| `page` | `pages/consumer-reconciliation.page.{ts,html,scss}` |
| `hero` | `components/reconciliation/reconciliation-hero.component.ts` |
| `pipe` | `components/reconciliation/reconciliation-pipeline.component.ts` |
| `metrics` | `components/reconciliation/reconciliation-metrics.component.ts` |
| `toolbar` | `components/reconciliation/reconciliation-toolbar.component.ts` |
| `card` | `components/reconciliation/reconciliation-gap-card.component.ts` |
| `svc` | `services/reconciliation.service.ts` |
| `kb` | `pages/settings-knowledge.base.ts` |

### B1 Entry & Multi-consumer Isolation
- Subscribe `route.paramMap` (`takeUntilDestroyed`); khi `:id` đổi → gọi `svc.setActiveConsumer(id)` + `svc.loadGaps(id)`. State lưu theo `Record<consumerId, ...>` nên chuyển giữa `fineso` và consumer khác **không bao giờ rò rỉ dữ liệu**.

### B2 Filter & Stage Interactions
- Click lại Pillar hoặc Category Tab đang active → tự động toggle về `'all'`.
- Click `.stage-chip` trong `S1–S17`: nếu `missing` → lọc `GAP_E_MISSING_SDLC_DOC` + điền mã stage vào search; nếu `drift` → lọc `GAP_F_INDEX_DRIFT` + thư mục stage.

### B3 End-to-End Resolution Flows
- **GAP-A / B / D / E:** Bấm *Extract / Generate Skeleton* → `POST /api/v1/consumers/:id/artifacts` (lưu DB với `ktState: 'proposed'`) → GAP chuyển `staged_in_inbox` → user mở `Open Artifacts Inbox` → bấm **Promote to KB** (`kb`) → backend ghi file vào `sdlc/` + cập nhật manifest + re-index Postgres → `kb` gọi `svc.markGapResolved(gapId, id)` → GAP chuyển `resolved`.
- **GAP-C:** Bấm *Re-verify & Re-lock Hash* → `POST /reconciliation/relock` → cập nhật SHA-256 manifest + re-index Postgres → GAP chuyển `resolved`.
- **GAP-F:** Bấm *Sync DB* (Hero) hoặc *Sync PostgreSQL Index* (Inspector) → `POST /reconciliation/sync-index` → re-index toàn bộ `knowledge_doc` và làm mới danh sách GAP.
- **Dismiss:** Bấm *Dismiss* → `POST /reconciliation/ignore` → lưu `.harness/reconcile-ignore.json`, gỡ GAP khỏi list và tăng `ignoredCount`.
