## 2. Header

| Thành phần | Nội dung |
|---|---|
| eyebrow | `Operate · observatory` |
| h1 | `Observatory` |
| subtitle | 1 câu mô tả mục đích |
| `Live event stream` | link → event stream, mang consumer hiện tại |
| `3D graph` | link → 3D view, mang consumer hiện tại |
| `Refresh` | nút; khi đang tải: nhãn `Refreshing…` + disabled |

## 3. Context bar (read-only)

Badge `read-only config` góc phải. 5 field, field 1 luôn hiện, 4 field còn lại chỉ hiện khi có consumer:

| Field | Cách hiển thị |
|---|---|
| Consumer | select; đổi ⇒ tải lại toàn trang, pulse reset |
| Workspace | monospace, 1 dòng, ellipsis, tooltip = path đầy đủ |
| Status | pill; xanh khi `ready`, vàng khi khác; kèm `v<version>` |
| Observation | pill `consent on` / `off / unknown` (gộp 2 trạng thái) |
| Flow | `name` + `v<version>`; `—` khi chưa có |

## 4. KPI strip

5 ô, mỗi ô: **nhãn · số · nhãn phụ nêu nguồn**. Nhãn cố định: `Events` · `Traces` · `Prompts` · `Failures` · `Last event`.
Cách tính số: FRD §2.4 — UI không tự định nghĩa lại.

## 5. Graph panel

| Thành phần | Hành vi hiển thị |
|---|---|
| tiêu đề / phụ đề | tên flow + mô tả ngắn theo view |
| `view-switch` | 2 nút `Workers` / `3D offices`, `role="group"`, nút đang chọn có trạng thái active |
| view Workers | sơ đồ luồng worker |
| view 3D | sàn 3D, cùng node/cạnh |
| rỗng | `No published flow for this consumer.` |
| chọn node | node được highlight; panel phải lọc theo worker |

## 6. Live pulse

| Thành phần | Hiển thị |
|---|---|
| tiêu đề | trace đang phát, hoặc `Play a request` |
| `Stop` | chỉ hiện khi đang phát |
| input | placeholder `Trace ID / request text / turn…` |
| nút play | `▶` khi rảnh, `…` khi đang phát, disabled khi đang phát |
| meta | `<đã hiện> / <tổng> events` · chấm live · `playing` / `ready` |
| progress | thanh % theo tiến độ phát |
| rỗng | `No events loaded` + hướng dẫn |
| danh sách | mỗi dòng: tên event · worker · thời điểm; dòng fail/block có màu cảnh báo; dòng đang phát được highlight |

## 7. Request grid

**Toolbar:** ô `Search` · dải `IDE Filter` (nút `All IDEs` + mỗi host, dot màu) · checkbox `Group by conversation` (mặc định bật) · checkbox `Failures only`.

**Chế độ nhóm:** mỗi conversation là một khối mở/đóng được, header có host badge · id rút gọn · số turn · thời điểm mới nhất; bảng con 13 cột: `# · When · Query · Source · Status · Verdict · Model · In · Out · Calls · Tools · Checks · Open`.

**Chế độ phẳng:** một bảng 15 cột (thêm `IDE`, `Conversation`).

**Dòng prompt con:** thụt vào, source hiện `subagent`/`swarm`, Calls=1, Tools=0, Verdict `—`.

**Pager:** `Previous` / `Next`, disable theo vị trí; dòng đếm `Showing a–b of N`.

## 8. Ma trận trạng thái hiển thị

| Trạng thái | Dấu hiệu UI |
|---|---|
| loading | `Refresh` = `Refreshing…`; không skeleton |
| ready | đủ 5 khối |
| empty — không flow | panel graph rỗng, các khối khác vẫn hiện |
| empty — không event | KPI = 0; pulse rỗng |
| empty — grid | `No requests found` + gợi ý chờ hoạt động |
| playing | `Stop` hiện, chấm live, progress chạy, dòng cuối highlight |
| error | một alert ở đầu trang, có mã + message |
| denied | cùng chỗ alert, mã `OBS_DENIED` |

## 9. Tương tác (UI)

chọn consumer · chọn view · chọn/bỏ chọn worker · nhập + play/stop · click một event (đi tới chi tiết) · search · lọc host · 2 checkbox · expand prompt con · phân trang · mở chi tiết request · `Stream` (phát trace trong pulse) · 2 link header · `Refresh`.
Mọi thao tác **không** ghi dữ liệu; `Stream` cuộn tới `#live-pulse`.

## 9b. Không quyết định

UI **không** quyết: `exists` · `permission` · `sufficient` · trạng thái consumer · con số KPI (lấy từ FRD §2.4, không tự tính lại) ·
việc consumer có flow published hay không (server trả). UI chỉ **hiển thị** kết quả server + mã lỗi server.

## 10. A11y

Có: `role="alert"` cho lỗi · `aria-label` cho select/input/nút play · `role="group"` cho view-switch · `aria-expanded` cho expand · `details/summary` native · `<table>` có `<thead>`.

Thiếu (phải sửa): progress thiếu `role="progressbar"`/`aria-valuenow` · trạng thái phát thiếu `aria-live` · nút play đổi nhãn nhưng không đổi accessible name · filter host thiếu `aria-pressed` · status chỉ phân biệt bằng màu + chữ nhỏ.

## 11. Visual

- Nền/token lấy từ shell (`--surface`, `--line`, `--muted`, `--space-*`, `--radius-*`).
- **Nợ:** `request-grid` tự khai palette riêng (`#131722`, `#5aa9ff`…) thay vì token ⇒ phải gom về token chung.
- Host có màu riêng theo bảng màu cố định; màu chỉ là phụ, nhãn chữ mới là nguồn.
- Responsive: dưới 1100px grid 5 cột → 1 cột; dưới 700px toolbar xuống dòng, bảng cuộn ngang.

## 12. Ảnh chụp cần có

1. mặc định · 2. đang phát · 3. không flow · 4. lỗi · 5. grid rỗng · 6. grid nhóm có expand.
