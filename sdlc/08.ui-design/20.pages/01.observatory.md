## 4. Trạng thái

| Trạng thái | UI |
|---|---|
| loading | `Refreshing…` |
| no published flow | graph rỗng + `No published flow` (không phải lỗi) |
| playing | `Stop`, live dot on, progress chạy |
| error | alert **mã + message**; không hiện 0 giả |
| empty pulse | "No events loaded" + hướng dẫn |

## 5. Không quyết định

UI không quyết: event hợp lệ · trace khớp · quyền · KPI (đếm từ 500 event mới nhất) · 3D event graph (Phase 2).

## 6. A11y

`aria-label` cho consumer select, pulse input, play button; `role="alert"` cho lỗi; nút disabled đúng trạng thái.
**Chưa kiểm**: keyboard di chuyển node trên graph; thông báo khi pulse kết thúc.
