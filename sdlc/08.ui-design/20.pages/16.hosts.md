## 0. Định danh

| | |
|---|---|
| Page id | `PAGE-HOSTS` |
| Route | `/hosts` |

## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ header: System · hosts                       │
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| Catalog | `cursor` · `agy` · `dsh` · `claude` · `codex` · `paseo` · `orca` |
| Runtime kind | `ide-native` · `cli` · `acp` |
| Health | `unknown` · `healthy` · `degraded` · `offline` |
| Model tier | `fast` · `balanced` · `reasoning`; mỗi tier `model` + `effort` |
| `HostModelSheet` | sửa model/effort theo tier |
| Dialog | `register` · `host` · `runtime` |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| empty | chưa có host, CTA `Register host` |
| dialog | form theo mode, đóng bằng Esc/backdrop |
| error | hiện message từ API |

## 4. Không quyết định

UI không quyết: host có thật hay không (probe), binding consumer (`F-35`), sync state (`F-33`), quyền.

## 5. A11y

Dialog cần focus trap + `Esc` (đã có `@HostListener`); mỗi field có label; health dùng chữ + màu.
