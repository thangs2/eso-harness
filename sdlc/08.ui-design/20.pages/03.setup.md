## 2. Bước 1 — Repo

| Thành phần | Hành vi |
|---|---|
| ô `Root repo` | nhập tay hoặc `Choose folder` (chọn thư mục) |
| `Choose folder` | resolving ⇒ nhãn `Resolving…`, disabled |
| hộp `Layout to create` | hiện trước `AGENTS.md` · `agents/` · `.harness/` |
| lỗi | `SETUP_ROOT_*` (mã + message) dưới ô nhập |

## 3. Bước 2 — Consumer

3 trường: `Consumer id` (slug) · `Consumer name` · `SDLC root` (mặc định `sdlc`). Không có trường host/source.

## 4. Bước 3 — Observe

| Khối | Hành vi |
|---|---|
| toggle `Enable observation` | off ⇒ khoá toàn bộ event + JEV cảnh báo |
| đếm | `n / 4 events selected` |
| `Select all` / `Clear` | disabled khi consent off |
| danh sách event | 4 checkbox 2 cột, mỗi ô có label + mô tả |
| `JEV mode` | `Off` · `Shadow` · `Active`; chọn khác `Off` khi consent off ⇒ cảnh báo `SETUP_JEV_NEEDS_CONSENT` |

## 5. Bước 4 — Preview & apply

Tổng hợp 5 dòng: Root · Consumer · SDLC root · Observation (`n event` / `off`) · JEV.
Nút `Create consumer + canonical harness` ⇒ `Creating…` khi đang gửi; disabled trong lúc gửi.

## 6. Trạng thái

| Trạng thái | UI |
|---|---|
| bước | `active` (đang xem) · `done` (đã qua) · `disabled` (vượt `furthest`) |
| loading folder | `Resolving…` |
| saving | `Creating…`, nút disabled |
| error | alert đầu trang, **mã + message**; dữ liệu đã nhập giữ nguyên |

## 7. Không quyết định

UI **không** quyết: root có tồn tại (server/FS resolve) · id có trùng (server) · kết quả provision (F-32) · quyền (401/403 do server) · giá trị mặc định của server.

## 8. A11y

`aria-label="Setup steps"` cho nav bước · `role="alert"` cho mọi lỗi (trang, root, JEV) · mỗi bước là `<button>` có trạng thái `disabled`/`active`.
Thiếu: `aria-current="step"` · thông báo khi chuyển bước (focus management).

## 9. Visual

Token shell (`--space-*`, `--line`, `--surface`, `--brand`). Bước `active` nền brand; `done` chữ đậm; panel min-height 340px để không nhảy layout. Grid 2 cột event; mobile 1 cột.
