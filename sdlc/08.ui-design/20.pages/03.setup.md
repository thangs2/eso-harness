## 0.1 Hành vi (page làm gì)

- 4 bước: chọn root repo (hoặc `Choose folder`) → khai consumer id/name/sdlcRoot → bật observation + chọn event + JEV → xem summary → `Create`.
- `Next` chỉ mở bước kế khi bước hiện tại hợp lệ; bước đã qua bấm lại được; `Back` lùi.
- Bước 3: `Select all`/`Clear` theo consent; event được chọn trước khi tạo.
- Submit tạo consumer + harness canonical; lỗi hiện mã + message, dữ liệu giữ.

### B6 State machine

```text
1 --Next hợp lệ--> 2 --Next hợp lệ--> 3 --Next hợp lệ--> 4 --Create ok--> /consumers/:id?created=1
n --Back--> n-1
n --click step ≤ furthest--> m (nhảy tự do)
n --Next lỗi validate--> n + error
4 --Create fail--> 4 + error (dữ liệu giữ nguyên)
rootResolving=true --resolve xong--> false
```

| Từ | Trigger | Đến | Anchor |
|---|---|---|---|
| `step n` | `next()` hợp lệ | `step n+1` | `setup.page.ts:252-254` |
| `step n` | `back()` | `step max(1, n-1)` | `setup.page.ts:244` |
| `step n` | click step ≤ `furthest` | `step m` | `setup.page.ts:29` |
| `step 4` | `apply()` ok | route detail | `setup.page.ts:317` |
| `step n` | validate fail | giữ `step n` | `setup.page.ts:249`, `setup.page.ts:301` |
