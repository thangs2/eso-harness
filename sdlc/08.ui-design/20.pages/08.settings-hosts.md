## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ h2 Who uses which host runtime               │
│ [Bulk upgrade] [New host binding]            │
├──────────────────────────────────────────────┤
│ Active bindings                              │
│  developer → host runtime × Stack version    │
│  · flow/version · memory · code graph        │
├──────────────────────────────────────────────┤
│ empty: "No host bindings yet"                │
└──────────────────────────────────────────────┘
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| `Target Stack version` | version đích cho bulk upgrade |
| `New host binding` | thêm join developer × host runtime × version |
| Nhóm theo developer | số host profile của developer |
| Form binding | Developer · Registered host · Stack version · Flow · Flow version · Memory source · Provider |
| `Bulk upgrade` | disabled khi không có binding |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| empty | "No host bindings yet" + gợi ý |
| ready | bảng binding |
| `VERSION_NOT_PUBLISHED` | mã + message; không ghi |
| `VERSION_NOT_FOUND` | mã + message |
| `BINDING_CONFLICT` | mã + message (trùng developer × host) |
| `BINDING_DENIED` | mã + message |

## 4. Không quyết định

UI không quyết: host runtime có tồn tại · version published · capability resolution · quyền.

## 5. A11y

Bảng có `<thead>`; mỗi form field có label; lỗi `role="alert"`; nút disabled đúng trạng thái.
**Chưa kiểm**: keyboard trong bảng nhiều dòng.
