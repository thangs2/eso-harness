## 0.1 Hành vi (page làm gì)

- Xem binding theo developer (`host · version · flow pin`); `View` mở hiệu lực (layers, memory/graph source + provider, material).
- `Bulk upgrade` chọn version đích → `Upgrade bindings` (chỉ khi có target + affected>0).
- `New/Add host binding`: developer, host đã đăng ký, stack version, flow (+version) → `Add`/`Save`.
- `Remove` binding / `Remove developer` (confirm); `Use host defaults` điền source/provider.
- `Detected host runtimes`: `Bind with ESO` hoặc `Register in Hosts`.

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| no binding | empty + CTA (disabled nếu chưa có host active) |
| bulk open | form version đích; `Upgrade bindings` chỉ bật khi có target + affected>0 |
| add/edit | form; Developer disabled khi edit |
| confirm remove | Cancel/Remove |
| detected | grid + action theo host đã đăng ký hay chưa |
