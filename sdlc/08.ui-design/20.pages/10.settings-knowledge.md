# `settings · knowledge` — bề mặt UI (khối Knowledge index)

> Hành vi ⇒ [`F-14` §7](../../05.requirements/01.specification/03.frd/14.inventory.md) · `REQ-22` ·
> tiêu chí [`AC-47`](../../06.analysis/02.ac/AC-47.md) · truy vết [`RTM-KNOWLEDGE-01`](../../06.analysis/04.rtm/RTM-KNOWLEDGE-01.md).
> **Chỉ khối Knowledge index**; 6 khối khác đã chốt ở [`00.index`](00.index.md#bản-đồ-settings--năng-lực-chốt-2026-11-23).

## 0. Định danh

| | |
|---|---|
| Page id | `PAGE-SETTINGS-KNOWLEDGE-INDEX` |
| Route | `/consumers/:id/settings?tab=knowledge&section=index` |
| Component | `components/knowledge-tab.component.*` + `knowledge-overview.component.*` |

## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ eyebrow Knowledge index                      │
│ 3 docs · 5 edges · 2 findings                │
├──────────────────────────────────────────────┤
│ Preflight · PASS/FAIL · n checks             │
├──────────────────────────────────────────────┤
│ Indexed documents · n                        │
│  bảng: doc · kind · path · status            │
├──────────────────────────────────────────────┤
│ findings (nếu có)                            │
└──────────────────────────────────────────────┘
```

## 1b. Năm section của khối index

`?section=` nhận: `section=overview` · `section=sources` · `section=contract` · `section=index` · `section=manifest` (mặc định `overview`; `index` là khối của page này).

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| counts | docs · edges · findings từ summary; thiếu ⇒ `—` |
| Preflight | `status` + `n checks`; FAIL nổi bật |
| Indexed documents | **tất cả** row; nội dung vẫn ở file, chỉ đọc Postgres |
| findings | danh sách; rỗng ⇒ "no findings" |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| loading | panel chờ |
| empty | "no document indexed" |
| check FAIL | khối đỏ + n checks |
| error | mã + message; không số 0 giả |

## 4. Không quyết định

UI không quyết: kind/owner của doc · kết quả check · index graph · project mode (OUT).

## 5. A11y

Bảng có `<thead>`; FAIL không chỉ bằng màu; lỗi `role="alert"`.
