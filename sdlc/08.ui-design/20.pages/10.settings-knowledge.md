## 0.1 Hành vi (page làm gì)

- 5 section (`overview` mặc định); overview có 4 card + preflight + routing.
- `Run check` chạy preflight; `Index now` index lại tài liệu; `Embed pending` nhúng chunk.
- Index: search doc, mở detail (outgoing/incoming/transitive + sections), xem findings + hybrid retrieval + coverage.
- Manifest/docgraph/provider routing: render nhưng **ngoài phạm vi tài liệu hoá chi tiết** (`F-36`/`F-37`/OUT).

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| checking | `Checking…` |
| indexing | `Indexing…` |
| embedding | `Embedding…` → `Embedded` |
| empty docs | `No indexed documents yet. Click Index now.` |
| findings 0 | khối findings **ẩn**, nhưng stat/open findings vẫn in `0` |
| error | message (không map mã riêng ở tab) |

## 4. Không quyết định

Index/read authority thuộc **Boundaries** · graph indexing (`F-37`) · manifest (`F-36`) · provider routing (OUT).

## 5. A11y

`role=tablist` + `aria-selected`; lightbox `role=dialog aria-modal`; row doc click **không** `tabindex` (gap: không keyboard được).

## 6. Coverage

**35/35** element (E25–E32 ghi **OUT phạm vi**, vẫn render); sửa 4 WRONG: cap **50** không phải "all rows", empty text, 4 cột thật, findings ẩn-khi-0 nhưng counter vẫn 0.
