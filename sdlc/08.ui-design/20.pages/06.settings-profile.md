## 2. Thành phần ổn định

| Thành phần | Ghi chú |
|---|---|
| Tab bar 7 tab | đổi tab = đổi `?tab=`; tab 1 là `profile` |
| `Switch consumer` | đổi consumer đang sửa |
| Form profile | `name` · `owner` · `locale` · `tags` · `description` (5 trường) |
| `Save changes` | disabled khi không `dirty` (hoặc đang `saving`) |
| `version` | hiện cạnh tiêu đề; tăng sau Save |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| clean | Save disabled |
| dirty | Save enabled |
| saving | Save disabled + nhãn |
| saved | banner |
| `409` | `PROFILE_STALE_VERSION` + message; không ghi đè |
| `401/403` | `PROFILE_DENIED` |
| `5xx` | `PROFILE_UPSTREAM_FAILED` |
| JEV sai | `PROFILE_JEV_NEEDS_CONSENT` · `PROFILE_JEV_THRESHOLD` (client) |

## 4. Không quyết định

UI không quyết: version (server) · drift (server hash) · quyền · giá trị mặc định của field · việc materialize (F-05).

## 5. A11y

Tab bar dùng button + trạng thái active; form có label; lỗi `role="alert"`; Save có `disabled` đúng.
`aria-selected`/keyboard tab order: **chưa kiểm** — nợ UI, không thuộc page doc.
