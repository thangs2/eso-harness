## 3. Bố cục

```
header (S1) + Switch consumer (S2)
alert (S3) | saved (S4) | legacy/migration notice (S5,S6)
migration panel (S7) | legacy finish (S8) | legacy archive (S9)
tab bar (S10) → profile panel (P1-P6)
footer: Back · dirty state · Save · Next/Finish (S12-S16)
```

## 4. Trạng thái

| Trạng thái | UI |
|---|---|
| clean | `All changes saved`, Save disabled |
| dirty | `Unsaved changes`, Save enabled |
| saving | `Saving…` (Finish), Save disabled |
| saved | banner `Settings saved.` |
| 409 | `PROFILE_STALE_VERSION` + message |
| 401/403 · 5xx | `PROFILE_DENIED` · `PROFILE_UPSTREAM_FAILED` |

## 5. Không quyết định

Version · drift · quyền · việc materialize (F-05) · migration/legacy là pipeline riêng, UI chỉ điều khiển.

## 6. A11y

`role=tablist`/`aria-selected`; dirty state `aria-live=polite`; lỗi `role=alert`; banner `role=status`.
**Chưa kiểm**: keyboard ←/→ giữa tab.
