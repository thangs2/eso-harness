| | |

## 0.1 Hành vi (page làm gì)

- Nhập username/password → `Sign in` (Basic, kiểm qua `/auth/me`).
- Thành công lưu credential + điều hướng `returnUrl` (chỉ path nội bộ) hoặc `/consumers`.
- Lỗi hiện `code: message`; dev prefill chỉ khi `environment=development`.

## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│            card "Sign in"                    │
│  eyebrow ESO Control Plane                   │
│  subtitle: credential từ eso/.env (Basic)    │
│  [alert lỗi: code: message]                  │
│  Username [________]                         │
│  Password [________]                         │
│  [ Sign in / Signing in… ]                   │
└──────────────────────────────────────────────┘
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| Username | `autocomplete="username"`, required |
| Password | type password, `autocomplete="current-password"`, required |
| Submit | gửi Basic; disabled + nhãn `Signing in…` |
| Alert | `role="alert"`, hiện `code: message` |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| idle | form trống (production) |
| dev | prefill `operator` + token dev — chỉ khi `environment=development` |
| signing-in | nút disabled |
| error | alert, không lưu credential |

## 4. Không quyết định

UI không quyết: credential đúng/sai (server) · quyền · trang đích hợp lệ (whitelist `^\/(?!\/)`).

## 5. A11y

Form có label · lỗi `role="alert"` · nút disabled đúng lúc · `aria-label="Control plane sign in"` cho card.
**Chưa kiểm**: focus vào ô username khi mở trang.
