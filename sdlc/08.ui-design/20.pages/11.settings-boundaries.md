# `settings · boundaries` — bề mặt UI

> Hành vi ⇒ [`F-06` §7](../../05.requirements/01.specification/03.frd/06.consumer-isolation.md) · `REQ-10` ·
> tiêu chí [`AC-48`](../../06.analysis/02.ac/AC-48.md) · truy vết [`RTM-BOUNDARY-01`](../../06.analysis/04.rtm/RTM-BOUNDARY-01.md).

## 0. Định danh

| | |
|---|---|
| Page id | `PAGE-SETTINGS-BOUNDARIES` |
| Route | `/consumers/:id/settings?tab=boundaries` (tab 6/7) |
| Component | `components/boundaries-panel.component.*` |

## 1. Bố cục

```
┌──────────────────────────────────────────────┐
│ h2 Read, write & index policy                │
│ Mode [audit|enforce]                         │
├──────────────────────────────────────────────┤
│ Path policies   "Deny wins over allow"       │
│  prefix · kind · mode            [thêm dòng] │
├──────────────────────────────────────────────┤
│ Grants  "write single-use · read once/always"│
│  target prefix · kind · mode · expiry        │
├──────────────────────────────────────────────┤
│ footer: Save changes                         │
└──────────────────────────────────────────────┘
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| `Mode` | enforcement: `audit` (chỉ ghi nhận) / `enforce` (chặn) |
| Path policies | prefix · kind · mode; **deny thắng allow** |
| Grants | target prefix · kind · mode · expiry |
| Save | gửi toàn bộ policy + enforcement |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| empty | "no policy" + gợi ý |
| dirty | Save enabled |
| `BOUNDARY_INVALID` | mã + message; không ghi |
| `BOUNDARY_DENIED` / `BOUNDARY_FAILED` | mã + message |

## 4. Không quyết định

UI không quyết: quyền actor · scope check runtime (`F-18`) · grant còn hiệu lực hay không tại thời điểm chạy.

## 5. A11y

Mỗi field có label; bảng policy/grant có header; lỗi `role="alert"`; "deny thắng allow" nêu bằng chữ, không chỉ màu.
