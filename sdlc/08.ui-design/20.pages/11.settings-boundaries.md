## 0.1 Hành vi (page làm gì)

- Xem 3 số hero; chọn `Mode` audit/enforce.
- Thêm/sửa policy: path + type + `read` (allow/deny) + `write` (bypass/gated/warn/deny) + `Index`.
- Tạo grant (target prefix · kind · mode); `Revoke`.
- `Save boundaries` ghi toàn bộ; banner `Boundaries saved.`

## 2. Bố cục

```
hero (E1-E8) · mode (E9)
path policies (E10-E19) · grants (E20-E26)
```

## 3. Trạng thái

`loading` · `empty` · `saving` · `saved` · `error` (message thô).

## 4. Không quyết định

Thứ tự áp policy (engine theo **specificity**, không phải "deny luôn thắng") · TTL grant (server default: write 15′–8h, read 15′–90d) · enforce thật (hook host).

## 5. A11y

Header cột `aria-hidden`; input path có `aria-label`; nút Remove có `aria-label` động; lỗi `role=alert`.

## 6. Coverage

**27/27** element; sửa 6 WRONG: nút là `Save boundaries` (không phải footer), không in mã lỗi, 5 cột (không 3), read/write tách mode, không có input expiry, write+always bị ép `once`.
