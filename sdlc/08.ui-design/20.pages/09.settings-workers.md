## 0.2 Prompt contract — Mode A/B (2026-11-25)

Mode A/B trong tab Deployment là **cấu hình worker**, không phải nút chạy. Prompt quyết định mode:

```text
mode=A <task>        # một worker local
mode=B <task>        # một worker dispatch sang host remote
impl <KEY> slp g mode=A|B <task>   # SLP optional
```

| Điều | Quy tắc |
|---|---|
| Target | lấy từ `worker-placement` (`modes`, `allowedHosts`); **không** `to=` trong prompt |
| SLP | không bắt buộc; `mode=` standalone chạy một worker |
| Không có `mode=` | prompt chat bình thường; router không can thiệp |
| Mode B | cần remote host `serve` + token; nếu thiếu → fail, không fallback |
| Single agent chat | **không** phải Mode A/B formal; Mode chỉ áp cho worker/host-runtime |

User guideline: [`17.prompt-mode-guideline`](../../02.governance/01.standard/17.prompt-mode-guideline.md). Prompt `mode=` được AGY/DSH PreInvocation injector chèn lệnh router; Cursor skill-followed (không có context field). Không cần SLP. Router: [`36.prompt-mode-router`](../../07.technical/01.architecture/36.prompt-mode-router.md).
UI chỉ lưu config; execution nằm ở host.


### 0.2.1 Prompt matrix panel (2026-11-25)
