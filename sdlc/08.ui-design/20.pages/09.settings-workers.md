```

```

## 4. Trạng thái

| Trạng thái | UI |
|---|---|
| empty | chưa có worker; `Add worker` / import |
| importing | `Reading…`; preview trước khi ghi |
| syncing | `Syncing…`; drift badge |
| dirty | Save settings ở footer shell |
| saving | `Saving…` ở placement |

## 5. Không quyết định

Policy engine · capability resolution · sync nền · quyền · thứ tự worker (flow quyết).

## 6. A11y

`role=tab`/`aria-selected` cho inspector; `aria-label` cho nút xoá scope/capability/worker; search có label; lỗi qua alert shell.
**Chưa kiểm**: keyboard thêm tag bằng Enter.
