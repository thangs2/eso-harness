## 1. Bố cục (phần sync)

```
┌──────────────────────────────────────────────┐
│ Worker directory            [Sync sources]   │
│  n source · n projection · status            │
├──────────────────────────────────────────────┤
│ drift list: file · kind      [Promote]       │
├──────────────────────────────────────────────┤
│ Worker directory → form: Name · Role · Layer │
│   Status · Prompt body                       │
├──────────────────────────────────────────────┤
│ Runtime & model: allowed runtimes + model     │
├──────────────────────────────────────────────┤
│ Import preview: n candidate · n skipped       │
│   [Apply] (audit ghi lại)                     │
└──────────────────────────────────────────────┘
```

## 2. Thành phần

| Thành phần | Ghi chú |
|---|---|
| counts | source vs projection |
| trạng thái | in sync · drift · missing projection · orphan projection |
| `Sync sources` | rebuild index; flow không đổi |
| drift list | file + kind; `Promote` từng dòng |
| `Promote` | một chiều projection → source + reindex |
| Identity | Name · Role · Layer (`peer/gate`) · Status (`declared/active/paused/retired`) |
| `Prompt body` | nội dung hướng dẫn của worker |
| `Runtime & model` | chọn runtime được phép; model mỗi runtime; rỗng ⇒ tier |
| `Import preview` | `n candidate · n skipped`; Apply mới ghi + audit |

## 3. Trạng thái

| Trạng thái | UI |
|---|---|
| in sync | không list drift |
| drift | list + Promote |
| saving/syncing | nút disabled |
| `WORKER_SYNC_DENIED` / `WORKER_SYNC_FAILED` | mã + message (sync) |
| `WORKER_INVALID` | role/layer/status sai, id trùng |
| `WORKER_IMPORT_CONFLICT` | apply khi chưa preview |
| `WORKER_CONFIG_DENIED` / `WORKER_CONFIG_FAILED` / `WORKER_POLICY_DENIED` | mã + message (config) |

## 4. Không quyết định

UI không quyết: file nào là source · merge nội dung · policy/placement · flow.

## 5. A11y

Bảng drift có header; nút Promote có nhãn rõ; lỗi `role="alert"`.
