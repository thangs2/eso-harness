# UI baseline — trạng thái + luồng

**Một chủ đề:** state matrix và flow người dùng. Không quyết định API (plane C) hay quyền (BRD/03).

## 1. State matrix

| State | Login | List | Wizard | Detail |
|---|---|---|---|---|
| `empty` | — | "chưa có consumer" + nút tạo | — | chưa có event |
| `loading` | nút disabled | skeleton | nút disabled | skeleton |
| `error` | `AUTH_INVALID` | lỗi + retry | lỗi field + mã | lỗi + retry |
| `denied` | 401 ⇒ về login | 401 ⇒ về login | 401 ⇒ về login | 401 ⇒ về login |
| `partial` | — | filter đang áp | field thiếu | event tải một phần |

## 2. Flows

| # | Bước | Người thấy | Người làm | Hệ làm | AC |
|---|---|---|---|---|---|
| F1 | mở app | form login | nhập credential | `GET /auth/me` | AC-15-1 · AC-01-1 |
| F2 | vào list | danh sách consumer | chọn filter | `GET /consumers` | AC-15-1 · AC-04-1 |
| F3 | tạo mới | wizard 4 field | submit | `POST /consumers` | AC-15-2 · AC-02-1 |
| F4 | mở chi tiết | profile + status + event | bấm nút theo status | API tương ứng | AC-15-2/3 · AC-07…09 |
| F5 | kiểm drift | kết quả `ok/drift/…` | bấm "kiểm drift" | `POST .../profile/check` | AC-15-3 · AC-11-1 |
| F6 | đăng xuất | form login | xoá session | xoá `sessionStorage` | AC-15-1 |

## 3. Bất biến

- Không bề mặt nào tự quyết `sufficient`/`can`; chỉ hiển thị kết quả server.
- `empty` phải nêu lý do; không hiện `0` thay cho "chưa tải".
- Mã lỗi hiển thị nguyên văn; không dịch thành câu suy diễn.
