## Luật

1. UI là **design**, không phải contract: API ở `07.technical/10.planes/02.plane-c-contract.md`.
2. UI **không** quyết định `exists`/`permission`/`sufficient` — chỉ hiển thị kết quả server.
3. Mọi state phải có: `empty` (lý do) · `loading` · `error` (mã + message) · `denied`.
4. Bề mặt Expansion (S3 declaration · S4 debt) **chưa** thiết kế.
