Host bindings

Who uses which host runtime

A host binding connects one developer, one registered host runtime, and one published Stack version. It answers where the stack runs and how Memory and Code graph resolve on that host. ESO is optional: unbound tools keep working unchanged.

Hosts are registered in . This tab only assigns a registered host; it does not create a host.
