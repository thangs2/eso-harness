When should I choose A, B, or both?
Mode A · Local host

Choose when this machine has the runtime, model, and workspace. Lowest latency; no remote host involved.

Mode B · Remote dispatch

Choose when the worker should run on another host, or this host lacks the runtime/model. The target host executes it.

Both

Both paths stay open. Routing picks the first available allowed host; fallback behavior is controlled below.
